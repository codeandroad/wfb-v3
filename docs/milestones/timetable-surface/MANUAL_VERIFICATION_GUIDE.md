# 课卡外观分离人工核验（2026-10-19）

入口：http://localhost:3109/timetable 。使用顶部“原型演示控制”合成教务身份或有课表中心权限的示例林老师，选有课周次（如2026-10-26）；不重置已有偏好。

1. 教学班或行政班视图打开“显示样式 → 整张课卡”。选择原来已设颜色的对象，确认原配色仍保留，出现“课卡外观 / 对象名称 / 教师姓名 / 办公室／教室”。
2. 在课卡外观设置背景、边框颜色、粗细、线型、圆角，预览与实际常规课卡同步。试“无边框”和“直角”，刷新后仍保留。
3. 分别打开三个文字页，确认控制项、布局一致：文字颜色、文字底色、字重、字体；没有整卡背景/边框选项。分别设三组颜色，只有对应文字改变，整卡外观保持。
4. 恢复对象名称默认时，整卡背景/边框及教师、地点文字不被清除。恢复课卡外观继承时，文字样式保留。切换对象、身份后不串设置。
5. 输入合法HEX候选色时预览标记“尚未保存”；非法输入不能保存。切换部位/对象不误存候选色。旧AUTO背景的输入值与预览保持一致。
6. 检查停课、锁定、草稿、个人调整和补课状态外观，冲突/待核对标签仍清楚；教师视图不重复显示姓名。办公室／教室仍显示真实排定地点，不改变字段内容；活动保持原整体设置。
7. 缩窄窗口检查四个部位按钮自然换行、弹窗可滚动，保存后关闭/重开、刷新后设置仍在。
