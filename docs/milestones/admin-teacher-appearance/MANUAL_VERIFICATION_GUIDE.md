# 教务按教师设置样式人工核验（2026-10-19）

入口：http://localhost:3109/timetable 。通过顶部“原型演示控制”切换合成教务管理员或示例林老师；不重置已有数据。

1. 进入课表总览，选择有课程的周次，例如 2026-10-26。点击“显示样式 → 按教师”，从当前课表范围选择教师。行政班视图可同时提供多名教师，教师视图只包含当前对象。预览应显示对应教师姓名。
2. 为示例林老师设置天青背景、墨蓝文字，设置字体/字重；关闭弹窗，核对其各课程及活动采用默认样式，其他教师没有被同步改色。切换教务教师、教学班、行政班视图后设置保持一致；刷新后仍保留。
3. 先在“整张课卡”给其中一个课程设置砖红文字，再为该教师设置松绿文字。该课程仍优先使用砖红；未独立设置的课程使用松绿。按教师预览提示哪些属性被覆盖。将具体课程文字恢复继承后应使用松绿；单独背景保持原设置。
4. 为一个活动单独配置背景，教师默认背景不能盖掉它。“无染色”明确保持透明；“继承背景”才回到教师背景。学科/行政班片段原颜色继续保留。
5. 修改HEX时看候选预览；无效值不得覆盖已有保存值。逐项恢复继承或“恢复此对象继承”后，具体课程/活动设置、其他教师及其他教务身份设置都不丢失。
6. 切换另一个教务身份，确认其样式独立；回到教师端“我的课表”与教学设置，原私人样式不变。教师端细分弹窗不出现“按教师”。
7. 在有冲突/待核对的课表、过去锁定日、停课、草稿或补课状态，核对原状态底色与文字提示仍清楚可见。用筛选隐藏部分课程，按教师对象仍来自当前完整课表范围。
8. 缩小窗口或用键盘操作，部位按钮可换行，弹窗内容可滚动，选择、保存和关闭可访问。当前范围无课卡时应显示切换范围的说明。

本轮自动检查覆盖样式解析、隔离、JSON保存/清除、真实课卡渲染和全量回归；弹窗实际点击、浏览器持久化和视觉由上述人工步骤核验。Owner 验收 PENDING，未提交代码。
