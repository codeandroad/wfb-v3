# 教师与地点文字样式核验（2026-10-19）

入口：http://localhost:3109/timetable 。顶部原型演示控制使用合成教务身份或示例林老师，选择有课的周次（如2026-10-26）。不要重置已有偏好。

1. 选“教学班”或“行政班”，进入“显示样式 → 整张课卡”，选择一个教学对象。对象选择下应出现“对象样式 / 教师姓名 / 办公室／教室”。
2. 在对象样式设置整卡背景/标题色，再切教师姓名设置独立颜色、文字底色、字体/字重。预览及实际课卡只改变教师姓名，标题/学科/行政班及整卡背景保持原设置。
3. 切办公室／教室，设置地点文字的另一组颜色/底色。确认只改变现有D101等地点文字，不修改排课地点，不把职员部门当成办公室。
4. 刷新后教师/地点设置保留。逐项继承或“恢复此部位默认”仅清当前文字部位；对象样式、其他部位、其他教学对象、其他教务身份都不受影响。
5. 返回教师对象视图，仍不显示重复教师姓名；地点样式可见。切回教学班/行政班能继续看到教师文字设置。teacher模式的“我的课表”保持原私人设置。
6. 在无地点课卡上应保留“未排教室”，不得伪造办公室/示例教室；活动课卡继续沿用原活动配置。查看冲突、停课、过去锁定或草稿卡，状态提示与整卡状态底色保持可辨。
7. 在HEX输入中尝试候选颜色，尚未保存时明确提示；切换部位不会误存到另一部位。狭窄窗口按钮换行、设置区可滚动。

Owner已明确确认本轮是课卡内部教师姓名/地点文字样式。自动测试涵盖解析/保存隔离与真实课卡SSR；弹窗点击、浏览器存储刷新、视觉均留待本指南人工核验。Owner验收PENDING，未提交。
