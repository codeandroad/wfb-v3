# 人工核验：多教师活动摘要卡（2026-10-19）

状态：PENDING。入口：http://localhost:3109/timetable，使用顶栏原型演示控制中的现有合成教务身份，无需真实账号。原默认数据可能只有一位教师的“数学答疑”，此时应保留单人卡；多人浏览器核验需要已有多位教师同名同节的已发布活动数据。当前课节新增表单没有独立活动类型入口，本轮不扩展排课业务，也不自动写入或覆盖浏览器数据；若数据不足，多人视觉项继续记PENDING。自动回归使用独立的合成多人数据验证对应路径。

1. 对象栏选择“活动 → 数学答疑”。同日期、同节次若有多项，应只出现一张摘要卡，显示教师人数、安排数和场所摘要，不堆放所有姓名。
2. 点击摘要查看所有教师的独立课卡；每项显示自己的场所、状态和样式，点击可进入原详情。人员较多时弹窗可滚动。
3. 按某位教师筛选：若仅剩一项，恢复原卡与姓名；计数同时区分安排数和显示卡数。清除过滤恢复摘要。
4. 相同名称在不同日期/时段分开；不同名称不合并。同一教师多项安排不被去重成一项。
5. 多场所显示数量；一处场所加未安排项时，同时提示具体场所和未安排数量。未知场所不算成真实共享教室。
6. 摘要采用活动公共设置；仅给某教师设置默认色，不应把该颜色套到整个摘要。展开后的那位教师仍有自己的默认色。原活动四部位样式保持可设置。
7. 真实教师/场所冲突继续标识；只筛选活动仍能看到其与隐藏课程的冲突。普通与补课等混合状态分别提示。
8. 打开摘要后切周、切活动或改筛选，不应继续看到旧名单；源数据更新后详情应显示当前成员。教师/教学班/行政班视图和编辑模式不启用摘要。

限制：这是显示归组，不会把同名安排自动认定为一个联合活动，也不修改参与教师、场所或冲突事实。原生弹窗、视觉与实际浏览器点击等待人工核验；SSR与事件回归不代表已完成浏览器验收。
