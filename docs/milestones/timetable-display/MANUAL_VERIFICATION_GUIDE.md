# 课表显示改进：人工核验（2026-10-19）

当前预览：http://localhost:3109 。顶部演示身份可切换“示例林老师”（教师兼教务）、“教务管理员”（纯教务）和“示例周老师”；仅使用合成数据。

1. **旧设置与新细分**：示例林老师打开 /teaching/settings?tab=style 。确认原“我的显示样式”仍在；先设整卡文字与背景，再点下方“设置细分样式”。对数学文字设颜色、对高一1班文字设另一底色。预览继承整卡字体/背景；到 /timetable/my、/teaching?view=days 查看。恢复某一片段继承后，其余设置不变。刷新确认保存。HEX 输入无效时不覆盖有效设置。
2. **活动**：在 /timetable/my 找到有“数学答疑”的周（例如 2026-10-26），点“显示样式 → 活动课卡”，按整体设置。活动不出现学科/行政班拆分；其他教学卡不受影响。无活动周显示明确空状态。
3. **教务隔离**：打开 /timetable，在教师对象模式设置整卡、学科和行政班文字样式；切教学班、行政班仍使用本人教务设置。返回 /timetable/my 确认未改教师个人偏好。切纯教务账号确认能独立设置，不继承林老师的教务设置。
4. **课卡教师与选班**：在 /timetable 选择“教学班 → 高一1班·数学”，仅此班高亮且只显示对应班课次，卡片有教师姓名。切高一2班独立变化。行政班卡片显示各教师姓名；教师对象模式无重复教师行。点击详情可核对教师；教学班“教师课表”入口可进入对应教师调整。
5. **筛选**：完整课表按课程/活动、数学、教学班、教师（聚合模式）和关键词组合筛选；“显示 X / Y 张”随之变化。示例林老师搜索卡上可见“纯数1”应匹配。无结果可清除。切对象清空条件；换周保留条件。日卡原有教学班筛选保持可用。
6. **编辑与状态**：在合成课表进入调整，过滤掉某些课次；隐藏条目所在格不可新增或粘贴，冲突数不因此减少。查看过去、停课、草稿、个人调整和调休卡，状态标记/底色及冲突提示仍可辨认。不要为核验发布真实数据。
7. **差异与补课**：差异视图筛选某侧名称/分工，完整差异类型不改变；变化清单与双栏同范围。教师确认按钮明确“本周全部差异”。核对跨周补课时，教务取学校来源、教师取已应用来源；教学班只显示本班。
8. **小屏与键盘**：工具区自动换行，弹窗内容可滚动，颜色/下拉/保存/关闭可键盘访问；核对标题片段不会更改原文。顶部导航、左栏和作业管理保持原样。

后续修正：行政班已改为教学班明确行政归属汇总，见[行政班与冲突提示核验](../timetable-conflicts/MANUAL_VERIFICATION_GUIDE.md)，仍不等同于走班学生的实际去向。尚不能识别的自由标题整体保留。浏览器交互与逐页视觉由本指南人工核验，本轮不把服务响应/SSR 测试计作浏览器通过。Owner 验收待填写，未提交代码。
