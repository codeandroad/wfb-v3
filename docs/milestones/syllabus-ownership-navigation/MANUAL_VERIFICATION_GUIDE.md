2. 查看学校大纲：没有“修订学校大纲”按钮；“复制并编辑资料”弹窗明确创建个人副本。修改标题并保存，副本归林老师；学校原稿仍为原名。副本页面可返回来源教研组，五个课程页签仍存在。

4. 在组内课程依次切换教学大纲、教学计划、教学资源、真题库、组卷台。五个页签保持可见，课程和数学组上下文不变。资源默认显示组内/校内可用资源；主动点“我的资源”可筛选自己的资料。

7. 在学校教学大纲页新建“权限核验大纲”，保存归属为学校，校内共享；输入内容后保存学校修订，再刷新确认存在。导入学校入口仅接收大纲，其他类型应报错；归档后切换“已归档”可找到原记录。
