## 颜色跨部位

1. 教务“显示样式 → 整张课卡”选一个有场所的教学对象。在对象名称设置文字色和文字底色；再对教师姓名、场所各设不同颜色。
2. 无需逐项点保存，切到课卡外观，设置背景与边框。往返四个部位，预览应同时保留全部样式。
3. 关闭重开弹窗，再刷新页面，各部位颜色仍在。教务教师视图不重复显示本人姓名，教学班/行政班视图显示教师样式。
4. 手工逐字符输入 `#123456`：输入到 `#123` 时不应强制展开；输入完整后自动保存。单独输入 `#abc` 后离开输入框/回车/切部位，应保存为对应颜色。
5. 输入非法颜色 `#oops`，原有效颜色不变。切其他部位可见未保存提示，返回仍保留原输入，可修正或恢复此部位默认。
6. 在原型故障控制模拟保存失败：改色不得假称保存成功，返回原部位仍可重试。解除故障后重试并刷新验证。
7. 教师课表和教学设置中重复步骤；旧任务/班级/课程范围及配色应保留。再选择活动，重复四部位设置，完整活动名不拆学科与行政班。

## 教务活动

1. 教务课表对象栏选择“活动”。应有“全部活动”及按名称汇总的活动列表，而不是仅当前教师活动。
2. 选全部或某一活动，课表显示活动、对应教师及场所；点击进入原课卡详情，显示样式可选当前活动。
3. 筛选活动名称、教师或关键词，计数随之变化；清除筛选仍处于左侧选择的活动范围。
4. 在教师课表先按教学班/学科筛选，再把类型改成活动：课程专用条件解除，应能选到活动。改回课程，活动名称条件解除。
5. 选择本周无安排的活动，应明确显示空态；切周可继续查看。无活动数据时不生成虚构活动。
6. 活动与同一教师的课程/同一场所的其他安排重叠时，应显示冲突，即使另一课卡被筛选隐藏。不同教师、不同场所的同格活动不应仅因无学生名册显示“走班待核对”。

## 限制

活动页展示学校发布安排，不会把教师未发布私人活动混入学校发布视图。设置只影响当前查看者显示，不修改排课和发布数据。SSR、HTTP和事件回归不能替代原生取色器、浏览器刷新和视觉检查。
