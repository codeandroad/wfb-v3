# 2026-10-13 我的教研与课程管理：人工核验

对象：wfb-v3 原生框架，基线 5308673 加本轮未提交差异。人工核验状态：待 Owner 确认。不要提交、合并或推送。

## 打开

运行中的本机预览：<http://localhost:3109/research>；学校入口：<http://localhost:3109/catalog>。

若服务已停止，在 `resources/wfb-v3` 中运行 `pnpm dev --port 3109`。依赖已恢复；常规检查为 `pnpm typecheck`、`pnpm test`、`pnpm build`。沿用顶部“原型演示控制”切换合成人物，不在教研页自行任命。

默认示例林老师有数学组长、物理组成员和授权学校统筹职责；普通任课教师为示例周老师，可创建本人任务和活动，但不能维护固定周课表或承接学校任务。请勿将演示身份当作真实人员事实。

## 逐项核验

1. 比较侧栏与顶部：保持原 wfb-v3 布局和菜单，仅沿用已有“我的教研、课程管理”入口。原作业管理仍是原页面。
2. 我的教研显示本人有效科组，点击数学组；逐一切换七个组页签。标题/按钮行不应随内容类别跳位，课表只在“教研课表”页签出现。
3. 任务与活动 → 添加教研任务：填写名称和事项，选择两位成员，分别填事项并来回切换。关闭再打开/刷新应保留草稿；保存后摘要与成员分工一致。编辑本人任务可继续修改。
4. 添加活动安排：确认与任务表单不同，可设备课/听课/团建类型、时间、地点、成员与职责。移除刚填过职责的成员再保存应成功。组内成员只可编辑本人安排，组长可管理本组。
5. 安排当前周一场晚间活动或跨日活动；教研课表两种视图应在实际日期与时段显示。点击日卡再点活动，查看参与人员、职责并记录已发生日期的日志；未来日期不能填写实际日志。两场活动日志草稿不应串联。
6. 组长调整固定课卡并切回按日查看；日期活动与日志不能随周模板移动。普通教师不应出现固定模板调整按钮。
7. 群组聊天：成员列表在左，聊天框在右；测试 @、emoji、meme、图片/GIF/文档、引用资料、回复、回应、本人撤回和搜索。无老师工作主页/围绕事项讨论页混入聊天页；明确标注本机模拟。
8. 本组课程先显示课程列表，点击某门课程的教学大纲后，详情按 教学大纲→教学计划→教学资源→真题库→组卷台 顺序。大纲四项子页签、资源教材/练习册/校本/收藏/我的资源可以切换。
9. 新建/复制/编辑资料，保存修订；旧引用版本保留。教学计划按实际分钟、机动预算、相对周分配并采用到原任教任务；原教学/反馈链接可打开。
10. 真题库：按课程、年份、考季、Paper、Variant 过滤；切换题目检索与试卷一览。点击试卷，QP/MS 真正加载，单文件/对照切换、Insert/等级线和原件下载可用。Word/ZIP 仅下载，不能宣称已解析正文。
11. 组卷台选择实际 Topic，选多题、移除、排序，核对已知分与未知分。保存个人组合后选择本人适用任教任务、选题并明确核对，打开原 wfb-v3 布置作业表单。答案不进入学生要求；原未布置草稿优先恢复。无需为核验向真实人员布置任务。
12. 将已选个人资源归档后返回组卷台：提示失效数量，可移除失效题或清空，随后继续选题。不能通过旧篮子采用无权来源。
13. 课程管理 → 科组概况停留在学校页面，显示组长、成员、办公位置及课程；显式工作区链接才进入具体组。授权人员可维护办公信息。
14. 学校任务下发到两组，分别承接；成员明确引用已保存资料/活动/日志才形成正式成果。要求验收时学校可验收或说明原因退回；无验收要求不增加审批。成果与支持页只汇总正式提交/明确共享/明确协调事项。
15. 在当前工作提交协调问题，到学校成果与支持回复，再回组查看同一回复。试验已受限资料的日志提交应被拒，既有正式快照不被新修订覆盖。
16. 使用浏览器前进/后退、刷新和直接 URL；当前页签和本人草稿保留。查看 320/390/768/1440 宽度，主页面不能出现整体横向溢出，课表表格按自身区域横向滚动。

## 原 HTML 外观核验（2026-10-13 补充）

1. 打开我的教研，确认行式学科入口和右侧待办；进入科组后，返回入口在标题上方、角色同行、资料按钮在右侧，组内七项页签为绿色下划线样式。
2. 当前工作对照原 HTML：主栏工作/学校下发/课程，右栏活动与通知；查看/发布按钮恢复细边框。学校科组概况为表格，不是进入组的卡片。
3. 添加任务/活动时查看原有760px表单、普通标签、成员下拉及逐人成员事项、草稿提示和底部操作；用Tab/Shift+Tab与Escape检查当前弹窗和返回原按钮，日卡日志切换不叠层。
4. 课程列表进入详情后显示五项一级分类与对应子分类，课程卡片两列，阅读有目录；返回本组课程回到列表。真题年份采用筛选器、紧凑列表，组卷右侧选题保持可操作。
5. 群组聊天是成员面板加独立聊天框，表情/meme/@/文件/资料工具常驻，输入区无框；课表为统一周表，固定教研蓝色、日期活动黄色。
6. 原左栏、顶部与原作业管理不随新模块样式改变。对照截图保存在 docs/design-history/2026-10-13-html-style-restoration/evidence/；数据来自原 wfb，因此合成人物和课程数量不要求与单 HTML 相同。

## 数据与边界

人员、目录、校历、原教学与作业存储沿用 wfb-v3。旧 `file://` HTML 与 localhost 是不同浏览器来源，原 HTML 的 localStorage 不会自动进入框架；没有清空或改写原 HTML 的个人浏览器数据。所有原型新协作数据按本机模拟保存，不提供真实消息服务或生产身份鉴权。
