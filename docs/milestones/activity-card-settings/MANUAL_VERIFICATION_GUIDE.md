# 活动统一课卡设置核验（2026-10-19）

入口：教务 http://localhost:3109/timetable ，教师 http://localhost:3109/timetable/my 。使用顶部原型演示控制中的合成教师（如示例林老师），选择有课程和活动的周次（如2026-10-26）；保留已有显示偏好。

1. 打开显示样式：顶部不再有独立活动课卡页签。整张课卡 → 设置对象下拉框有“教学对象”和“活动”分组。两侧都核对。
2. 选择活动，检查原背景、名称色、字体、字重仍保留；可以在四部位分别修改外观、完整名称、教师姓名与场所。预览和真实活动课卡一致，状态提示保留。
3. 逐项恢复默认只清当前部位，整卡背景不会因恢复名称而消失；名称文字不会因恢复外观而清除。连续输入文字色/底色仍可共同预览，单独保存一项不清另一候选。
4. 教师选择活动时不显示任务/班级/课程范围按钮，显示同名活动说明。切回教学对象后恢复原范围设置；不将教学范围套用到活动。
5. 同名教学对象与活动如存在，分别选择和设置，彼此颜色不能串用。切换对象、模式及账号不会复活另一对象的未保存草稿。
6. 没有教学任务但有活动的教师仍可进入活动四部位编辑；无活动时不出现空活动分组。未安排场所不伪造地点，本人课表不重复教师姓名。
7. 关闭重开、刷新后原设置与新活动设置保留；小窗口下拉分组、按钮换行与滚动可用。
