# 颜色编辑与两侧统一设置核验（2026-10-19）

入口：教务 http://localhost:3109/timetable ；教师 http://localhost:3109/timetable/my 。顶部“原型演示控制”选示例林老师，可分别进入两侧。教学设置从“我的教学”进入设置中的“我的显示样式”。使用有课周次（如2026-10-26），保留已有偏好，不重置存储。

1. 教务显示样式 → 整张课卡 → 对象名称，先输入文字色#A2422E，再输入底色#E7EFF8，均暂不保存。两个候选应一起显示，文字不能退回原色。
2. 只保存底色：底色已保存、文字候选仍显示且未保存。关闭再打开，只有底色改变。再用相反顺序验证只保存文字色；输入框与预览一致。
3. 两项都在预览时，将一项输入暂改成“#”，只有该项退回有效保存色，另一项保持预览。验证恢复单项、选择与原值相同的色板、恢复当前部位都清除对应原始草稿；切换对象A→B→A不复活旧草稿。
4. 在课卡外观同时输入背景色和边框色、单独保存一个，验证相同隔离。只有主动选择“跟随对象名称颜色”时背景才随名称颜色配套；选择具体颜色后独立。
5. 切教师侧：教学设置与完整课表的设置都提供“课卡外观 / 对象名称 / 教师姓名 / 场所”，三个文字页控制项一致。原本任务／本班级／本课程范围保留，旧设置可直接看到。
6. 教师设置一个班级背景、一个任务名称色、课程场所字体；确认逐属性最后保存规则，P1/S1对应任务不会因整卡设置误合并。刷新后仍保持。恢复一个部位不影响另一个部位，旧范围值不会重新冒出。
7. 在我的教学按课次/按日与我的课表核对名称、场所和边框；聚焦边框、合并日卡左侧标记、停课/锁定/草稿/补课和冲突提示保留。本人视图仍不重复显示教师姓名。
8. 场所显示实际room；未排地点显示“未安排场所”，不出现伪造办公室。确认小窗口换行、滚动与键盘访问；保存失败时草稿保留且提示失败。
