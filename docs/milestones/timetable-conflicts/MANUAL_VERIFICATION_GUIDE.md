# 行政班与冲突提示人工核验（2026-10-19）

入口：http://localhost:3109/timetable 。顶部“原型演示控制”使用合成教务管理员或示例林老师（具教务身份）；切换到课表总览。不要重置已有个人存储或发布真实课表。

1. 选择行政班 → 高一（2）班，切到 2026-10-26 至 11-01。顶部显示“归属安排 · 只读”，并说明走班学生去向可能不同。默认演示课表周五第3节应显示高一2班历史，高一1班数学/物理不因任课教师关联混入。高一（1）班应包含原先遗漏的陈老师化学。若已自行修改学校课表，以当前发布版本及实际班级归属为准。
2. 切教师、教学班、行政班，核对原导航/选择仍可用；班级模式有教师姓名，教师模式不重复姓名。此前保存的颜色、细分样式不丢失。
3. 在合成草稿中将已有课次调到该教师另一课次的时段（不发布）。预期两卡显示红色教师冲突；如教室相同，也显示教室冲突。上方清单列出日期、节次、双方课程/教师及原因。退出后撤销核验草稿，不改变原发布版本。
4. 有不同教师、不同教室的同时间安排时：当有效名单存在交集，应显示学生冲突；名单明确分离时正常并行；名单不足时显示黄色“同时段安排 · 待核对”，不能把所有同格课卡一律判红。
5. 用学科/教师/关键词筛选隐藏冲突一侧，当前范围清单和剩余卡片标识仍在。清除筛选恢复全部卡片。检查颜色自定义后红/黄标识仍可辨认。
6. 校历停课日卡片保留失效状态，但不产生当日冲突；调休补课按目标日期检查。跨周补课仍采用所选班级范围。
7. 使用演示存储读取失败入口时，不应使用任务种子名单报告确定的学生冲突；教师/教室冲突继续可见。恢复读取后按实际名单更新。
