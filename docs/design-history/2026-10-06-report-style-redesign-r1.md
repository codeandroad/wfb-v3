# 周反馈报告样式重构设计史（2026-10-06）

> 记录 2026-10-06 当天 Owner（Winkee）提出的全部设计与实现要求、Dash 的实现提交，
> 以及 Owner 在 v0 中后续的 3 次提交。本文档为单一事实来源；较早修订中未被替代的要求继续有效。

## 一、最高优先级与总体原则

1. **周反馈报告发布是系统重构的重中之重**，自定义报告样式必须真正融入现有数据和模板体系，而非另起一套。
2. **数据架构铁律**：所有新样式必须围绕原型原有的核心表格和数据计算（`classicMatrix`：教学日期与作业检查合并的 chronological events、`columnKinds` 区分课堂/作业、`facts` 结构化状态）来表达，**不能只画脱离数据的文本卡片**。
3. **模板 ID 语义化且不冲突**：C01/C02/C03/C04、P02/P03 有原始代码钩子，自定义模板使用 C11–C16 / P11–P12，避开保留 ID。

## 二、Owner 全部设计与实现要求

### 预览与导出
4. 预览使用 **HTML**；通过按钮导出图片，**不**在预览窗直接显示 PNG。
5. 原有经典模板（C01/C02/C03/P01–P03）的样式**不能**因 HTML 预览的引入而被改变。
6. 「结构与样式」「元素细调」「条件格式」三处修改都必须在 HTML 预览中**实时反映**。
7. 导出图片默认 **2x 高清**，并提供清晰度选择（标准 / 高清 / 超清）。

### 字号与排版
8. 系统字体基调：正文 13–14px、页面标题 22px；预览字号和表格比例不能过大，避免过度换行和长距离下拉。
9. 数据表采用**固定布局 + canvas 实测列宽 + 单元格不换行**，各列比例统一（修复过「周一/周六出勤列换行、周五出勤列巨大空隙」的问题）。

### 缩放与工作台布局
10. 预览缩放档位：**50 / 60 / 70 / 85 / 100** 五档，外加**「适配宽度」**按钮（自动计算刚好完整显示报告的比例，不放大超过 100%，窗口变化时重算）。
11. 发布准备与模板中心的左侧设置栏收窄（`0.9fr → 0.72fr`），右侧预览窗对应变宽（`1.1fr → 1.28fr`）。

### 样式清单（均须有 HTML 预览 + canvas 图片导出）
12. **C11 三卡片速览**（微信三卡片）：手机宽度、章节 + 知识点 chips、高光学生、绿色 CTA 卡、末尾详细汇总表。
13. **C12 班级仪表盘**：3 个指标 tile、课堂等级分布条形图、本周徽章墙、待跟进清单、汇总表。
14. **C13 时间轴周报**：周次信息要明显，增加图像化元素。
15. **C14 快问快答**、**C15 一图流长图**。
16. **C16 班级周报**（报纸风，对标 `preview-2.html` 样式四）：报头 + 头版头条 + 知识速递/光荣榜双栏 + 下期预告 + 汇总表。
17. **P11 个人成长档案**（对标参考图1）：深绿渐变横幅头、四维进度条（课堂专注度 / 课堂参与度·本周突出 / 作业质量 / 出勤）、粗渐变进度条、老师点评米色底 + 金色左侧竖线、下周小目标浅绿卡、大圆角卡片 + 独立数据表卡。
18. **P12 每周一信**。
19. 班级样式必须包含「本周总评」和「学生个人点评·一人一句话」。

### 协作流程变更（2026-10-06 生效）
20. Dash **不再直接修改和推送仓库代码**；改为依据 Owner 的要求和截图**单独设计独立 HTML 页面**（如之前的作业管理模块 `homework-2.0.html`），由 Owner 手动融合进原型代码。Dash 仍可参考原型代码。

## 四、Owner 在 v0 中的后续提交（`8458c23` 之后）

### `1dd3911` — Fix report preview width measurement and simplify class template names
- `DataTableHTML` 表格加 `minWidth: '100%'`。
- **重写「适配宽度」逻辑**：Dash 版用隐藏测量层 `width: max-content` 测量自然宽度，但 max-content 会把说明长段落算成单行，导致矩阵被异常缩小；v0 版改用**固定排版宽度**（`pageWidth` state，默认 960）：取内容根节点的 computed `maxWidth`，取不到时按表格实测宽度推算（含右侧边栏说明的 1.5 倍补偿）；fit 缩放上限 **0.85**；监听 viewport/测量层/表格尺寸变化及 `document.fonts.ready`。

- 修复报纸样式光荣榜分隔符乱码。
