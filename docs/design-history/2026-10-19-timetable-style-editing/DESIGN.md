# 课表颜色编辑修复与教师设置统一（2026-10-19）

## 本次用户指令

Owner反馈文字颜色与文字底色调整时互相影响、使另一项失效；要求修复。教师端同时按教务侧方式将课卡外观和各部分文字分开，保留原设置；原办公室／教室标签统一改为“场所”。

## 编辑规则

文字颜色、底色、边框颜色各自保存原始输入和候选值。多项同时输入时，所有合法候选共同参与预览；点击某项保存只持久化并清除该项草稿，其他候选仍显示且明确未保存。输入无效颜色只撤回本项候选，不影响其他字段；失败保存保留草稿。恢复单项同时清除该项草稿，恢复当前页只清当前页草稿。切换对象、范围、部位或身份不恢复旧候选。

具体底色独立于文字颜色。旧“跟随主题色”能力保留，统一文案为“跟随对象名称颜色”或“跟随文字颜色”；只有明确选择该模式时，底色按文字颜色自动配套。既有AUTO/NONE/色板/HEX偏好继续兼容。

## 两侧统一的设置结构

| 部位 | 控制项 |
| --- | --- |
| 课卡外观 | 背景、边框颜色/粗细/线型、圆角 |
| 对象名称 | 文字颜色、局部底色、字体、字重 |
| 教师姓名 | 文字颜色、局部底色、字体、字重 |
| 场所 | 实际排定场所的文字颜色、局部底色、字体、字重 |

教学设置“我的显示样式”与“我的课表 → 显示样式”共用教师编辑器，教师原有本任务／本班级／本课程范围保留；同一属性仍以最后成功保存的设置生效。教务继续按当前查看者和具体对象隔离显示。学科文字、行政班文字和活动原入口保留。

原背景仍是整卡背景，原标题颜色/字体/字重不迁移、不改含义。新增文字底色、姓名、场所、边框等使用独立属性；恢复当前部位不会清掉其他部位，也不会让其他范围的旧值重新生效。

## 展示边界

原教学任务列表保持布局；任务名称可应用局部底色。教师按课次、按日、完整课表均接相同教师解析；状态、聚焦和合并标记优先保留。本人课表仍不重复显示教师姓名，预览可展示姓名以便设置。场所继续使用room，不修改排课地点，不伪造办公室。

大班演示任务以当前permittedTasks中的明确任务为准，使用当前教师的偏好键；不写演示教师或其他账号的偏好。无本人教学任务身份时显示空状态，不假造教学身份。

仅改变本机原型显示，不更改真实人员、课程、排课、发布与作业业务；人工视觉验收待完成。
