## 3. "我的完整课表"入口与返回导航（落实 r5 第四节）

### 3.1 按钮

- 本周教学安排页标题保持"本周教学安排"。
- 按钮从"完整我的课表"改为"我的完整课表"。
- 目标从 `/timetable`（课表中心）改为本人的 `/timetable/my`，并显式传递来源与周次：
  `/timetable/my?from=schedule&week=<该周周一>&back=<原周次与筛选参数>`

### 3.2 返回动作（`app/(app)/timetable/my/page.tsx` 的 `myTimetableBack`）

| 来源 | 返回动作 |
| --- | --- |
| `from=schedule` | "返回本周教学安排"，回到原周次、视图与筛选 |
| `from=teaching` | "返回我的教学" |
| `from=center`，且当前身份有教务权限 | "返回课表中心" |
| 侧栏、直接链接、或来源不合法 | 不显示返回动作 |

- `back` 只接受本应用内的查询参数，不会作为任意 URL 跳转；不依赖浏览器上一页。
- 普通教师任何情况下都不会看到"返回课表中心"。
- 没有给普通教师增加任何教务权限。

### 3.3 所选周保持

`/timetable/my` 读取 `week` 参数并定位到对应周，所以从第 5 周进入时仍显示第 5 周。侧栏"我的课表"和本按钮进入同一个完整模块。

### 3.4 修复的附带问题

接入 `week` 参数后，曾出现"Maximum update depth exceeded"渲染循环。现在只在 `week` 参数变化时同步一次所选周，循环已消除。清空控制台后重新加载，计数为 0。
