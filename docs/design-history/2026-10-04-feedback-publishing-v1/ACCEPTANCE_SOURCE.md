### 六条连续操作证据

1. **共同内容与双报告**：周编辑填写教学介绍／学情总结 → 进入发布准备确认同源 → 改其中一类并返回核对 → 同时预览个人与班级 → 确认不是把整体评价写成每个学生的个体结论。
2. **模板可复用**：切换八套系统模板 → 复制一套 → 改模块排序、主题、标题与默认 → 换班换周使用 → 发布 → 修改或删除模板 → 核对历史呈现不变。
3. **大班实际出图**：72人、每页27 → 全部个人预览范围 → PNG及ZIP生成 → 打开首、中、末几份及重名学生文件 → 导出长校内总表并核对全部分段。
4. **周中至修订**：从日卡进入整周准备 → 明确阶段发布V1 → 补齐后续课堂及旧作业补交 → 对比差异 → 发布V2 → 重导出V1确认旧内容不变。
5. **交付与访问**：两孩家长、双监护人、无账户学生 → 模拟账户交付和单人链接 → 注入一个渠道失败后仅重试该项 → 核对教师预览不计已读 → 停用链接后重新访问被拒。
6. **校内与家长分离**：有权教师查看/导出班级明细 → 同一班家长阅读版无逐生私密结果 → 换孩子／换学校／猜校内路径均拒绝 → 核对内部哨兵未进入任何家长图或页面。
