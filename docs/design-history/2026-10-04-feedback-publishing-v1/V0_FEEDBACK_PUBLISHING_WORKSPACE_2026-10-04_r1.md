## 0. 目标与本轮不可偏离的边界

在当前工程中完成这一条操作链：

**已有周反馈事实与公共总结 → 选择个人／班级报告 → 选择或自定义模板 → 核对实际受众与预览 → 明确发布 → 图片导出／家长账户演示／阅读链接演示 → 查看记录与修订、补发。**

先检查当前实际路由、公共总结字段、发布准备、任务组合、发布快照、图片能力、模拟存储及权限上下文。简短说明复用和修改位置，然后实施；不要停在计划、静态效果图或一组无后续动作的按钮。

本轮只规定页面应有的内容、功能导航、数据含义、交互结果和验收条件。**页面布局、控件位置、尺寸、列数、视觉编排与响应式全部由 v0 设计。** 不把本文章节顺序当页面布局，不照搬上轮讨论中的固定三栏、固定右侧预览、固定顶部按钮等示意。保留当前已稳定的共同导航，不增加重复说明、巨型统计框或层层嵌套弹窗。

沿用当前工程，不回滚历史 ZIP，不另建项目或第二套课堂／作业数据。旧 Codex 的 M3/M4 阶段门禁、早期课程单元层级和旧 UI 布局不是本轮 v0 的前置条件。保护 Owner 已试填的有效数据与当前已发布记录；必要调整定点进行，不用全站清空掩盖问题。

## 1. 最重要的内容调整：公共总结分成两类呈现

### 1.1 统一名称与含义

老师旧表格中的“备注”并不是一个应直接照搬的报告字段。按照 Owner 最新确认，现有“公共总结”中的共同教学内容分类为：

| 报告栏目 | 表达什么 | 来源及不能混入的内容 |
|---|---|---|
| **教学介绍** | 本周实际讲授、复习或训练了什么，主要章节、知识点与教学进展 | 当前任务、当前周期公共总结中对应教学内容；不是课程目录的永久简介，也不把教学计划直接视为已经完成 |
| **学情总结** | 本班整体学习状态、掌握情况、参与表现、共性困难和需要加强的方向 | 同一公共总结中对应整体表现；不是某个学生的个体评语，不自动根据字母等级生成结论 |
| **作业与后续安排** | 已明确布置的后续任务、截止时间、适用要求及教师补充说明 | 独立作业事实与已确认安排；不混进“教学介绍”或再另造一份作业 |
| **个人亮点／教师评语** | 当前学生获准公开的个人表现与建议 | 现有亮点、个体评语；不从班级整体描述复制出每个学生都相同的“个人事实” |

新报告默认使用“教学介绍”“学情总结”，不再把这两类合并叫“备注”“综合备注”或“教师寄语”。模板可以改变表现形式，但这两个内容类别不能合并成无分类的大文本框。其他模块标题可在含义清楚的范围内自定义。

### 1.2 复用同一份公共总结，不让教师写两遍

先检查现有公共总结：已有教学内容、整体掌握、课堂状态等结构字段时，映射至上述两类；不要新增发布专用的同义字段。若目前仅有一个混合文本字段，则在**同一任务＋同一周期的公共总结对象**内补齐两个有明确语义的子字段，不创建“周编辑版总结”和“发布版总结”两个来源。

周编辑、发布准备、个人报告与班级报告都读取同一内容。教师在发布准备中修改教学介绍或学情总结，保存后回到周编辑也看到同样结果；从周编辑修改后，发布预览重新核对并更新。编辑共同内容时清楚表明作用于本任务该周的共同文本，而不是只改眼前预览的某个学生。

旧混合文本无法可靠拆分时，保留完整原文作为待整理来源，提供轻量明确的分类整理操作；不按标点硬切，不自动丢弃文字，不用模型推断代替教师确认。只在确有旧混合文本的对象出现整理入口，不给所有教师增加迁移向导。已经发布的旧版本按旧快照保留，不强迫重做历史。

日小结、单课教学观察、课表本课备注、学生内部备注仍是不同对象。可查看并**明确引用、编辑后采用**相关内容整理公共总结；不自动拼接，不覆盖已经写好的总结，不把内部原文自动外发。

### 1.3 避免把个体信息重新混入共同正文

教学介绍和学情总结面向该范围内家长共同阅读。个体困难、请假原因、未交名单、私人备注不自动进入两类正文。个体表扬从已有亮点按本次明确选择进入表扬模块，不因学生获A就自动点名表扬。

旧文本里包含学生姓名或个人细节时，整理和发布前应便于教师核对共同可见内容；可以提示发现的姓名等，但不能宣称自动检查能识别所有敏感内容。不得静默改写原文成另一个意思。

两类总结可以为空，仍沿用选填规则；教师端可提醒补充，家长结果不出现占位提示或巨大空白。全部有效内容都为空的报告不能发布。不要为了让模板完整而补写“全班表现优秀”��无依据文字。

## 2. 发布工作区与导航：多入口、一条发布流程

保留“我的教学”现有教学任务／课次安排／按日记录三视图及稳定控件。发布工作区属于本模块的完整业务能力，不强制新增左侧同义一级菜单，不另造“日卡发布器”。

需要三个可直达的功能视图：**发布准备、模板中心、发布记录**。它们是功能导航，不是固定排版指令。模板中心可从教学设置提供同源入口，不能复制出第二份模板库。

| 来源 | 默认进入的上下文 | 返回要求 |
|---|---|---|
| 教学任务“准备发布／继续发布” | 当前真实任务＋当前选定周期 | 返回同一视图、周次、筛选及滚动位置 |
| 周编辑“发布与历史／发布预览” | 同任务同周期的发布准备或对应记录 | 返回原编辑上下文，不改学生选择 |
| 日卡“预览第X周反馈” | 该日所属反馈周期的完整周范围 | 不经矩阵中转；可恢复原日卡，不能变成每日报告 |
| 工作台发布或待处理项 | 实际关联任务、周期及需核对事项 | 返回工作台原上下文 |
| 发布记录“修订／补发／再次导出” | 指定报告及实际版本 | 不默认切到最新工作草稿或另一周 |

日卡来源日期仅用于确定周期、定位和返回。日卡中的搜索、分页、仅看待处理、勾选人数不隐式缩小发布范围。同任务同周期从不同日卡进入，在数据版本相同时得到相同默认周上下文。

进入、预览、切模板、打开记录都不是发布。已有草稿自动保存，准确显示保存中、已保存、失败与重试；不恢复常驻“保存草稿”按钮，不要求“先开始发布”才能浏览。发布未完成可离开并恢复一次当前准备，不建设多轮草稿管理中心。

上下文名称保持短且可辨识，使用正式教学班和规范分工；内部ID、评价代次、重复完整课程名不常驻。个人自定义分工、课卡配色不自动变成家长报告的正式名称和报告样式。

## 3. 两种报告与真实范围

### 3.1 个人反馈

一个学生一份。支持全部适用学生、明确选中学生、单个学生、明确选择可发布学生，以及从发布记录补发已有版本。分页、搜索只影响操作视图，不自动决定受众。使用“仅已完成者”前展示实际将包含与暂未包含的人数，不能静默遗漏。

个人反馈可以包含共同教学介绍、班级整体学情总结、该学生课堂记录、该学生作业结果、个人亮点、个体评语与适用后续安排。共同段落应保持班级整体语气，不改写成针对当前孩子的个体断言。

学生未出席某次课不排除其周报告和接收家长。教学范围内无已上课堂但存在作业或共同教学安排时，也能形成真实有内容的周报告。

### 3.2 教学班反馈

一个教学班的所选合法教学范围一份。主要内容为教学介绍、学情总结、日期教学摘要、实际可用的总体统计、共性提醒、经明确选择的正向表扬和后续安排。

“整个教学班”不等于其名称所指的行政班，也不等于全校该课程。范围来自真实教学班、所选任务、实际名单和任教关系。只负责P1时，必须表达本报告覆盖P1，不伪装已经包括同事负责的S1。

同教师、同教学班、同周期且有权兼容的P1/S1等任务可明确组合；不默认勾选其他分工，不自动收集其他教师草稿。组合后各任务记录、方案和公共总结仍独立存储，输出可按内容类别组织并保留必要分工标识，不产生新的成绩或第二份共同正文。编辑组合中的文字时明确编辑哪一个来源任务。

同一学生在两个分工出现时，个人报告按学生身份去重成一份，内部保留各自分工结果；班级人数使用所选真实范围的学生去重并集，不能简单相加。P1未适用的学生不得出现空白P1成绩或被计为欠评价。

### 3.3 班级家长阅读版与校内核对版

旧表的全班逐人明细有校内核对价值，因此保留**班级报告中的校内核对版**：有权教师可查看和导出自己有权范围内的全班姓名、日期、出勤、课堂及作业明细。清楚标明校内核对用途，不默认发给全体家长。这是班级报告的一种受众呈现，不增加第三套反馈数据。

班级**家长阅读版**默认不含全班逐人等级、未交名单、请假原因或其他学生私人情况。可选正向表扬须符合当前校内权限和本次明确选择，不从全班等级自动生成名单；未知学校政策不当作已经批准公开全班明细。

本版不增加一个让普通教师随意关闭隐私保护的开关。校内核对版不得出现在普通家长发送／家长分享选项里。若现工程已存在学校明确授权的不同公开政策，报告实际规则并严格沿用，不凭样例图片推断已获授权。

同时准备个人和班级报告时，共用本次一致的数据版本，分别选择模板和呈现；不是重新填写两次。个人报告受众选择不隐式改变班级统计的范围，班级统计也不凭个人发送成功人数重新计算。

## 4. 发布准备应提供的能力

发布准备应让教师直接完成：确认教学范围和周期、选择个人／班级或两者、选择学生与实际接收关系、整理两类公共总结、选择纳入内容、选择模板及本次外观、核对问题、预览、确定渠道并发布。

不强制每次走一套很长的向导。当前上下文、本人按报告类型设置的默认模板、现有纳入规则可以预填；教师只需调整例外。切换报告类型或预览学生不清空已写文字，不把当前学生的编辑复制给下一位。

课堂和作业结果优先在源记录修改。发布准备中可定位已有同源快捷编辑、该学生作业评改或学生抽屉，处理后回到同一次准备并重校验；不要另造“发布页专用分数”。周反馈仍以作业评价为主，需要布置新作业时进入现有作业管理或日卡轻量创建，发布页不扩建作业布置系统。

必须能区分：课堂记录已完成、该周内容可准备、个人报告是否发布、班级报告是否发布、各渠道是否交付。只发布班级共同报告，不把所有学生个人报告标为已发布；只补发一名学生，也不把全班标为刚更新。

## 5. 标准内容模块与表达规则

模板处理表现，不改变以下语义。各模块读发布预览或发布快照中的合法字段，不自行再次查询全班原始数据。

| 模块 | 个人反馈 | 班级家长阅读版 | 校内核对版 |
|---|---|---|---|
| 身份与周期 | 当前学生、正式教学范围、周次日期、责任教师、发布信息 | 正式教学范围、周次日期、责任教师、发布信息 | 同班级版＋校内用途 |
| 教学介绍 | 可引用适用共同正文 | 共同正文 | 同源共同正文 |
| 学情总结 | 可引用，明确为班级整体 | 共同正文 | 同源共同正文 |
| 课堂记录 | 当前学生按实际教学日的评价，附真实课次出勤明细 | 日期教学摘要；不含逐生明细 | 授权范围内逐生明细 |
| 作业表现 | 当前学生实际作业与独立提交、质量、分数、说明 | 真实总体情况，不出现负面点名 | 同源逐生结果 |
| 亮点／表扬 | 当前学生获准公开的亮点 | 明确选择的正向表扬或不点名 | 授权范围 |
| 教师评语 | 当前学生已保存个体评语 | 不套用任一学生评语 | 按权限查看 |
| 作业与后续安排 | 当前学生适用要求、真实截止与延期 | 对该报告范围适用的共同安排 | 可核对个体差异 |
| 评价说明 | 结果实际使用方案的等级与简短释义 | 展示相关统计时给出必要解释 | 实际方案说明 |

课堂按日的评价只出现一次；当天有两节课时，可列明两节的不同出勤，不复制出两个独立课堂等级。模板叫“日期纪要”也不改变存储粒度。

未参加的课堂范围不显示有效课堂等级或课堂亮点，不从旧失效记录恢复；同日部分参加按有效参与部分与现有资格规则表达。考勤事实仍可在本人报告里出现。不以未出席推断未交作业，作业真实提交的独立质量评价保留。

课堂不同日期、分工与作业各自的等级不可平均、取最低、取最高或默认转成一个“本周综合等级”。A、A+、A*、B−等按实际方案解释，不能由模板改成同义字��。原始0分保留；满分未知不擅自显示百分比。没有依据不生成能力雷达、排名、进步幅度或学科趋势。

“未登记”“到期待核对”“已确认未交”“已交待评”“选做未参与”“免做”“批准延期”等按现有实际状态表达。特殊文字说明不能强行变成字母等级。未来到期作业进入后续安排，不冒��已完成结果；同一作业不能按每次课复制。

总体统计若展示，给出清楚的统计范围与有效覆盖；分母为0或未知时不画假百分比。不把任务记录处理率当作班级出勤率或作业完成率。异质评价方案不混合统计等级；原系统没有明确、可验证的统计定义时，可使用已核对计数或文字总结，不能为了模板填充而发明算法。班级未点名的统计仍需核对其是否可从极小样本反推个人，不承诺“去掉姓名就是匿名”。

## 6. 系统模板：至少八套，区别来自信息表达而不只是颜色

每套模板都必须用同一真实合成数据可渲染、可预览、可出图；不能只有缩略图。风格由 v0 自行设计，以下定义叙事重点及必要能力，不指定任何页面坐标或固定布局。

### 6.1 四套个人模板

| 模板 | 内容表达重点 | 必须与其他模板有何区别 |
|---|---|---|
| 个人·学习简报 | 教学介绍、学情总结与个人记录的均衡摘要 | 信息简明，适合常规每周阅读，事实与评语区分清楚 |
| 个人·成长来信 | 突出已有个体评语、具体亮点和后续建议 | 叙事为主但保留可核对记录，不自动生成夸奖或虚构进步 |
| 个人·日期纪要 | 按实际教学日回顾本人课堂，作业独立归列 | 能表达同日多节不同出勤且每日评价只一次，不把作业绑在课次上 |
| 个人·清晰表格 | 课堂、作业的紧凑结构化阅读 | 手机可读，说明与等级不含混；长记录可以分段而不缩成极小字 |

### 6.2 四套班级模板

| 模板 | 内容表达重点 | 必须与其他模板有何区别 |
|---|---|---|
| 班级·每周简报 | 教学介绍＋学情总结＋共同后续安排 | 常规班级周报，能快速理解本周内容及整体情况 |
| 班级·教学纪要 | 章节、训练和日期教学摘要 | 呈现教学推进过程，不自动把未授课计划算为完成 |
| 班级·观察与建议 | 共同学习状态、共性困难、表扬及巩固方向 | 以教师已写观察为主体，不变成逐生排名或负面名单 |
| 班级·结构总览 | 共同内容与清楚的表格式摘要 | 家长版仅合法共同/总体信息；校内核对版支持授权逐生总表 |

系统模板可以属于若干视觉家族，但不是8个同结构换色副本。要求模板缩略图和实际预览对应；模板名称不承诺数据不存在的能力。

所有模板都应处理短内容、长内容、缺一个选填模块、无作业、无课堂、合并分工、不同方案和中文英文混排。空模块按规则自然收起，不出现“暂无亮点”等填充性占位，也不把存在但未核实的问题藏成空白。

每份正式输出必须可辨识报告类型、对象、周期日期和责任来源；个人反馈必须有当前学生身份，历史版能识别发布时间与版本。可简洁呈现，不靠大封面或重复页头堆叠。正式名称不能被任意手写标题替换到无法辨识真实对象。

## 7. 教师自定义模板：第一版就完成

模板中心支持系统模板、我的模板、按报告类型筛选、实际效果预览、复制系统模板、从标准模块创建个人模板、编辑、另存、重命名、设为默认、停用／删除自己的模板。

系统模板只读，复制后成为本人模板，不修改原件或其他教师模板。个人与班级默认模板分别设置，互不覆盖；本次选用不自动改全局默认。未设置个人默认就使用相应系统默认。默认改变只影响之后新建准备，不能改已打开且明确选过模板的准备或已发布报告。

允许自定义：模板名称、合法模块开关与顺序、模块支持的表现形式、报告主题与背景、可读字体风格和字重、允许的模块标题、教师署名表现、可复用的中性开场／结尾。支持颜色预设与HEX；与私人课卡样式是两份不同用途的偏好，不自动联动。

模块排序应真正可操作，提供可用的排序方式；若采用拖拽，应有键盘／触屏可用替代。不是无限自由画布，不允许通过模板执行代码、查询原始对象、拼任意URL、插入任意HTML/CSS或上传不受控背景来泄漏数据。

模板只能引用给该报告类型开放的安全字段。保存的模板配置不包含当前学生姓名、成绩、整班名单、当周正文或图片中的真实学生内容。固定文案只保存教师明确希望复用的通用文字；“另存模板”不能把眼前这名学生的整份报告当模板正文保存。

有真实结果的事实模块，默认模板应能完整表达；教师可以选择不同详略，但不能通过隐藏某个模块规避发布校验、把未知变正常或制造“全班都已完成”的印象。需要本次不纳入的结果，使用明确的发布范围操作并保留待办，不用模板开关暗中删除结果。

切换模板只改变报告呈现，不重置评价、正文、作业、受众或周期。在“个人”与“班级”类型之间不能套用不兼容模块；不兼容配置在教师端可解释地处理，不丢失模板原配置、不放宽可见字段。

模板保存前预览、保存后重开、使用于另一班另一周都应成功。修改或删除我的模板不改变过去发布的效果，历史输出读取当时冻结的模板配置；不因此建立复杂的模板审批／历史版本树。

## 8. 发布前预览：真实内容、真实受众，不是固定样例

预览读取当前已保存、已经按受众过滤的内容，提供手机阅读效果与实际图片输出效果。可以整份展开阅读；不要求固定占据屏幕某一侧，也不强迫一次只能看一个截断缩略图。

个人预览支持在本次真实选中的学生中切换、搜索、上一位／下一位，能快速定位缺项、未出席、延期、免做、长评语等例外。切换预览学生不改变发送范围，也不修改当前报告正文所属人。

班级预览必须明确当前看的是家长阅读版还是校内核对版。切换到家长版后，逐生明细应从读入该预览的内容中排除，而不只是用样式隐藏；不能把全班数据预载到家长可访问的组件中。

在任一种模板预览时，能确认教学介绍、学情总结、课堂、作业、亮点和安排的实际取值及适用范围。报告中不会出现内部原因、技术ID、模拟存储提示、教师侧控件、模板配置按钮或其他学生私人结果。

模板中心的示例预览与本次真实发布预览明确区分。没有当前合法业务上下文时可以使用显著标为合成的示例，但不能让教师误以为已加载本班实际数据。

预览后若课堂成绩、公共总结、名单适用关系、任务方案或选定模板配置发生变化，清楚提示预览待刷新，更新并再次核对实际输出后才能发布。不得发布与教师刚确认的预览不一致的快照。

关闭预览返回当前准备，选择、正文、滚动和相关问题定位保留。预览不创建正式版本，不发送，不标已读。

## 9. 发布前检查与阶段发布

校验要面向本次选择的报告、字段和接收渠道，而不是给整个班无差别封锁。问题有直接处理或明确范围调整入口，不能只报“还有15项待定”却不给下一步。

| 情况 | 本版处理 |
|---|---|
| 草稿保存失败、内容版本冲突、无权任务或学生、模板引用越权字段 | 阻止受影响输出；保留输入并提供可执行的恢复路径 |
| 未出席范围仍有有效课堂等级或课堂亮点 | 统一资格检查拒绝错误输出，回到源记录修复；不由模板偷偷保留旧值 |
| 尚未核实的负面事实 | 不能显示成已确认未交或其他确认性负面结论；明确核实或本次暂不纳入，原待办保留 |
| 已发生课堂确有未完成记录 | 提示准确范围，可直接处理；阶段发布必须由教师明确选择，不能自动藏缺项 |
| 后续尚未发生课次 | 不生成出勤或等级，不作为此前已完成；允许周中明确发布同周期阶段反馈 |
| 公共总结、亮点、个体评语等选填为空 | 提醒而不凭空阻断，家长输出按空模块策略收起 |
| 选做未参与、免做、合法不适用 | 不作为欠交或欠评价；不因此排除学生受众 |
| 缺家长账户、无核验监护关系或无可用联系方式 | 影响该渠道；合法个人图片仍可生成，不猜一个联系人发送 |
| 无课堂但有真实作业或共同教学内容 | 可按实际范围准备报告；不伪造课堂、不强迫创建日卡 |
| 本次输出内容完全为空 | 不允许发布只有标题的空报告，提示可填写或选择有效内容 |

学校要求的是周反馈，不变成日反馈。周中发布应清楚称为本周阶段反馈，保存截止到何时的内容覆盖；同周期后续补齐仍是该周的更新，不每天创建一条独立“日报”。来源日卡的日期不决定发布只包含一天。

个人范围明确选择部分可发布学生时，报告真实展示所选人数，其余保留未发布状态。班级报告如果仅有教学介绍和学情总结，可独立校验，不为没有纳入的逐生数据伪造完成；若包含总体统计，必须说明统计实际覆盖，不能把部分已登记者冒充全班。

模板开关不能消除基础数据的真实矛盾或改变任务完成度。明确暂不纳入本次的内容只是范围决定，不代表免做、已完成或删除事实。旧版本已发布且仍有效的覆盖不能在普通补发布时被不经说明地清空；确有删除、更正或范围缩减时需在差异中说明。

## 10. 发布动作、快照与记录

### 10.1 一次明确确认，内容与渠道分离

最终动作须准确说明本次报告类型、教学范围、周期、个人报告份数／班级报告份数和所选交付方式。一次清楚确认即可，不连续叠加多轮相同确认；不得因选模板、预览、生成链接候选或自动保存就触发正式发布。

发布成功写入不可变的模拟发布快照：当时的合法内容、对象与名单范围、等级解释、公共总结、所选模块、模板具体配置、语言、发布时间及版本。复用原有发布身份和规则，不创建与旧发布无关的新列表。

同时生成个人与班级报告时，快照基于同一次核对的数据版本，建立可追溯的本次发布关系；不使班级报告带入个人版私密字段。报告身份、版本与渠道交付尝试分离，不把每次下载或每位家长收件都称为一个新版本。

保存成功与渠道成功分开。渠道失败时已有发布快照仍存在；只重试失败的输出／接收方，不重新发布整个班、不重复发给已经成功者。重复点击和响应丢失重试使用同一次发布结果，不能生成多个同内容版本。

### 10.2 后续修改、修订与补发

发布后编辑课堂、作业、公共总结或个体评语，只形成相关报告的未发布变化。家长已看到的报告、旧图片和旧链接绑定版本不被后台悄悄修改。

“修订发布”基于当前合法工作内容，展示相较相关旧版本的实际变化，再明确提交新版本。“补发”是将原有指定版本补交付给明确接收方，不自动夹带尚未发布的新成绩。

同一版本可以再次下载、生成另一个受控交付链接或重试图片，不为这些操作新建内容版本。已经发布后更换模板并希望用新样式对外交付，作为明确的样式修订保存新版本或现有等价不可变呈现修订，旧效果不被替换；不重新填写成绩。

发布记录中可按教学班／任务、周期、个人／班级、版本及交付状态查找；能查看报告、实际范围、发布时间、所用模板、各渠道状态、下载、重试、补发和修订。提供必要分页，不把全历史一次加载成无限长表。

个人、班级的发布覆盖分别计算。本次只选择一种输出时，不把未选择的另一种显示为“已经发布”；也不要求每次必须同时产生两种。组合任务与受众变更时明确相关范围，不用相同班名误认同一报告。

保留旧发布记录，不要求重新分类才能查看。现有合法撤回能力继续复用；撤回或停用线上访问不删除旧事实，也不表示已收回他人保存的图片。重新发布新版本不自动复活已停用的旧访问链接。

### 10.3 状态必须真实

分开表达：待发布／已发布；图片未生成／生成中／成功／失败；账户待发送／已模拟送达／失败；链接未创建／可用／过期／已停用；人工发送记录；有证据的模拟已读。

生成、下载、复制链接、发到账户和已读不是同一状态。教师预览不是家长已读；保存截图不是已人工发送。某位家长失败不能显示“全班已送达”。

## 11. 第一版的三种交付方式

### 11.1 图片与批量ZIP：原型必须真实可用

从确定的报告内容与模板渲染生成真实PNG文件。至少支持个人单份、班级家长阅读版、授权校内核对版，以及本次明确所选个人报告的批量ZIP。

不要截图当前教师编辑页面，不把侧栏、弹窗、光标、控件或浏览器滚动条带进报告；不要将预览学生的一张图复制成全班文件。每名学生的实际内容、姓名和适用作业必须正确隔离。

长图超过当前实现安全尺寸时，按内容边界分段出图，并保留可辨識对象、周期及连续顺序。不能只截首屏，不能从一半的字或一行学生记录中间切开，不能缩小字体到不可阅读。模板、文字和图片资源加载失败时明确失败，不输出空白成功文件。

教师页面的学生分页不影响图片范围。每页27人的72人核对版应覆盖全部72人，个人批量应生成明确所选人数的完整报告，而不是仅当前页。

文件名能够辨认类型、周期、对象和版本，重名学生文件不相互覆盖；不写电话、证件号、令牌或其他非必要私密数据。ZIP清单说明包含哪些报告及分段、失败项，不包含未选学生或内部源数据。

正式导出可通过一次“发布并导出图片”的明确动作完成快照和文件生成。另有导出未发布预览稿时，清楚标明预览稿，不计为正式发布或送达。正式版本的重导出从原快照读取，不混入后来工作数据；优先复用已生成的原文件。

实现可用现工程合适的图片能力，不指定新框架或固定库版本。必须实际打开生成文件核验，不以下载按钮出现或文件扩展名证明成功。PDF／打印不是本轮验收依赖；没有完成就不宣称支持。

### 11.2 家长账户：完整合成演示，不冒充真实通知

复用当前模拟身份和监护关系，在合成家长收件列表中建立相应报告的可见项；教师选择“发送到家长账户”后能核对接收对象、结果、失败及重试。家长阅读页可打开已模拟送达的报告；不是只出现成功toast。

账户接收关系来自明确学生—监护人—账户映射，不从教学班名称、同姓、电话号码相似或展示名称推断。一个家长有两个孩子时分别关联两个个人报告；一个孩子多个合法接收家长时正确记录各自交付，不能反向合并其他孩子。

本轮未接真实服务时，操作和交付结果清楚显示“模拟发送／已模拟送达”，不调用真实短信、邮件、微信或现有连接器发送老师图片。账户收件演示不等于已接真实推送。

没有关联账户���提供该渠道不可用原因及合法导出／人工发送记录路径，不自动创建家长或把报告发给任意联系人。人工标记已发送是教师操作记录，不是系统验证送达或已读。

### 11.3 阅读链接：站内可打开、范围受限、限制明确

为已发布报告生成可打开的站内阅读入口，支持复制、查看有效期、停用��必要重新生成。个人链接只定位一名学生的一份已发布报告；班级链接只读取对应家长阅读版，不能访问校内核对表。

默认采用受限阅读：有效家长身份及对应关系满足要求后才能读取；已有登录状态可以直接打开，不每次重新选择孩子。原型用明确合成身份演示，不把“知道链接”当作已经核实家长身份。未登录、关系不符、过期、停用、版本撤回都有可操作且不泄漏正文的阅读状态。

链接不得在URL中携带整个报告JSON、姓名电话、成绩正文或可枚举学生编号，不用仅前端隐藏或不可猜测ID冒充生产级访问控制。报告受众在发布时确定，读取时仍核对当前访问资格；新加入班级的家长不自动得到过去所有报告。

若现v0仅有浏览器本地存储，可实现“当前浏览器演示链接＋合成家长阅读路由”，并明确跨浏览器／跨设备无共享数据的限制。不能将blob URL、data URL、虚构公网域名或只有教师当前标签可读的地址宣传为真实可分享服务。已有服务可支持共享合成数据时按其实际能力接入，但不未经授权新增付费服务或真实人员数据。

链接固定对应明确发布版本。新版本可以在有权家长的报告列表中显示，并提供清楚更新提示；原版本内容不原地改写。停用／过期必须使后续读取失败，刷新或回退不能恢复旧正文；仅隐藏“复制”按钮不算停用。

复制链接不记录已送达或已读。是否展示转发按钮不能阻止截图、复制文字或已经下载的文件；不提供“绝对禁止转发”“撤回后所有图片失效”等虚假保证。

## 12. 家长阅读与隐私投影

家长阅读页是结果页，不带教师侧栏、学生全班选择器、草稿记录、内部观察、内部请假原因、后台ID或教学设置。通过家长账户或受限链接进入时，得到相同版本的同一份受众内容。

父母能看共同教学介绍和学情总结，以及自己孩子的已发布个人结果。班级报告里的公开表扬按本次合法选择处理，不能借个人报告引用共同文本而带入其他孩子的困难、成绩或未交情况。

校内核对版仅有权教职工可用；普通家长请求、猜测路由或切换查询参数都不得取得它。先得到权限过滤后的报告投影再渲染，不能将完整班级或内部字段塞进浏览器数据后用CSS遮住。

模板不能扩大权限：恶意模板字段、手改报告ID、跨学校、换孩子、过期关系、未经核验接收人均应拒绝。原型的数据访问层也需覆盖这些负例；若没有真实后端授权，交付说明这是模拟边界，不能宣称可承载真实隐私数据的生产认证。

导出的静态文件不具备在线权限撤回能力。教师导出个人批量时应能识别应发给谁，但文件包本身不得提供给某个家长下载全班个人报告。

## 13. 保留当前已经确认的业务规则

1. 仍使用一份共享课堂事实：课次考勤、按日课堂评价、同源日卡／矩阵／学生抽屉；不因新增模板恢复逐课次独立打分。
2. 未出席范围禁课堂评价和课堂亮点；无效结果保留原有更正语义，不重新出现在报告。恢复出勤不自动复活旧等级或亮点。
3. 作业继续独立；必做、选做、免做、参与、提交、质量、独立数字分数和延期不混成一个状态。周反馈内“作业评价”不变回作业布置中心。
4. 课堂与作业各自使用实际绑定方案；第二阶段r5“一次采用、持续使用、精确重评”保留，不恢复方案更换历史或下期计划。
5. 普通批量直接执行、保护例外、可安全撤销；发布是对外动作，需要明确最终确认，不能因批量无确认而自动发送报告。
6. 个人课卡样式按同一属性最后成功设置生效，完整课表、课次卡和日卡一致；与报告模板主题独立，不因为改私人课卡颜色产生未发布报告变化。
7. 学生列表自定义分页和大班场景保留。统计、发布、重评、批量不隐式缩为屏幕可见子集。
8. 默认实时Asia/Shanghai，明确演示时钟与模拟数据分离；报告历史状态以当时快照时点表达，不因今天过了截止就把旧报告中的待处理改成未交。
9. 三视图公共导航、学生资料入口、规范分工、自定义显示、教务访问边界和真实课卡拖拽均不回退。

## 14. 保存、失败与实际实现要求

使用当前框架与共享模型。建议逻辑上区分：源记录／公共总结、发布准备选择、个人模板配置、不可变报告快照、图片产物、渠道交付及链接状态；这些是职责，不要求照名字创建服务或数据库表，不另建微服务和通用工作流引擎。

原型内要有真实可恢复的状态写入：文字编辑、模板、当前准备、发布记录、合成交付及链接状态刷新后仍能按现有能力恢复。失败提示以真实结果为准，不用延时成功替代保存。

发布提交应再次校验权限、源版本和受众。原子创建合法快照与本次发布关系；图片或模拟交付可独立失败。旧请求、快速切学生、双标签更新、模板更改、重复发布和重试不能串写、重复创建或覆盖新结果。

使用现有失败注入能力或隔离合成状态测试保存失败、导出失败、单个接收方失败、无监护关系、链接过期等。常用路径不要堆技术说明；具体错误必须有下一步，并保留教师输入。

模板渲染和出图使用同一份经受众过滤的内容；禁止模板从全站存储自主查学生。复杂文本、数学符号、中文、英文长单词和多段说明安全渲染，不执行正文中的HTML或脚本。

1. **共同内容与双报告**：周编辑填写教学介绍／学情总结 → 进入发布准备确认同源 → 改其中一类并返回核对 → 同时预览个人与班级 → 确认不是把整体评价写成每个学生的个体结论。
2. **模板可复用**：切换八套系统模板 → 复制一套 → 改模块排序、主题、标题与默认 → 换班换周使用 → 发布 → 修改或删除模板 → 核对历史呈现不变。
3. **大班实际出图**：72人、每页27 → 全部个人预览范围 → PNG及ZIP生成 → 打开首、中、末几份及重名学生文件 → 导出长校内总表并核对全部分段。
