# 课表改进：最终设计与实现总览

日期：2026-10-19。适用项目：wfb-v3，Next.js / React / TypeScript 交互原型。

本文汇总教师端、教务侧课表本轮所有改进的最终规则、实现位置与核验结果。早期文档中已经被后续调整替代的方案，不再作为现行交互依据；原阶段文档、测试和审查记录仍保留，供追溯。

## 1. 当前状态与交付范围

用户本次反馈：“好的，核验没发现问题，暂时可以接受”，并要求汇总为一份文档、提交和推送。记录为 **U-TT-20261019-01：当前原型人工核验暂时接受，授权提交推送**。这代表用户对当前版本的反馈，不扩展解释为所有异常路径、所有设备的逐项验收或生产系统上线许可。

本轮累计改进包括：

1. 教师端保留原设置，增加可选学科、行政班文字细分。
2. 教务侧增加个人显示样式、按教师设置及课卡各部位设置。
3. 两侧统一“课卡外观 / 对象名称 / 教师姓名 / 场所”的编辑结构。
4. 修复文字颜色与底色相互影响、切换部位后设置消失的问题。
5. 活动纳入整张课卡的设置对象，保留同名活动的原偏好。
6. 教务教学班、行政班视图显示教师；教师视图不重复姓名。
7. 增加课卡筛选，保留完整排课、校历及冲突判断。
8. 修正行政班归属汇总，增加确定冲突与待核对提示。
9. 增加教务活动目录、活动筛选、多教师活动摘要及完整明细。
10. 增加四位数学教师同一时段不同场所答疑的独立演示。

原左栏、顶部导航、作业管理、发布与采用业务、已有排课与样式数据保持。文档也说明教研组课表与这些能力的关系，但本轮不重做已提交的教研工作区。

## 3. 样式设置的统一结构

### 3.1 先选类别与对象，再选部位

教师侧类别为“整张课卡、学科文字、行政班文字”；教务侧另有“按教师”。

“整张课卡”的对象选择器把**教学对象**和**活动**分组显示。活动不再单独占用一个样式类别。即使教学对象与活动名称相同，选择值仍含类型，存储与显示不会混用。

| 部位 | 可设置内容 | 影响范围 |
| --- | --- | --- |
| 课卡外观 | 背景色、边框颜色、粗细、线型、圆角 | 整张课卡，不改各部分文字设置 |
| 对象名称 | 文字颜色、文字底色、字体、字重 | 教学对象或活动名称，不把文字底色当成整卡背景 |
| 教师姓名 | 文字颜色、文字底色、字体、字重 | 课卡中的教师姓名，不改任课关系 |
| 场所 | 文字颜色、文字底色、字体、字重 | 已排场所的文字，不改变实际地点 |

“场所”统一替代此前办公室／教室相关设置标签，继续读取原课次的 `room`，可表示教室、办公室等地点。没有新建与排课地点脱节的办公室字段。字体提供无衬线、衬线、等宽；字重提供常规、中粗、粗体。边框与圆角使用已有编辑器的受控取值。

### 3.2 学科与行政班的文字细分

只在能够可靠识别教学班组合名称时拆分显示片段：名称中的学科必须与结构化 `subject` 一致，并有登记教学班、已知班级或明确行政归属依据。保留原文字、顺序和分隔符，不为样式重新命名教学班。

行政班片段还须与登记的行政班名称一致。教学组别名不能仅因有行政归属就被当作行政班文字。自由名称、未知结构、活动名称保持整体显示，不强拆。

学科与行政班片段支持文字颜色、局部底色、字体、字重。未设属性继承外层名称样式；只覆盖对应片段，不染色整张卡、不影响分工标签或状态提示。

### 3.3 活动的范围

活动按**完整活动名称**保存样式，应用于当前浏览者相应模式下的同名活动；没有增加单次活动样式范围。教师选择活动后隐藏本任务／本班级／本课程范围，因为活动没有相应教学任务身份。

有课表活动但没有本人教学任务的教师仍可设置活动，不为了样式制造教学身份。活动不参与学科或行政班片段定制。

## 4. 继承、兼容与保存规则

### 4.1 教师：保留原范围与逐属性保存顺序

原 `TASK / CLASS / COURSE` 设置继续有效。每个属性独立比较**最后成功保存序号**，不把某一个范围固定为永久最高优先级。无序号的旧设置继续按原任务、班级、课程顺序回退，不伪造历史保存时间。

恢复单项会保留清除序号，防止其他范围旧值重新出现。新增姓名、场所、名称局部底色、边框等补充属性遵循同样的范围机制。恢复当前部位只处理该部位，其他部位和其他未涉及属性保留。

原名称颜色、字体、字重仍写原偏好键；原背景仍是整卡背景。没有把旧背景迁移成文字底色，也没有清空既有样式。教师按课次、按日、完整课表及任务名称使用共享解析；本人课卡不重复姓名，设置预览可展示姓名用于核对。

### 4.2 教务：独立对象优先于按教师默认

“按教师”以稳定 `teacherId` 为对象，设置该教师课程与活动的默认名称颜色、背景、字体及字重。教师候选来自当前完整课表范围，不因显示筛选隐藏而消失。

同一属性的组合规则为：**具体教学对象 / 活动设置 → 按教师默认 → 系统默认**。这是按类别的覆盖关系，不比较教师与对象的保存先后。清除对象属性会恢复继承教师默认；明确选择“无染色”仍是有效设置，不等同于清除。

学科与行政班片段保留自身覆盖。教师姓名和场所的文字设置、整卡边框等各有独立部位，不把“按教师”误写为每个姓名文字的设置。预览会说明哪些具体对象属性覆盖了教师默认。

### 4.3 身份隔离与旧键兼容

教务及名称片段/活动设置的键包含当前浏览者、`admin / teacher` 模式、部位和对象；教师教学任务设置保留原教师身份及范围键。兼任教务的教师可以分别拥有自己的教师样式和教务样式，不会写入当前被查看教师的私人偏好。

`CARD` 与 `ACTIVITY` 分开，新增部位使用各自前缀。下拉框用于区分类型的值不写入旧名称键。数据保存在原本机原型的偏好通道，未修改排课发布快照、任课关系、实际地点或作业业务。

### 4.4 颜色输入与跨部位保留

两次用户报告的问题分别是候选值互相覆盖，以及颜色还停留在预览状态时切换部位导致候选被清空。最终规则如下：

- 文字色、文字底色、整卡背景和边框色分别维护输入与候选；修改或清除某项不抹掉另一项。
- 取色器与完整六位 HEX 合法输入立即保存当前字段。
- 三位 HEX 输入时保留原文，失焦、回车或切部位时保存；不在输入第 3 位时自动展开，避免打断继续输入六位颜色。
- 非法或未完成输入不写入；保存失败保留输入并提示，可重试。
- 同一对象各部位的未完成输入分别保留；切到别的部位仍提示未保存输入。对象、范围或查看者改变时隔离草稿，防止串到其他对象。
- 保存某项只清除该项草稿；恢复当前部位只清除对应部位。

旧 `AUTO / NONE`、色板与 HEX 均继续支持。“自动配套”只有明确选择跟随文字/对象名称颜色时才联动；手动指定的底色独立于文字色。先组合最终名称颜色，再解析跟随色，避免使用旧颜色计算背景。

### 4.5 状态提示优先

停课、过去日期、锁定、草稿、个人调整、补课等保留原状态表达；适用状态的底色优先于普通自定义外观。冲突环、待核对文字、聚焦和合并标记保留。设置界面的预览与真实课卡共用解析规则。

## 5. 教务对象、教师姓名与行政班归属

| 左侧对象 | 汇总依据 | 课卡中的教师姓名 |
| --- | --- | --- |
| 教师 | 选中教师的学校发布 / 教师当前等原视角 | 不重复显示已选教师姓名 |
| 教学班 | 按教学班独立选择，精确匹配班名的学校课次 | 显示对应教师 |
| 行政班 | 教学班明确登记的行政归属及有效期 | 显示对应教师 |
| 活动 | 学校发布活动目录及日期投影 | 单人显示姓名；多人摘要显示人数，明细展示姓名 |

修复原教学班选择实际选中第一位教师的问题，使同一教师的不同教学班能独立选择。

行政班此前把关联教师整张课表聚合，混入了其他班课程。现在按明确行政归属汇总已配置教师目录中的学校课次；已登记教学班使用当前归属及有效期，未登记演示班使用明确的种子归属，不按名称拆字猜测。教师摘要从实际汇总课次推导。

页面标明“归属安排 · 只读”。行政归属不等于学生实际走班去向；不能把该视图宣称为完整学生个人课表。活动没有明确行政归属，不因某教师参加就混入行政班视图，使用活动入口查看。

## 6. 筛选只控制显示

周表前的紧凑工具区提供计数、样式入口及筛选。可用条件包括课程/活动类型、学科、教学班、活动名称、教师和关键词；实际选项随视角调整。关键词共用可见标签解析，匹配名称、分工、场所及教师；教务使用规范分工，不读取教师私人别名。

切换为活动会移除不适用的学科/教学班条件；切为课程会移除活动名条件，教师与关键词继续可用。活动视图的范围由左侧对象固定，清除筛选不会放出课程或其他选中活动之外的数据。切换对象重置局部筛选，换周可以保留条件；当前周没有的已选项有提示，无结果提供清除入口。

处理顺序为：**取得完整来源 → 校历与补课投影 → 冲突判断 → 对象范围 → 显示筛选 → 活动摘要归组**。各视角沿用自己的完整来源，不宣称一次检查覆盖全校所有数据。

筛选不会改变占位、复制/移动校验、发布或采用范围。被隐藏的课次仍然存在，不被当作新增空格。差异先按完整数据计算，再显示任一侧匹配的差异行，避免筛选制造伪新增/删除。

## 7. 同时段安排与冲突提示

同一格出现两张课卡不自动等于错误；要判断它们是否争用相同资源。判断按实际日期及节次时间重叠进行，不能只比较格子或班名。

| 情况 | 当前结果 |
| --- | --- |
| 同一教师或同一已知场所时间重叠 | 红色确定冲突，给出类型与原因 |
| 同一学生身份范围内，有效名单存在交集 | 红色学生冲突 |
| 有效名单无交集，或一侧明确为空 | 不报学生冲突 |
| 课程名单缺失，或来自不能直接关联的数据范围 | 黄色同时段安排“待核对”；已有确定资源冲突时避免同一对重复提示 |
| 活动与课程 / 活动同时出现 | 检查教师、场所；活动无学生名单，不据此制造学生名单待核对 |

教学任务使用逐日有效成员；教学目录使用有效教学分工及继承/子集名单。两套原型学生身份范围不按姓名、序号或旧群体标签强行合并。名单未就绪或加载失败视为未知，不拿种子替代来断言确定冲突。

同一源课次的重复投影去重；不同教师的本地课次 key 相同仍是不同记录。停课及已调走的来源课次不参与有效冲突，补课按实际目标日期参与。显示筛选和摘要合并都不会消除已知冲突。

课卡提供红色冲突或黄色待核对标识，表前有可折叠清单，包含日期、节次、对象、教师和原因。无问题时不占额外空间。该判断是当前完整来源范围内的展示核对，不是生产级全校排课审计。

## 8. 活动目录与多人摘要

### 8.1 活动可被直接查看

课表中心左侧增加“活动”，可查看全部或完整活动名称。目录来自学校发布模板，包含无教师账号的人员，以及本周没有安排但发布模板中仍存在的活动。周表按学校发布源投影，校历跨周来源也按该源解析；不以当前筛选后的卡片反推目录。

活动视图从完整学校课表判断冲突后再缩小显示范围。因此，被过滤掉的普通课程仍可能与可见活动发生教师或场所冲突。目录不重复展示可能忽略调休的本周计数；当前安排数由实际投影工具区计算。

### 8.2 归组规则

只在**教务只读活动视图**启用多人摘要。相同实际日期、相同节次、相同完整活动名称的多项可见安排显示为一张摘要卡。教师、教学班、行政班视图和编辑态仍使用原课卡。

- 教师数按身份去重，安排数保留原条数；同一教师有两项安排不能因摘要而丢失冲突。
- 已知场所只有一个时显示地点；多个时显示场所数；未排场所的安排单独计数。
- 同名归组只是显示方式，不表示多位教师共同参加同一场活动，也不合并存储记录。
- 只有一项时显示原单人课卡。
- 工具区分别显示“项安排”和“张课卡”，筛选后的数量不混淆。

点击摘要，弹窗展示各项原课卡，可继续进入完整详情，查看教师、场所、日期和节次。原备注、状态和样式继续保留。筛选至一人时自动回到单卡；清除恢复摘要。换周、改筛选或换对象后关闭失效摘要；来源更新使用当前明细，不恢复陈旧列表。

摘要使用完整活动名的公共设置，不随机继承第一位教师默认色；展开后每位教师的原卡继续采用各自适用样式。停课、过期、草稿、补课、锁定及冲突按原项计数，不把首条状态套给全组。

## 10. 与已有教研课表的关系

此前已移植的教研工作区以独立“教研课表”页签为入口，不常驻在所有组内标签上方。按日与按节视图共用固定周安排和日期活动；安排活动后按真实日期及时间归入相应日卡/节次，跨日、晚间和非标准时段有对应展示。组长维护固定周安排，日期活动不写成每周重复模板。

点击日卡可查看当日固定安排、任务、活动详情及参与人员，并读取已有日志；有效成员可记录已发生日期的教研日志，未来日期不能保存实际日志。任务、日期活动、日志与固定周模板是不同对象，调整模板不自动迁移或删除已有日期记录。

这些功能来自已提交的教研移植，不属于本次新增四教师活动摘要的数据源。教务活动目录当前读取学校发布模板，不能把它等同于全量教研活动目录，也不宣称组安排已自动同步每位成员个人课表。

旧 `research-group-timetable-design.md` 中“课表置于页签上方、只允许组长点日卡添加事项”等描述属于早期设计；页面位置与日卡日志交互按后续移植及当前实现执行。该历史文档不再覆盖本文说明的现行规则。

## 13. 原型边界

- 显示偏好、合成课表和教研内容仍使用原本机原型存储；没有把这些改进宣称为正式数据库、跨设备实时同步或服务端授权。
- 样式只改变显示，不更改对象名、教师、实际场所、学生名单、排课发布或作业。
- 行政班归属汇总不是学生走班去向全集；冲突检查只覆盖当前完整来源，不假装是全校排课引擎。
- 活动同名摘要不证明共同活动身份；未知或未排地点继续明确展示。
- 四教师演示不自动播种到原学校数据；普通页面仍可继续编辑原安排和显示偏好。
