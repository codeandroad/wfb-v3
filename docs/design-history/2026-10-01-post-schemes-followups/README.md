# 评价方案 r1 之后的补充修订（2026-10-01）

本文件汇总评价方案 r1 之后几轮对话中提出、但尚未写入任何设计文档的需求与实现。各条只替代与之直接冲突的早期要求；其余早期要求继续有效。

状态：已实现，待 Owner 核验。

## 1. 任务工作区：「课堂标准」入口与「查看本标准」

**需求**
- 教学任务页要能直接看到当前采用的是哪套课堂评价标准，并能快捷打开查看。（r1 当时把这项列为遗留项。）
- 入口要醒目，不能做成容易被忽略的淡色小字。

**实现**
- 任务页头部和周次选择器、任务切换框并排，有一个带边框的按钮：`课堂标准：<名称>　查看本标准`。
- 标准按「任务 + 当前周」解析，切换周次时跟着更新。
- 如果本周反馈还没固定标准，名称后面标「(默认)」，表示当前按教师的课堂默认标准显示；鼠标悬停时说明是否已固定。
- 点击后打开与设置页相同的只读查看弹窗（`ViewModal`），内容包括等级与判断说明、常规默认等级、家长呈现方式。
- 代码位置：`components/mt/task-workspace.tsx` 中的 `StandardLink`，依赖 `useClassroomStandard`。

## 2. 采用新评价方案可以立即生效

**需求**
- 设定新的课堂默认方案时，应允许立即生效，不能强制等到下一周。

**实现**
- 生效时间提供两个选项：「立即生效（本期起）」和「自下一周起」。默认选立即生效，不再要求本期没有任何评价。
- 立即生效时：
  - 本期还没录入课堂评价的任务，马上改用新方案；
  - 本期已经录入评价的任务，保留原来固定的标准，以免已录入的等级失效（历史保护规则沿用 r1）。
- 选中立即生效时，界面会就上述保留规则给出提示；设置页说明文字也已同步。成功后提示「已设为课堂默认（本期起）」。
- 代码位置：`components/mt/scheme-settings.tsx`（选项与提示）、`lib/mt/scheme-ops.ts`（生效逻辑）。

## 3. 我的课表：课卡详情弹窗改用「教学分工」

**需求**
- 课卡设计阶段已明确去掉「教学单元组」，改为「教学分工」，但「我的课表」点击课卡后的详情弹窗里仍显示「教学单元组」，需要更正。
- 弹窗标题下面那行「数学 · P1」是冗余信息，应删除。

**实现**
- 详情弹窗第一行改为「教学分工」，显示教务登记的正式分工名称，与课节编辑弹窗用同一个数据来源。没有分工的课显示「整科（无分工）」；校园活动类课次不显示这一行。
- 删掉标题下的科目 + 分工副标题，因为科目已经在标题「班级 • 科目」里，分工已单独成行。
- 网格课卡上的分工小标签（如「P1」）保持不变，按原课卡设计保留。
- 代码位置：`components/timetable/detail.tsx`。

## 4. 工作台：教学班名称可点击进入教学班页面

**需求**
- 工作台「本周教学任务」列表里的教学班名称，应和「我的教学」列表一样，点击后进入教学班页面。

**实现**
- 任务标题改成链接，指向 `/teaching/class/<classId>?task=<taskId>&week=<当前周>&from=workbench`，进入后定位到对应任务和周次。
- 教学班页面识别 `from=workbench`，返回按钮显示「返回工作台」，并回到 `/`；从「我的教学」进入时，返回行为不变。
- 右侧「准备发布 / 查看反馈」「开始填写 / 继续填写」按钮保持不变。
- 代码位置：`app/(app)/page.tsx`、`components/mt/class-detail.tsx`。

## 核验要点

1. 打开任意任务页，头部能看到「课堂标准：<名称>」按钮，点开能看到完整等级表；切换到尚未固定标准的周次时，显示「(默认)」。
2. 在设置页把另一方案设为课堂默认、选择立即生效：未评价的任务马上改用新方案，已评价的任务仍是原标准。
3. 在「我的课表」点开一节数学课：弹窗没有副标题，第一行是「教学分工」。
4. 在工作台点击教学班名称：进入教学班页面，周次和任务正确；点击「返回工作台」能回到工作台。
