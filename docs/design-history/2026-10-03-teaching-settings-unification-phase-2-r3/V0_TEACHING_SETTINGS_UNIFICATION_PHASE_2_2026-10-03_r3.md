## 1. 入口与设置工作区

### 1.1 三视图公共入口

“我的教学”的教学任务、课次安排、按日记录均提供同一个“教学设置”入口。它是工作区级能力，不属于某一子视图，不因无课、筛选无结果、学生列表分页或当前任务已发布而消失。

三种入口打开同一个设置功能、同一份本人配置；不是三个各自保存的组件。入口位置和视觉由v0统一设计，不要求固定右上角。不要新增侧栏一级模块或在每条任务行常驻一组设置控件。

打开和返回设置时，保留来源视图、实际任务、周期、筛选、搜索、合理页码和滚动。明确打开某一设置分类的上下文入口优先于上次访问分类。仅查看设置不建课堂记录、不布置作业、不换课表版本。

### 1.2 四类切换

一个工作区内提供以下分类切换，主体只呈现当前分类，不再把所有内容一次性纵向铺满：

| 分类 | 必需内容 |
|---|---|
| 评价方案 | 课堂默认、作业默认、系统方案、我的多套方案、查看／复制／编辑／分别采用 |
| 作业与列表 | 新作业默认N天、推荐及自定义每页人数 |
| 显示样式 | 本任务／本教学班／本课程的本人样式、文字与背景、继承和效果预览 |
| 常用内容 | 考勤原因、课堂亮点；系统项与个人项的使用、收藏、复制、编辑、停用 |

恢复默认和作用范围说明放在各自功能中按需访问，不另设空泛的“说明与恢复”页面。不新增批量行为配置器、任意自动化规则或复杂三级导航。

分类切换不丢失尚未保存的有效输入，也不把未提交输入假装已保存。沿用现有保存方式，普通切换不反复要求确认；真正保存失败／冲突时提供就近可恢复状态。

页面名称覆盖整个功能，应为“教学设置”；进入评价分类再表达“评价方案”。移除过长常驻规则和重复周次，必要的实际作用范围仍可直接识别。

## 2. 课堂评价与作业质量：分别采用，不另造两套系统

### 2.1 独立的两个默认

必须能够给同一教师同时配置，例如：

- 课堂评价默认：细化八级。
- 作业质量默认：文字四级。

选择课堂用途只改变课堂默认，选择作业用途只改变作业默认。两个用途允许引用同一份合法方案修订，但不能共用一个无法分别设置的selectedScheme状态，也不能“采用”一次就无提示改掉两者。

系统方案、个人方案可以复用同一方案库／编辑器，不要求人为复制两套独立库。方案允许适用课堂、作业或两者；选择时只提供当前用途合法方案。通用方案可同时使用；教师需要不同释义时，可复制为自己的方案单独编辑。

保留系统默认和多个系统预设、多个个人方案、保存备用、分别设默认、复制后独立修改、停用和历史引用。教师不修改系统原项；保存方案不自动评分，也不自动切换另一个用途。

基础四级保持A＝优秀、B＝良好、C＝合格、D＝待改进。个别个人方案有自定语义时按其真实释义显示。出勤、未提交、不适用、免做、待处理仍是系统状态，不伪装成可编辑等级。

### 2.2 默认与实际采用必须分开

以下是逻辑职责，不要求按名称新建数据库表或服务：

| 对象 | 作用范围 |
|---|---|
| 教师课堂默认 | 本人各任务后续符合生效条件的课堂周期 |
| 教师作业默认 | 本人后续新布置作业的候选方案 |
| 当前教学任务的课堂覆盖 | 仅该真实任务按生效边界使用，不改兄弟任务 |
| 当前教学任务的新作业默认覆盖 | 仅该任务以后新布置的作业，不改已布置作业 |
| 已采用的课堂方案修订 | 一个真实任务／责任范围＋一个学校反馈周期 |
| 已采用的作业方案修订 | 每一份实际作业，全部适用学生共用其固定修订 |

本轮新增／完善的是任务范围快捷采用；不顺带增加按学生、按单节或每个日卡独立切换方案。

候选优先使用该用途的明确任务覆盖，否则使用当时有效的教师默认，再使用系统默认。已经固定采用的对象先使用自己的绑定，不从最新偏好反推。

当前默认、后续默认、当前周期实际采用、当前作业实际采用不能用同一个标签或同一个变量相互替代。

### 2.3 快捷选择放到实际工作上下文

允许从周反馈工作区和日卡了解并快捷采用方案，不必每次回设置中心。但不把整套方案管理铺到每个学生行、课次卡片或任务列表摘要。

| 当前上下文 | 应准确表达的内容与作用 |
|---|---|
| 课堂矩阵／日记录 | “课堂评价：实际方案名”，可查看释义，并对当前任务进行合法的方案采用 |
| 当前任务的双用途摘要 | 同时可见／可展开课堂和作业两个用途；作业尚仅是未来默认时必须标“新作业默认：方案名” |
| 正在评阅某一份作业 | “本作业质量：实际方案名”，使用该作业绑定修订；不冒称全周所有作业都是此标准 |
| 同时查看多份已采用不同方案的作业 | 按作业说明实际标准，或清楚概括“作业质量：按各作业方案”；不能取第一份方案覆盖其余 |
| 方案选择下拉 | 选择整个标准的候选，不能直接给学生赋值 |
| 批量等级下拉 | 在实际标准内部选择本次准备写入的等级，不能因此换标准 |

统一把含糊“课堂标准”改为明确用途。日卡主要编辑课堂，因此课堂实际方案应明确；作业默认可在同一个紧凑方案入口中查改，不强迫日卡常驻两套长说明。教学任务列表不再新增每行双方案大摘要或下拉控件。

### 2.4 快捷采用的生效与保护

**更方便的选择入口，不授权把已有A／B等结果用新标准悄悄重新解释。**

课堂规则：

1. 当前真实任务周期尚未实际评价、评价确认、明确锁定采用，也没有包含该维度的发布时，可以明确立即采用所选方案。页面浏览和默认候选显示本身不算正式评分。
2. 该任务周期已经采用锁定／使用／发布后，普通快捷选择用于该任务后续合适反馈周期；当前周期继续用原修订。说明“本期仍用X，下期起用Y”，不能只提示保存成功却把下拉显示成当前已用Y。
3. “也用于后续周期”或“该任务后续默认”的意图应明确，不因仅查看候选而扩大生效范围。任务覆盖不改教师其他任务或全局默认。
4. 教师全局课堂默认继续遵守既有按实际学校反馈周期的生效规则；不要用当前浏览的历史周或任意ISO周号决定生效。
5. 本轮不增加强制切换已使用周期、按字母／档位自动映射、批量重评、清空旧记录后换标准或复杂审批。确需历史更正沿用已有明确流程，不由这次快捷选择附带执行。
6. 日记录、矩阵、学生抽屉和课堂批量使用同一个当前周期修订。出勤单独操作不能被拿来任意改换评价标准。

作业规则：

1. 新作业在布置前可以明确选定合法作业方案，首次成功布置时固定实际修订。
2. 修改教师作业默认或当前任务新作业默认，只用于之后新布置的作业。已经布置，即使尚未批改，也保持原方案；跨周批改不重绑。
3. 已布置作业的实际方案可直接查看；选择“用于后续新作业”可以修改相应默认，但不能伪装成已更换当前这份作业。不要做一个表面能选、实际上无声回滚或假生效的控件。
4. 同一任务可有旧作业用基础四级、新作业用文字四级；每份分别显示、录入与发布。单生作业弹窗也是逐份处理。

所有方案选择／保存／恢复默认都不改变已经保存的等级原意或已发布快照。同一字母不同方案不视为同一等级；方案内容实质修改保存新修订，引用旧修订的结果仍可阅读；不因为修订被停用就无法解释旧成绩。

从设置／快捷选择返回时正确恢复对象，失败保留原绑定与输入；迟到响应不能覆盖新任务。已选的批量候选按实际方案修订校验，方案不兼容时不按同名等级自动沿用。

## 3. 本人课卡样式：文字、分工和背景完整贯通

### 3.1 不只给标题文字上色

在“显示样式”中实际支持：

- 教学对象标题／识别文字的样式；
- 规范教学分工及当前实际显示的自定义分工文字／标签的协调样式；
- **课卡背景样式的选择与恢复**；不能只有标题色或一条色线，背景仍完全不可配置；
- 已有字重与少量可用内置字体风格；
- 当前对象真实效果预览，以及恢复该层默认／继承。

可用一组预设同时提供协调的文字、分工、背景，也可提供安全的独立背景选择。具体配色和视觉由v0决定，但教师必须能明确改变并看到课卡背景；不能只写“支持背景”而所有课卡依旧白色。

背景与文字不允许任意CSS、脚本、外部字体URL、字体上传。可读性不满足时给出合适的可用组合或明确提示，不让待办／锁定／冲突文字被隐藏。不要承诺未经测量的标准合规。

### 3.2 继承和身份

继续按：**当前学校与教师 → 具体教学任务 ＞ 教学班 ＞ 真实关联课程 ＞ 系统默认**。

按属性逐项解析。设置任务背景不应顺便清掉班级字色；清除任务背景覆盖后恢复上级背景。明确“无染色／透明”与“继承”不能是同一个值。恢复本任务默认只清该任务覆盖，不删班级、课程或其他任务配置。

没有规范分工的整科任务不补造分工标签；有个人自定义分工时替换显示但身份不变，样式仍按真实任务匹配。隐藏课程名称不影响课程级样式继承。

修复当前“高一2班·数学(1)/(2)”这类无法识别目标的选择项，优先用真实班名＋规范分工P1／S1；必要时同时给出个人显示名。不能将内部ID或数组序号作为常规用户辨识方式。

### 3.3 必须应用的四处

同一份本人偏好、同一解析结果，必须覆盖：

1. 我的教学：教学任务的身份文字和分工标识。
2. 我的教学：课次安排课卡。
3. 我的教学：按日记录合并日卡。
4. **完整“我的课表”中的本人课卡**，包括其正常查看和个人调整时的同一对象；不能漏掉此入口。

任务列表不必为此整行铺色；课卡背景配置重点在真正的课卡／日卡上体现。不要把“同步”解释为所有容器像素完全一致。

合并卡采用该真实任务样式，不取第一节的临时显示文本作为身份，也不引入逐课次独立配色层。同一天原课次教室不同、个人课次备注不同，不改变任务配色。

设置保存后当前和其他本人入口更新；刷新、返回和有效缓存恢复后仍一致，不需要重新导入／采用课表。

### 3.4 严格区分个人辨识与业务状态

本轮个人样式不自动改“学校课表”“差异对比”的正式语义配色、教务管理视图、其他教师、家长周反馈、已生成图片和发布快照。差异仍基于真实课表字段，不把个人配色算成排课差异。

无论选何种对象颜色，待评价、保存失败、免做、锁定、冲突、未来、停课、合并N节、键盘焦点、选中和拖拽反馈都要可辨认。不能绿班级就代表完成、红班级就代表错误。

个人显示写入只写偏好，不产生排课草稿、个人或学校课表新版本、采用申请、更新通知，也不修改教学责任、名单、学生结果和发布状态。已有“已发布且有未发布内容”只由真实发布内容差异决定，不受配色变化影响。

真实课卡拖拽必须保持稳定，不能用弹窗调节星期／节次来替代；不因为增加样式事件而拦截拖拽、误触详情或破坏空格新增。

## 4. 日卡两类快捷动作：点击执行，不再确认弹窗

### 4.1 明确动作

| 动作 | 实际写入 | 不得附带 |
|---|---|---|
| 确认本日常规 | 对本日已发生、适用、尚待处理且明确常规的目标，补正常出勤和本任务本周期常规默认评价；按字段保护已填值 | 不改作业、评语、亮点，不发布；不覆盖手工等级或缺席事实 |
| 出勤快速处理 | 仅补尚未处理的已发生课次考勤：已获批准且准确覆盖的请假读取原来源，其余合法常规候选按教师本次明确操作记正常 | 不填写课堂等级，不生成请假批准，不改作业或发布 |

两项普通动作必须从原位页面直接执行。移除现有预确认弹窗，不保留隐藏的“下一步确认”，不做0人写入预览窗口。简短必要范围和实际默认等级在点击前可辨识；不铺一大段技术规则。

范围维持日卡本日全部合法适用学生，不受搜索、“只看待处理”或当前页偷偷限制；若已有明确选定子集模式，必须明示并只按该集合执行。复用到其他入口时，保留该入口原本明确的对象／日期范围，不扩成全周或全校。

### 4.2 零候选与默认缺失

如果没有实际需补的字段，原位显示“本日无待处理项”或禁用对应动作，不打开“确认写入0条学生—教学日”的弹窗，不创建空批次、空评价或假更新。

全部出勤已处理不一定表示评价也已处理，两项候选分别计算。确认未出席且评价不适用是已处理的排除状态，不应再次显示“整日跳过，需要人工核对”，除非确有未解决冲突。

本期实际方案没有常规默认等级时，可以在日记录中明确选择一次候选；未选时出勤快速处理仍可用。常规联合操作若无法明确评价值，原位说明缺哪个值，不猜A／A+，也不悄悄退化为只写一半却报完整成功。

### 4.3 保留资格和安全撤销

请假、缺勤、在他班的未参加范围不能写课堂等级／课堂亮点。已有错误有效值应按统一资格规则退出、必要历史保留；恢复出席不自动复活旧值。

同日部分出席仅评价实际参加范围；未来课次不预先确认。上午阶段记录、下午沿用既有值完成覆盖的规则保持，不因为去确认弹窗就把时间流逝当教师确认。

手工B、明确留空／不评价、必要考勤来源、锁定和冲突继续保护。点击表示本次常规登记意图；页面打开、查询、选候选、换页不自动登记。

提交后显示真实成功／部分失败结果及安全撤销，详细保留原因可按需查看。无权限、未知来源和版本变化不能伪装普通跳过成功。

撤销只回撤本次仍可安全回撤的字段。批量正常＋A之后某学生被手改为B，撤销不能抹掉B，也不能撤掉它所依赖的已确认出席、留下无依据有效B；无法安全拆开的关联变更保留并短说明。其他可撤目标正常撤回。

双击和重试幂等，执行时固定上下文、范围、值和版本；迟到保存不能复活已失效评价或覆盖新任务。作业第二阶段r2三类直接批量继续无需普通确认弹窗，不回退。

## 5. 待评价、作业摘要与文本可读性

周矩阵“作业”列中的“待评价N”“到期待核对N”“评改”等是可操作待办，必须在正常缩放、实际主题和本人配色下清楚可读。不能使用接近底色的浅文字，也不能把可操作待评做得像禁用。

已核对、尚未截止、已确认未交、免做和待评价保持不同业务含义；用明确文字辅助，不仅依赖色相。完成状态可较弱，但不能弱到看不清。具体颜色、字重、标签样式由v0设计。

与日卡、侧栏作业、学生弹窗使用一致的结果语义。课堂待处理与作业待处理不相加、不互相改名，计划未来作业不自动算未交。

修复标签乱码的实际来源，不能删掉整个作业提示来掩盖。移除常规页面中的DEMO_STU、TASK等内部键，学生有正式学号则按真实资料显示，无学号则不占位冒充。恢复查看必要完整资料的能力。

继续保留周矩阵独立“亮点”“作业”列；作业入口只打开该学生、该任务、相关周期的作业评改，不回到全班或混入课堂表单。缺席禁课堂亮点规则不能从新列绕过。

## 6. 自定义每页人数：本轮必须交付

### 6.1 可输入，不限于预设档位

提供常用推荐值20／30／50／100，并**必须支持自定义整数每页人数**。本原型输入保护范围为1—200；例如27、35、75可保存并实际生效，不能仅加入30档就声称完成“自定义”。

空值输入过程不当作0；负数、小数、0、超过上限、非数值应原位校验，不悄悄回落20或自动四舍五入。默认未设置时20；已有合法个人值保留。用“每页N人”表达，不暴露内部pageSize键。

在“作业与列表”维护本人默认；列表的每页数量选择复用同一偏好，不另存彼此冲突的默认。不同列表页码可以独立。生效切换前妥善处理正在输入和保存的字段，不能卸载即丢失。

返回第1页或合理校正页码后，当前选择数量保持。总人数少于设定值时显示全部实际对象，不凑空行；未知总数／读取失败不当0人。

### 6.2 分页不改变业务范围

适用于周矩阵、作业全班评阅、日记录中需要分页的学生列表。搜索和结果统计查询当前合法完整集合，不能只搜当前页。

默认批量对象仍为整份作业／相应课堂动作完整范围的符合目标；明确勾选才缩小。跨页选中总数持续可见，按稳定学生ID绑定输入和选择；切作业／任务／身份清理不适用选择，不留下隐形目标。

修改每页数量不清掉同一任务下有效的显式选择，不使按钮范围变成新页内人数。选择本页与选择整个筛选结果语义清楚；清空后恢复全范围也要明确。

日评价进度、作业核对进度、名单人数和周反馈受众不能用当前页长度计算。周预览／发布和全范围导出不因页面只有27人就只包含27人。个体弹窗返回恢复原上下文。
