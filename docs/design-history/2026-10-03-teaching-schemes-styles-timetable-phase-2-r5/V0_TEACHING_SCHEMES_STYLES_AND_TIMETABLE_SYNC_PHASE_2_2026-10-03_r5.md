## 1. 评价方案：本次采用后持续使用

### 1.1 任务方案界面简化

当前教学任务只需分别管理“课堂评价方案”和“新作业默认评价方案”，可以相同，也可以不同。保留当前有效值、方案选择、简短采用动作、必要释义；现有系统／我的多套方案库继续使用。

移除“单独设置后续默认”“下期起采用”“第几周起采用”“方案更换历史”“评价代次”等专门操作或技术显示。不是仅折叠旧内容，也不是改名后保留另一套未来计划。

课堂方案明确采用后，同时完成：

1. 当前选中教学任务、所选反馈周期的整个可编辑工作版本采用该方案。
2. 该任务的持续课堂方案改为这一次采用的方案；此后新周期持续使用，直到教师再手动更改。
3. 日卡、周矩阵、学生抽屉、快捷编辑、批量按钮及相关进度立即读取相同的新方案。

不需要另勾“同时用于以后”，也不要求下周再次采用。已经预建但尚无实际评价／评价确认的后续空周期，不能被初始化时缓存的旧方案锁住；后续使用时读取最新持续方案。

“以后持续使用”不等于无差别改写其他已有结果：已经实际填写的其他周期保留其实际绑定和成绩。教师明确选择某个历史可编辑周期进行采用时，只重评那个周期，同时更新该任务今后使用的方案；不自动清理中间所有周期。

任务明确采用不改变其他任务、其他教师或教师全局默认。未单独设置任务的默认来源沿用现有教师／系统选择；教师全局默认变更也不静默重评已有记录。若保留“使用教师默认”动作，把当下教师默认作为采用候选，通过同一操作完成，不另建下期分支。

### 1.2 一次采用，一次必要确认

选择候选或查看释义不写学生结果。明确采用时：没有旧评价及评价确认，无需空的确认窗；存在需要重置的结果，做一次简短确认，显示实际任务、周期、方案及影响数量，取消不改变任何数据。

可用语义：“改用细化八级？本任务第5周的课堂等级将重置，考勤等记录保留；以后继续使用此方案。”不要要求长理由或逐学生确认，不叠多层完整弹窗。

目标周期和任务持续方案都已是所选方案时，不重置、不重复提交。若本周期已用该方案、但任务持续方案不同，只更新持续选择，不清空本周期相同方案的成绩。

### 1.3 重置边界保持精确

| 更换对象 | 重置内容 | 保留内容 |
|---|---|---|
| 课堂方案 | 当前真实任务＋选中周期的课堂等级及对应评价确认／完成覆盖 | 每节考勤及确认、原因及批准来源、名单、课次、全部作业事实、合法亮点、观察／内部备注、日小结、公共总结、个体评语、其他周期和已发布快照 |
| 具体一份作业的质量方案 | 该份作业全部适用结果中的质量等级及质量确认 | 作业ID、原布置时间、题目要求、名单、提交／时效、必做／选做／免做、未参与、截止／延期、独立原始数字分数（含0）、备注、其他作业及发布快照 |
| 新作业默认方案 | 不重置已有作业 | 以后新布置的作业采用新默认；已有作业，包括尚未批改者，保留自己的实际方案 |

单份作业立即重评能力继续保留，入口属于该份作业的管理／评价上下文；不放入“仅评当前学生作业”的弹窗执行全班重置。改一份作业不附带修改任务新作业默认，除非另有明确的默认设置动作。

课堂重置作用于该任务整个所选周期，不能被日卡来源日期、搜索、分页、勾选或仅看待处理缩小。手工等级也在已明确确认的重评范围内；普通批量保护规则不能阻止这次主动重评。

重置后，合法需评价者回到待评价；未出席者仍不适用，未来／停课仍不提前确认。默认等级仅为候选，不自动写满A或第一项。只批量评价作业仍要求真实提交；修改质量方案不制造提交事实。

### 1.4 不再保存专门切换历史，但不能破坏旧发布

停止生成、读取及维护方案切换时间线、旧工作等级切换副本或供教师浏览的专门更换档案。已废弃的专门存储只做定点清理，不清其他模块审计、课堂更正历史、方案库或整库数据。

保留仍在使用的记录绑定与必要等级释义，确保其他周期／已有作业不会被改方案名称就重新解释。已发布反馈、图片及其实际内容按原快照保留；重新评价只改变合法工作版本，之后仍由教师明确发布新结果。

最小内部并发版本／请求标识仅用于防止旧保存覆盖与重试，不变成新的教师���能，也不借此继续保存已删除的旧工作等级。成功后换回旧方案，不能复活旧成绩。

采用新方案、精确重置、更新任务持续选择必须同成同败。失败保留原绑定、原有效结果与原持续选择；重试或双击不得再清一次新成绩。旧自动保存、旧下拉、旧批量及旧撤销不得跨方案变化写回旧结果。普通批量撤销继续保护之后的手工更正及其出勤／提交依据。

取消旧“未来采用计划”的读取和执行逻辑；遗留计划不能在切周、刷新或到期后偷偷生效。升级本身不执行重评、不提前执行旧计划；保留现有有效记录，新的持续行为由这次及之后教师明确采用的选择驱动。

## 2. 样式：同一属性，最后设置生效

### 2.1 三种范围不是永久优先级

保留短名称选择及“本任务／本班级／本课程”。本班级指教学班。本次保存的作用范围分别是本人一个实际任务、本人该教学班全部实际任务、本人实际关联该课程的任务；严格按真实ID关系匹配，不按名称前缀、P1文字、课程名或当前屏幕数组索引匹配。

对于某个实际任务的某个属性，从适用于它的本人设置中使用最后成功保存的值。不再永远优先取任务层，也不允许用整个设置对象的更新时间决定所有属性。

学校＋教师隔离保持；某班设置不影响同名异班／其他课程／其他教师。班级或课程的已存设置可作用于之后新加入其真实范围的本人任务；无任何个人设置时才用系统默认，不强迫逐任务初始化配色。

### 2.2 按属性更新，禁止整包旧值回写

属性分别处理：主题色、背景模式及明确背景值、字重、已有内置字体风格。主题色统一协调名称与规范／自定义分工；不恢复独立标签色。

背景模式保留跟随有效主题色、明确颜色、无染色／系统默认等已经必要的能力。跟随模式依据最终主题色派生；明确背景不因只改主题色而变更。

以下顺序是必验行为，不是指定生产色板：

| 连续操作 | P1结果 | S1结果 |
|---|---|---|
| 单独设P1蓝底、S1绿底 | 蓝底 | 绿底 |
| 在本班级保存米黄色背景 | 米黄底 | 米黄底 |
| 再单独设P1紫底 | 紫底 | 米黄底 |
| 在本班级只保存新主题色 | 名称／分工采用新主题色，紫底保留 | 名称／分工采用新主题色，米黄底保留 |
| 再明确保存班级米黄背景，即使班级字段原值还是米黄 | 米黄底 | 米黄底 |

最后一项很重要：不能只比较班级自己保存的旧值就禁用保存，忽略下属任务后来已有不同设置。明确再次应用同一班级值也能统一该属性；已经完全一致时可以无变更成功，但不制造业务副作用。

保存某属性不触碰未修改属性。改变字重不能使旧颜色成为最新值；整表提交不能夹带其他未修改字段重新覆盖。任务／班级／课程范围的选择、页面打开和预览本身不是设置操作。

### 2.3 保存、预览和恢复要有同一语义

颜色预设、取色器、HEX输入均继续可用，支持#RRGGBB及#RGB规范化。合法候选即时预览，尚未保存时不标成已生效；成功后预览与各实际视图一致。非法／半输入保留原有效颜色及可恢复输入，不保存随机值。

班级预览应让教师核对全部本人分工的结果，不固定拿P1代表全班。未保存候选可以预览将如何影响P1／S1，成功后显示实际效果；不再铺“任务独立覆盖无法改变”等旧规则说明。

普通班级保存就是实际应用，不需要第二个“统一使用本班样式”按钮才能生效。移除这个旧必经步骤；确实保留“一次应用全部样式”的快捷操作时，仅表示同时应用所有明确属性，不作为普通保存的补丁。

恢复默认也应按明确范围／属性执行，不能仅删除班级新值后让更早的任务旧值无声复活。可使用“恢复此属性默认”等明确动作；它作为该属性最新明确选择处理，其他属性保留。后台不必保留已被替代的个人样式历史；现有安全撤销只恢复本次仍可安全恢复的值，不覆盖之后更新。

逻辑上可用每个范围每个属性的当前值＋内部单调提交序号，或等价简单实现。无需事件平台或历史界面。不要使用演示时钟、可回拨系统时间、响应到达顺序或打开页面时间确定先后。并发旧响应不得压过更新操作；失败保存不取得优先权。

### 2.4 当前偏好定点升级

本轮采用新规则，不丢弃所有已有偏好。旧属性有可靠保存顺序时保留；没有顺序时可一次性保留原实际显示作为初始状态，不伪造“最后保存时间”。迁入后任何新的明确保存必须按新规则生效，旧层级解析、旧标签色缓存不能继续盖回结果。

只调整相关偏好与消费者，不清空课表、学生、作业、反馈或Owner手工测试成果。简短说明作用范围即可，不把内部来源、提交序号和覆盖状态堆成新控制面板。

## 3. 完整我的课表：接通同一份样式和真实对象

### 3.1 四处共用最终个人样式

相同学校、当前实际教师和真实教学任务，使用同一偏好读取与最终样式解析，贯通：教学任务识别、课次安排、合并日卡、完整“我的课表”的个人课卡。包含有权查看的过去／锁定课卡、正常浏览、允许编辑的状态及拖拽预览。

不复制颜色到每份导入文件、学校课表版本或逐课次快照；不要求重新导入、重新采用学校课表或刷新整站才能生效。返回、刷新、新标签及当前工程支持的偏好持久化行为一致。

优先核查真实路径：完整课表是否缺任务关联、是否使用另一份账号／教师标识、是否读取旧快照颜色、是否缓存未失效、是否被过去／锁定／编辑状态CSS覆盖。依据实际代码报告根因，不凭截图指定其中之一。

完整课表通过真实关联解析任务、班级、课程；个人别名、规范分工与自定义显示分工不能作为样式主键。未解析导入课次不得按同名猜任务；保留原有待匹配处理，并在修复报告指出实际缺失关系，不能伪造全部可匹配。

### 3.2 状态与颜色独立

不能调整排课，不代表不能显示个人配色。过去或带锁课卡不得因为disabled／opacity／固定中性色把有效主题和背景全部抹掉。锁定、修改、冲突、停课、调休、选择与拖拽状态仍须独立清楚，不改变真实操作资格。

默认对象预设应核对并尽量避开当前完整课表已有修改态、校历、调休等语义色。自定义颜色接近状态色时仍以独立文字／图标等辨识状态。HEX原值可核对，可读性修正不得偷偷更改保存值。

保持主题色与规范／自定义分工一致，不向无分工任务添加伪标签。日卡按真实任务使用主题，不随第一节教室、临时显示名或日期改变身份。

修改偏好不产生排课草稿／版本／申请／通知，不改变反馈“有未发布内容”，不改学校正式课表、其他教师、家长报告或已发布图片。保留原型稳定拖拽，不以新增星期／节次下拉替代移动。

## 4. 一并核对简版与完整表的课次差异

### 4.1 问题依据，不先猜哪张图正确

当前参考图中，课次安排和日卡显示5个原始课次，10/1、10/2为无课，未见周末日期；完整表同周还显示10/1两节S1、10/2两节数学、10/3一节数学。完整表另有“数学答疑”等活动，不应机械要求活动也成为课堂评价任务。

先核对是否同一学校、同一实际教师、同一周、同一已采用个人课表及其有效区间、同一校历修订和同一筛选。分别记录实际来源、原始课次、有效／取消／调休结果、筛选与投影，给出有依据的差异原因。不要把一张截图认定为绝对正确���也不要只把计数改成一样。

### 4.2 共用实际有效课次，再按用途投影

普通教师当前使用的有效个人课表、实际生效区间、已确认调整、学校课节时间及校历共同确定课次。未应用个人草稿不混入正式教学记录；学校新发布但教师尚未采用的版本，也不能被简版静默采用以“修复一致”。

完整表可以含非教学活动与取消安排参考；课次安排取本人真实教学任务的有效课次；日卡按同一实际日期＋同一真实教学任务／分工＋本人责任范围聚合，保留原课次引用，仍按课次记录考勤、按日评价。位置、时间、教室及合法自定义显示来自相同事实。

日期已过、记录完成或属于周末不是删除课次的理由。所选周覆盖的周六／周日存在有效课时，必须可见／可达并正确计数，不得固定截成周一至周五。不要通过过滤所有未来或过期课来伪装实时时钟已修好。

校历真实取消时，完整表可保留参考但必须明确停课／调休；简版可只展示有效课次，但应能辨识因校历取消，不把取消与本来无安排、读取失败混为一谈。调休按实际授课日期归属，保留来源联系，不能在原日期和实际日期重复制造课堂。以系统校历为依据，不从公共节日常识推断停课。

不要通过删除全部日期后的课堂记录消除差异。已有实际事实与新课表不一致时，沿现有更正／失效处理，保留必要记录；修复读取不能自动填考勤、打分、撤回或发布。

### 4.3 日期与计数

继续默认实时 `Asia/Shanghai`，显式演示时钟与模拟数据场景分离。恢复实时、窗口聚焦、休眠唤醒及跨课节边界更新状态，不重建课表或自动跳走所选周。图片日期只用于复现，不写成正常模式常量。

计数分别为原始教学课次数和合并日卡数，不能把卡数称为课次。任务人数、反馈资格和完成度读取一致的真实名单与记录；时间经过只改变阶段，不自动产生评价完成。

用两个受控场景测试：一个没有取消且包含周末／同日多节／活动，另一个确有停课和跨周调休。第一个必须在三处能核对全部有效教学课；第二个在排除教学计数时给出真实来源。测试场景不得覆盖Owner当前数据。

## 5. 保留现有正确功能与本轮边界

三视图公共控件与教学设置入口保持稳定，设置继续按评价方案／作业与列表／显示样式／常用内容分类。恢复原视图、周期、搜索、分页和滚动，不把普通教师导航到课表中心。

日卡两类快捷操作及作业三类普通批量仍点击即执行、零对象不弹窗、结果清楚且可安全撤销。普通批量不覆盖已有例外，方案重评之后能补新评价；课堂批量不联动作业。

缺席／请假／在他班的相应未参加课堂范围仍禁课堂等级和课堂亮点，同日部分参加按真实参与部分处理；这不影响真实提交作业的独立评价。日卡、矩阵和学生抽屉继续共用课堂事实；单课次观察保持参考职责。

保留学生资料、周矩阵亮点列、仅当前学生的作业评改、常用原因与亮点库、N天期限、分页自定义1—200及大班场景。批量、方案重置、统计和发布不缩成当前页；作业跨周同一身份，免做／未参与／未登记／未交／待评仍分开。

### 四条连续操作证据

1. **方案持续生效**：已有成绩的第5周采用八级 → 核对只重置对应课堂等级 → 新方案批量 → 单人更正 → 切第6／7周 → 刷新 → 核对旧发布未变、无下期计划或切换历史功能。
2. **后设样式生效**：任务P1／S1分别设置背景 → 班级保存另一背景 → 任务P1再次修改 → 班级只改主题 → 再次应用原班级背景 → 依次打开日卡、课次安排、完整我的课表 → 刷新核对。
3. **课次一致**：同一已采用版本下逐条比较三视图 → 核对周末与同日多节 → 有校历取消／跨周调休的隔离场景 → 检查活动与课堂不同口径 → 恢复实时且课次不被删掉。
4. **完整表状态**：合法过去锁定课与可调整课同时展示个人配色 → 允许范围真实拖拽 → 不应用时不改变正式教学课次 → 核对学校版本、状态标识及私人配色无业务写入副作用。
