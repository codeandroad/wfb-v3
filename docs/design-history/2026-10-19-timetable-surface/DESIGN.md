# 课卡外观与文字样式分离（2026-10-19）

## 用户要求与设计

Owner反馈：整张课卡中只有对象样式可设置整卡背景，而教师姓名、办公室／教室只设置文字，造成设置页面不统一；要求将背景、边框等独立到一个页签。

保留教务“显示样式 → 整张课卡”的对象选择，改为四个部位：

| 页签 | 设置范围 |
| --- | --- |
| 课卡外观 | 整卡背景、边框颜色、粗细（0–3px）、线型（实线/虚线/点线）、圆角（0/4/6/10/14px） |
| 对象名称 | 名称文字颜色、局部文字底色、字重、字体 |
| 教师姓名 | 姓名文字颜色、局部文字底色、字重、字体 |
| 办公室／教室 | 实际排课地点的文字颜色、局部文字底色、字重、字体 |

三个文字部位共用相同控件结构；整卡外观不混入文字控制。既有完整对象名称、按教师、学科和行政班片段的作用范围保留；按教师仍可设置该教师的基础配色，具体课卡属性优先。

## 兼容、恢复与状态

原对象背景继续表示整卡背景，不把旧颜色变成文字高亮。对象文字底色为新增偏好，默认没有设置。清除当前文字部位不清整卡背景和边框；恢复课卡外观不清名称、教师、地点的文字设置。原自动配套背景继续随有效标题颜色计算，设置输入与真实课卡使用相同有效颜色。

未设置边框或圆角时沿用原系统外观。普通课卡应用设置；过去锁定、停课、草稿、个人调整、补课等状态仍使用原状态外观，冲突与待核对提示继续显示。预览标明“常规课卡预览”。活动保留原活动课卡设置。

设置仅影响当前查看者的教务显示，按完整教学对象名称保存；不修改教师、地点、排课版本、校历或业务记录。当前是本机持久化原型，未新增生产后端。设计已按明确指令实施，人工视觉与交互核验PENDING。
