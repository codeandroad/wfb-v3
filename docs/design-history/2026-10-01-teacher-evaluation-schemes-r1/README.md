## 方案字段

名称、可选说明、2–10 档有序等级（标识、简短释义、可选判断说明）、可选常规默认等级、家长呈现方式（等级＋释义 / 仅文字释义）。等级以稳定 id 存储，标识或释义修改不影响已存值的解析。

## 默认与实际采用

- **默认**：本人按用途（课堂 / 作业）选择的方案修订，作用于本人全部有权任务，不受筛选、搜索和浏览周影响。
- **实际采用**：课堂按「任务 × 反馈周期」在首次评价时绑定；作业在布置时写入 `schemeRevId`；发布时冻结图例。三者确定后不再随默认变化。

## 生效边界

- 课堂：本期尚无评价可「本期立即采用」；本期已有评价或发布，只能「自下期起」，同一待生效周期再次调整即替换。
- 作业：只影响之后新布置的作业。
- 保存方案不自动设为默认；设默认必须明确勾选用途。

## 历史保护

- 已被评价、作业、发布或默认引用的修订不可改写；编辑时追加新修订，未被引用的最新修订原地更新，内容无变化不产生修订。
- 被业务引用的方案只能归档；归档仍可查看、复制、恢复，已采用的周期与作业可继续录入。
- 仍为默认的方案在归档/删除时必须选择替代（默认系统「基础四级」）。
- 找不到修订或等级时显示原值并标「标准待核对」，不回退为 A 或最新默认。
- 任何方案操作都不改写学生结果、不重算、不重新发布。
