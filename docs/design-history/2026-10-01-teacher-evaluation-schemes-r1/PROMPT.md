任务：教师教学评价方案
日期：2026-10-01
修订：本主题r1
对象：当前周反馈系统v0原型，在r5相关成果上增量实施。
不代表r5已经验收，不涉及Codex真实产品实施。

在“我的教学”增加“教学设置”入口，支持教师管理多套
课堂评价／作业质量方案：查看系统预设、直接采用、
复制修改为个人方案、保存多套个人方案，
并分别指定课堂和作业的默认方案。

先核对当前统一反馈编辑器、作业管理、批量确认、
发布及模拟存储，复用已正确的实现。
不重跑或覆盖r1—r5，不另造“配置版反馈编辑器”。

只实现完整原型交互和可恢复模拟数据，
不连接真实产品数据库，不开始Codex实施。

以下定义必要元素、功能、导航、业务规则和核验结果。
布局、视觉和控件组织由你设计，
章节与清单顺序不代表页面排列要求。
不要把业务规则和版本元数据堆成常驻长说明。

一、可配置范围

1. 支持教师自定义课堂评价和作业质量的有序等级。
   支持A、A+、A-等标识，也支持简短文字，
   不限定只能使用A/B/C/D。

2. 以下仍是系统事实或处理状态，不开放任意改义：
   正常、迟到、早退、缺勤、请假、在他班；
   按时提交、迟交、未交；
   未记录、待处理、明确不评价、不适用、未参与、免做等。

   不把这些状态做成教师可随意增删的评价等级。

3. 等级与处理状态分开：
   D可以是一条已经确认的评价，
   A也可能只是尚未确认的候选。
   缺勤和未交不自动转换成D。

4. 保留评价可明确留空和不适用的现有规则。
   不因自定义方案增加“必须评价”
   或“为什么不评价”等新要求。

5. 本轮不增加：
   等级转分数、自动平均、百分比、GPA、跨教师排名、
   等级自动触发预警或家长通知、多维加权量规、
   逐班／逐学生方案覆盖、每次课任选方案、
   方案审批平台、跨教师共享市场或通用配置导入。

二、入口与默认使用方式

1. 导航为：
   我的教学 → 教学设置 → 评价方案。

   可以在同一个设置功能内表达，
   不强迫教师逐层经过三个页面，
   不新增侧栏一级模块。

2. 需要能够访问：
   系统方案、我的方案、课堂默认、作业默认、
   方案内容编辑和效果预览。

3. 每位教师可以保存多套个人方案。
   课堂评价和作业质量各有一个明确默认，
   可以使用同一套，也可以分别选择。

4. 默认适用于本人后续有权的全部教学任务，
   包括不同教学班、实际分工和整科教学。

   不改变其他教师的任务，
   不通过配置方案增加任教权限。

5. 默认设置不受当前列表搜索、班级筛选
   或正在浏览的周次限制。
   不能只更新当前屏幕看见的教学班。

6. 不在每个任务行、单元格或学生抽屉中，
   增加方案编辑和整套方案切换控件。

   日常填写自动使用当前对象已经采用的标准，
   教师需要时可以查看该标准的等级与说明。

7. 从反馈或作业查看标准、进入教学设置后，
   返回应保留原任务、周期、学生和未完成输入。
   查看设置不创建反馈，不自动应用新方案。

三、系统方案库与我的方案库

1. 系统方案支持：
   查看、直接采用、复制为我的方案。

   教师不能原地修改系统方案。

2. 至少提供三套预设起点：

   基础四级：
   A＝优秀
   B＝良好
   C＝合格
   D＝待改进

   初始课堂和作业的系统默认使用基础四级，
   常规确认默认等级为A。

   细化八级：
   A+、A、A-、B+、B、B-、C、D。

   示例释义依次为：
   表现突出、优秀、整体优秀、良好偏上、
   良好、基本良好、合格、待改进。

   提供简短判断说明，帮助区分相邻等级，
   不只靠近义词表达差别。
   常规确认默认等级为A，不是最高档A+。

   文字四级：
   表现突出、达到目标、需要巩固、需要支持。

   提供对应释义与判断说明，
   常规默认“达到目标”。
   标识与释义相同的文字不重复显示两次。

3. 上述预设是本原型的通用起点，
   不冒充考试局、考试成绩或GPA标准。

   A＝优秀保持在基础四级和细化八级系统预设中。
   教师需要不同判断说明时，可复制后调整。

4. 教师可以：
   从空白新建；
   复制系统方案；
   复制自己的已有方案；
   修改、保存多套方案；
   设为默认；
   归档或在合法条件下删除。

5. 复制得到独立个人方案，保留来源关系即可，
   不与源方案持续同步。
   系统更新不能覆盖教师个人副本。

6. 不强迫课堂和作业永久共用同一份判断说明。
   可以选择同一方案，也可以复制成两个独立方案。

7. 同名方案不等于同一个对象。
   保存时如果与本人已有名称重复，
   提示使用可区分名称，不覆盖原方案。
   不用方案名称或等级文字代替稳定身份。

四、方案编辑与校验

每套方案包含：

- 方案名称；
- 可选的方案说明；
- 有明确高低顺序的等级；
- 每档的简短标识、简短释义和可选判断说明；
- 可选的常规确认默认等级，允许不设置；
- 家长呈现方式：
  默认“等级＋释义”，可选择“仅文字释义”。

教师能够增加、删除、修改和调整等级顺序。
顺序是评价语义，不按字符串排序，
不擅自重新排列教师的等级。

保存或采用前检查：

1. 名称、等级标识、简短释义不能仅为空白。
   至少有两个可区分的有序等级。

2. 同一修订内的等级标识不可重复。
   首尾空白及明显等价输入采用一致校验，
   不能吞掉“+”“-”。

3. 默认等级必须属于本修订。
   删除默认等级所指的条目时，
   要求重新选择或清空，
   不能自动选最高档、第一项或相似代码。

4. 未记录、不适用等系统状态不允许伪装成等级。

5. 字母和中文都可使用。
   纯文字方案不要求教师填写额外的隐藏字母代码；
   内部稳定标识由系统负责。

6. 使用安全文本和合理长度校验，
   不支持HTML、脚本、公式或可执行配置。

7. 判断说明可以留空，不强制填写长篇标准。
   界面切换语言，不自动改写教师自定义内容。

预览须使用当前候选：
能够查看教师选择时的效果，以及家长看到的结果示例。

预览明确属于样例，
不向真实学生记录写值，不触发发布。

五、保存、默认方案和默认等级分开

1. 保存：
   保存个人方案备用。
   不自动设为默认，不给学生评分，
   不改变已经采用的标准。

2. 设为默认：
   明确选择用于课堂、作业或两者，
   并说明实际生效范围。
   不暗中同时改变另一个用途。

3. 保存并设为默认：
   允许一次完成，避免保存后再找另一个入口。
   按一次明确操作处理；
   失败不能留下不明的半成功或假成功。

4. 常规确认默认等级：
   用于教师明确执行常规确认时的候选值，
   不是打开页面就给全体学生赋值。

5. 未设置个人默认时，使用系统默认。
   教师可以改选另一套系统方案或个人方案。

   “系统默认”是推荐选择，
   不等于“系统方案库里只有一套”。

6. 恢复系统默认：
   切回当时明确采用的系统默认修订，
   不删除个人方案，不重置已有评价。

7. 当前默认与已保存备用的方案要能区分。
   有待生效选择时，简短说明生效周期或日期，
   不能只有“设置成功”。

8. 系统以后新增推荐修订，可以提示教师了解并采用。
   不静默把已采用默认指向最新版，
   不覆盖个人副本。

9. 设置按学校和真实教师隔离，
   不按姓名识别，不跨校传播，
   不因查看另一位教师资料而改变设置所有者。

六、生效规则与历史保护

课堂评价：

1. 使用学校的反馈周期和时间规则，
   不以当前正在浏览的历史周决定生效日期。

2. 当前周期尚未使用评价方案时，
   可以明确立即采用。

   一旦本人当前周期已有实际课堂评价、
   评价确认、明确采用锁定或含该维度的发布，
   修改课堂默认原则上从下一反馈周期起生效。

   这个判断针对本人范围，
   不只检查当前打开的某一个班。

3. 采用结果明确说明：
   例如“本期保持基础四级，下期起使用我的细化八级”。

   不新增任意日期排程器。
   同一待生效周期再次调整，
   明确替换待生效选择，不堆成多轮配置任务。

4. 每个真实教学任务／责任范围＋反馈周期，
   共用一个已经确定的课堂方案修订。
   不能让同周期不同学生分别使用教师此刻的最新默认。

5. 打开页面只是解析候选标准，不创建业务草稿。
   首次明确评价或确认时固定引用；
   已经明确绑定的对象继续使用原绑定。

6. 补录过去周期时，
   读取那个周期实际有效的标准或已有绑定，
   不使用今天的默认重新解释过去。

   已明确绑定的未来周期也不能被静默改写。

7. 保存足够的默认采用历史，
   供历史补录和后续任务解析。
   不提供强制切换已使用周期、
   批量重评或等级自动转换。

作业质量：

1. 新作业首次成功布置时，
   采用当时有效的作业默认修订，
   固定用于该作业的全部适用学生。

2. 未布置草稿可预览候选标准。
   最终布置时若候选版本已经变化，
   核对后再提交，不能悄悄换成另一套。

3. 默认修改用于之后新布置的作业。
   已布置但未批改、部分批改、跨周批改的作业，
   全部保留原方案。

4. 复制旧作业再布置属于新作业，
   使用新布置时有效的默认，
   不复制旧成绩或误带旧方案绑定。

5. 既有线下补录功能保留，
   准确显示补录作业实际采用的标准。
   有真实旧标准依据时保留，
   不伪称今天的默认就是过去执行的标准。

修订与历史：

1. 方案、修订和等级具有稳定标识。
   已被默认选择、任务周期、作业或发布引用的修订，
   不原地改写。

2. 教师正常编辑和保存即可。
   系统在实质内容变化时保留新修订，
   不要求手工管理v1/v2、分支、合并和审批。

   不因查看、每次输入或无变化保存，
   制造一串修订记录。

3. 修改正在使用的方案：
   可以仅保存新修订，
   或明确更新选定用途的默认。

   “保存”不能自动升级原默认引用。

4. 名称、释义、顺序、默认等级、
   家长呈现方式的变化，不反向改写旧记录。

5. 已发布反馈保留当时的等级、释义和呈现方式。
   查看旧版或重新生成旧版图片，
   不能改用最新默认。

   补发布和更正沿用原对象标准及现有发布规则。

6. 教师交接或共同处理已有对象时，
   使用对象原来的标准，
   不用当前查看者的个人默认重新解释。

7. 相同字母在不同方案或修订中不是同一个等级。
   不自动将A-转成A或B，
   不按顺序计算均分、百分比或GPA。

七、归档、删除和失败处理

1. 未被采用、未被业务记录引用的个人方案可以删除。
   如果默认或待生效选择仍引用它，
   先明确替换，可在同一次操作中完成。

2. 已用于业务对象或发布的方案只能归档，
   不物理删除必要修订及等级。
   归档后仍可查看和复制。

3. 当前默认归档前必须选择替代或系统默认，
   不能留下悬空引用。

4. 归档只退出新选择的常用范围。
   已经采用该方案的周期和作业仍可继续录入、补评。
   尚未评分的学生不能突然失去原等级选项。

5. 删除、归档、恢复系统默认，
   都不删除学生结果，不重算、不重新发布。

6. 保存失败、取消或关闭编辑，
   不影响原来有效的标准。
   保留输入并支持重试，
   重新打开能分清已保存与未提交内容。

八、必须接入全部现有评价入口

共用一套有效方案解析，至少覆盖：

- 日期矩阵摘要和单元格编辑；
- 学生反馈抽屉；
- 作业管理及学生结果编辑；
- 逐生常规确认、批量确认及安全撤销；
- 既有评语依据和建议读取；
- 发布校验、预览、家长结果和历史；
- 已有图片输出；
- 工作台和我的教学的状态、统计。

具体要求：

1. 按当前业务对象已采用的修订呈现和校验选项，
   不拿教师最新默认冒充旧对象标准。

2. 移除相关硬编码A/B/C/D判断。
   八级和文字等级都能保存、刷新和正常流转。

3. 常规确认使用对象绑定修订中的默认等级。
   没有默认时不猜等级、不取最高档；
   可以按原规则处理其他适用维度，
   并明确评价仍需教师判断。

4. 不覆盖手动B、已确认结果、明确清空、
   例外、不适用、未参与或未来课堂。

5. 作业默认质量不代表已经提交。
   更换方案不改变参与要求、截止日期、名单或成绩。

6. 等级高低不决定是否已处理。
   不把所有非A结果当异常，
   不因增加A-、B+制造新待办或自动通知。

7. 沿用r5摘要矩阵、单元格编辑和统一学生抽屉。
   不恢复满表下拉、第二种矩阵，
   或进入后再点一次“开始填写”的门槛。

8. 保留自动保存、批量作用范围、权限、
   未来课堂和发布保护。
   快速切任务与迟到响应不得写入错误对象。

9. 标准引用缺失时，
   优先使用该对象保存的真实标准快照。

   既没有引用也没有可核对快照时，
   说明待核对并保留原值；
   不回退成A或最新默认假装正常。

10. 接入既有原型记录时核对原字典和含义。
    原有A+、A-等不在新基础四级中，
    也不能删除、降档或重新释义。

    保留可以证明的原标准快照；
    不整站重置来掩盖问题，
    不建设真实产品迁移平台。

九、家长呈现与权限

1. 默认“等级＋简短释义”。
   可整套采用“仅文字释义”，
   所有等级遵守同一种模式，
   不能只对较低档隐藏字母。

2. 家长、班主任在有权查看结果时，
   可以理解该结果实际采用的标准。

   不因此开放教师全部个人方案、
   编辑候选或其他学生资料。

3. 等级释义和判断说明属于标准内容，
   可能随合法结果被查看，预览应明确呈现。

   通用标准不是学生个人观察，
   不能自动冒充教师给某学生写的个体评语。

4. 内部等级与家长解释必须一致，
   不能内部B、外部显示A-。

   文字模式仍保留真实等级身份和历史来源。

5. 多教师、多任务、课堂与作业组合发布时，
   保留各自标准，不误用一份统一图例，
   不换算成同一种字母含义。

6. 评价方案不是仅本人可见的“自定义分工”。
   但私人分工、内部请假原因和私人备注，
   也不因此进入评价标准或家长反馈。

7. 教师仅维护自己的方案和默认。
   管理员、班主任读取学生结果继续按现行权限，
   本轮不新增替教师修改私人方案的能力。

十、原型实现和文案

1. 提供真实可操作原型，
   不能只有方案卡片、三个固定选项或成功提示。

2. 使用统一身份、学校周期、演示时钟和模拟存储。
   方案、默认、生效选择、对象引用和历史快照，
   刷新重开均可恢复。

3. 未配置的教师继续使用系统默认，
   不把教学设置变成开始教学前的必经步骤。

4. 只展示必要内容与当前操作影响。
   规则按需查看，
   不常驻长版本链、内部ID、重复说明和多层确认。

5. 无变更退出不警告；
   确有未保存候选时才保护输入。

   保存方案与采用默认必须明确，
   不能字段失焦就自动启用新标准。

6. 不让教师逐班维护副本，
   不在任务列表重复添加设置控件，
   不重做无关页面。

7. 复用现有国际化资源。
   教师自定义内容原样保留，
   不声称自动翻译已经完成。

8. 加载失败不能显示为空方案库，
   更不能因此自动重置默认。
   空库、归档、无默认等级、错误和无权状态，
   均有准确说明和合法操作去向。

十一、实际核验

使用隔离合成场景，逐项记录PASS／FAIL／NOT_RUN：

1. 未配置教师可直接用系统基础四级填写；
   其他教师的个人标准不受影响。

2. 复制系统八级、修改并保存：
   系统源不变，保存后默认不变；
   设为课堂默认后，作业默认不变。

3. 保存至少两套个人方案；
   能选择系统预设、个人方案和恢复系统默认，
   不删除原方案及评价。

4. 新建文字方案，
   中文、A+、A-均能保存、排序、选择和刷新恢复。

5. 空值、重复等级、删除默认等级、无默认等级、
   取消及保存失败，不产生错误的自动选档。

6. 同一修订可用于课堂与作业；
   仅保存新修订不升级任何默认，
   只更新课堂时不顺带更新作业。

7. 已使用四级的当前周期保持原标准，
   新默认从后续周期生效；
   浏览历史周不导致回溯生效。

8. 当前周期未使用时明确立即采用可用；
   仅浏览不锁定方案。
   历史补录与未来已绑定对象使用正确引用。

9. 旧作业跨周批改保持旧标准，
   新作业使用新默认；
   复制新作业不复制成绩，
   同一作业的学生之间不混用标准。

10. 已用方案改等级、释义、顺序、呈现方式后，
    旧课堂、作业、发布和旧图片不变，
    新修订按规则使用。

11. 未使用方案可以删除；
    归档已用方案后，旧作业仍能完成批改；
    默认归档需明确替换。

12. 单元格、抽屉、作业和常规确认共用对象标准；
    从工作台进入不退回写死四级。

13. 默认A-不变成A+，无默认不造等级；
    保留手动B、请假、明确清空和未来课堂，
    不伪造作业提交。

14. D已确认仍计已处理，A候选不计已确认；
    配置变化不制造异常、均分、GPA或通知。

15. 教师预览与家长结果一致；
    文字模式保留真实等级；
    多标准发布不误用图例，不泄漏私人方案库。

16. 不同学校、教师不能互改方案；
    合法接手任务仍按该对象原标准处理。

17. 快速切换用途、身份、任务，重复保存、
    刷新和故障重试不串数据，
    不重复创建修订或待生效选择。

18. 回归r5的统一入口、摘要矩阵、学生资料与反馈抽屉、
    课表合法导航、独立作业和阶段发布。

可以增加逻辑测试，
但不能以编译通过、静态截图或直接修改store，
代替真实页面操作。

未实际执行的发布、图片等核验如实标NOT_RUN，
不使用假按钮或伪成功代替。
