## 1. 不可遗漏的交付约束

1. **班级报告和个人报告必须一起完成。**“个人同样适用”不构成交付；必须有个人专属可选元素、真实配置应用和独立验收。
2. 两类报告共用样式解析、条件规则、值格式化、预览与输出基础能力，**不强制采用相同模板、参数或详细度**。
3. 班级报告仍为默认主流程；个人报告按教师需要选人生成，不因为完善个人报告而把发布默认改成全班每人一份。
4. 个人报告必须是包含真实课堂与作业表格的完整沟通报告，不能变成文字摘要、班级表格裁下一行，或只有名字不同的复制品。
5. 元信息整体靠左、左对齐，三行字号一致；班级与个人均修正，不仅修改班级PNG。
6. 出勤、课堂评价、作业等字段的**表头与数据格分别可定制**；日期表头不能与字段表头混为一个对象。
7. 请假/早退等出勤状态、优秀等级、明确未交等支持基于真实数据的条件着色，而不是搜索显示文本后改颜色。
8. 课堂评价与作业质量按各自实际采用的方案匹配，不写死A、A+或当前默认方案。
9. 更换报告样式不能修改出勤、成绩、评价体系、名单、检查日、公开范围或实际发送对象。
10. 现有模板清单＋单份预览继续保留；不一次性展开全部模板或全部学生的完整报告。
11. 一次只预览一个对象，但切换对象、保存设置、导出时必须准确保持该对象身份与对应配置。
12. 普通颜色、字号等修改即时预览，不增加逐次确认弹窗；批量统一、清除细调等明确动作可配撤销。
13. 班级报告默认一张完整报告；学生列表分页不等于报告分页。个人报告默认也完整输出其所选教学周内容，不只输出预览中可见的几行。
14. 内部备注、健康/家庭私人原因和未选课堂观察不因个人模板或条件格式而自动公开。
15. 所有显示样式调整只影响报告，不联动改变“我的课表”、课次安排、日卡或周反馈编辑矩阵的配色。

## 2. 两类报告的数据与结构基线

### 2.1 班级报告：保留经典矩阵

- 学生按行；教学日期及作业检查/记录归属日期按列。
- 日期/星期为上层表头；出勤、课堂评价、作业等字段为下层表头。
- 表头不重新写成“周一出勤”“周一课堂评价”这种混合字段。
- 作业列按现有已确认的检查/记录归属日期动态产生：无课日也可有作业列；没有任何检查或记录的日期不造作业结果列。
- 归属日期一般采用实际业务已有的检查日期/约定截止日，教师已有提前或延后选择继续保留；样式操作不得重新计算或改写日期。
- 同日多项作业保留其身份和各自结果，按现有合法方式展开或简洁区分；不得求平均、取最高分或覆盖为一个结果。
- 班级表格单元格不出现“第3节·09:40–10:20”。按日出勤简况、按日评价与具体作业结果分别投影。
- 现有边栏说明型、下方说明型、紧凑矩阵型等结构均接入新能力，不要求删掉已实现模板重造。
- 教学介绍、学情介绍、公开亮点继续由既有数据提供。无亮点不显示亮点区，也不留空框。
- 无法评价与未填值默认显示“–”或空白；明确的“未交”不属于空值，不可被隐藏。
- 已确认可向班级受众展示的姓名、出勤、课堂评价与作业简况继续保留；本次不得降级成匿名统计摘要。

### 2.2 个人报告：完整周数据，而非单日切片

个人报告范围为选定学生、选定教学周及本次明确选择的合法教学任务。来源日卡日期只用于返回，不缩小整周范围。

个人报告至少具备以下真实内容能力：

| 模块 | 必须支持的字段与语义 |
|---|---|
| 个人身份 | 学生姓名、教学班/学科/实际分工、周次日期、教师 |
| 本周课堂记录表 | 日期、出勤、本日课堂评价；课堂评价仍按任务按日唯一 |
| 可选课次明细 | 真实节次、时间、教室、对应课次出勤；不得伪造第二套逐课次正式等级 |
| 本周作业明细表 | 作业名称、检查/截止日期、提交状态、质量等级、已填分数、已允许公开的教师反馈 |
| 教学介绍 | 可引用本次班级共同内容，保持原文和适用任务 |
| 学情/跟进说明 | 本生可公开评语、本次关注、已有建议，不自动生成空洞套话 |
| 亮点 | 该生在合法出席情境下的公开亮点，不混入其他学生记录 |
| 明确选入的观察 | 只呈现教师主动选入并已整理为家长可读内容的观察，不直接导出内部原文 |

个人报告必须同等支持元信息、各表头、各数据列、区块标题、正文、边框、间距、颜色、条件格式和本次细调。

不要强制个人模板使用班级矩阵结构。个人表以日期/作业为行是合理结构，沿用已有实现并精修；也不得把“班级不显示课次时间”错误扩大成“个人也不允许查看真实课次明细”。

### 2.3 粒度与重复信息

个人报告提供“按日简况”和可选“含课次明细”的显示能力。开启明细后：

- 日期、节次、时间与教室可分别显示和设置宽度，不与出勤结果拼成冗长字符串。
- 已有���涉及课次”列显示节次与时间时，出勤列只显示对应状态，不再重复同一节次时间串。
- 同日两节课可分别显示考勤，但正式课堂评价仍只呈现该日的一份结果；不能把同一个A复制成两次评价、重复计数或重新算平均。
- 合并日期格、日评价格或显示课次子行的具体呈现由你设计，但不能误导为逐课次已评分。
- 部分出席时沿用已确认的日评价资格逻辑，不因一节请假就删除全天合法评价；该次未出席本身仍准确表达。

## 3. 元信息：班级与个人同时修正

### 3.1 班级默认三行

```text
第5周  2026/09/28–2026/10/04
高一2�� · 计算机
示例林老师
```

### 3.2 个人默认三行

```text
第5周  2026/09/28–2026/10/04
示例学生01 · 高一2班 · 计算机
示例林老师
```

日期与姓名使用当前真实模拟对象，不硬编码上述内容。有真实分工则简洁追加到第二行；无分工不强制显示“整科”，不重复已经出现的学科。

两类报告均遵守：

- 整个元信息区域处于报告内容区左侧，与第一张主表左缘对齐。不能只是将一个仍位于中间的小块内部改为左对齐。
- 三行共用同一个字号设置，默认同字体、同字重。第一行不得独立放大。
- 允许统一修改字号、字体、行高、行间距和距首表间距；高级可修改某行文字颜色或字重，但不恢复独立大标题字号。
- 第二行在长名字/多任务下允许自然换行，仍保留学生身份与真实任务区分；不截断成无法识别的姓名。
- 换主题、换模板、选择个人、批量导出后都不得回到“大号居中日期＋小号居中身份”。
- 默认不增加“个人报告”“模板预览”“内容截止”“来源任务ID”“已保存”等系统元信息或页脚。
- 单一任务下表格模块标题使用“课堂记录”“作业明细”等清晰短名，避免反复拼接班级全名；多任务确需区分时保留最小任务标识。

## 4. 配置分类与入口能力

保留“样式/布局”“主题/配色”，补齐“元素细调”“条件格式”四类功能。分类是能力分工，不强制四个页面或固定页签布局。

| 分类 | 内容 |
|---|---|
| 样式/布局 | 报告结构、内容区组织、画布、表格密度、列宽、行高、可选明细 |
| 主题/配色 | 可复用颜色集合；字段表头、正文、状态色等语义色槽 |
| 元素细调 | 当前报告中可选择的具体元素与属性 |
| 条件格式 | 根据合法状态、方案等级、有效数值自动突出显示 |

所有能力均能在班级和个人模式使用。某个元素只存在于个人报告时，应在个人模式提供对应控件，不显示一个不能操作的“后续支持”占位。

当前截图中的“修改报告样式（仅本次）”入口继续保留并接入完整配置。模板中心编辑可复用模板，发布准备编辑本次报告；两者共用同一配置能力，不维护功能不一致的简版/完整版。

需要能够明确选择：

- 当前报告类型：班级／个人。
- 当前模板及主题。
- 本次编辑作用范围。
- 当前预览对象。
- 当前待编辑元素或条件规则。

这些概念不能合成一个下拉：**预览谁，不等于把谁加入发送；切到个人预览，也不等于正在编辑只作用于这一个学生的样式。**

## 5. 通用属性：各类元素使用一致的编辑能力

以下数值为本轮可采用的报告参数初值/校验区间，不是设置页面的布局要求。尺寸统一使用报告设计像素，预览缩放与输出倍率单独计算。

| 属性组 | 必须支持的参数 | 初值/边界 |
|---|---|---|
| 字体 | 中文、西文、数字字体；继承或指定 | 使用项目实际可稳定渲染与导出的字体目录；不能只在本机有效 |
| 字号 | 继承/准确数值，不只三个档 | 正文与元信息建议默认16，可调10–36；元信息三行统一 |
| 字重 | 常规、中等、半粗、粗体/可用字重 | 不用不支持的伪选项冒充字体能力 |
| 字形 | 常规/斜体、下划线 | 默认无装饰，不用删除线表达成绩作废 |
| 文字色 | 主题色引用、HEX、RGB、取色器 | 不允许用零透明度或透明文字隐藏结果 |
| 背景 | 继承/无填充/指定色、背景透明度 | 白色填充与无填充是不同选择 |
| 对齐 | 水平左/中/右；垂直上/中/下 | 元信息遵守固定靠左左对齐；其余可调 |
| 行高与字距 | 准确数值 | 行高建议1.0–2.0、字距−0.5至3；无破词、无重叠 |
| 内边距 | 上右下左，独立或联动 | 建议0–24；紧凑数据格可从上下2/左右6起步 |
| 外部间距 | 区块间、段前后、元信息到主表 | 可调，不让无内容区块占空位 |
| 边框 | 四边、颜色、粗细、实线/虚线/点线/无 | 可准确输入，建议0.5–4；避免相邻格偶然双线 |
| 宽度 | 自动/固定/相对比例/最小最大值 | 同一目标宽度模式互斥，比例合法；内容不得被截掉 |
| 高度 | 自动/最小高度；可选内容所需统一行高 | 不提供“裁掉文字”的固定高度行为 |
| 换行 | 自动、优先单行、保留原段落 | 正式报告不静默省略；姓名与英文单词不被不合理拆断 |
| 恢复 | 恢复单属性、恢复元素、恢复主题默认、清除本次细调 | 动作只影响所标注范围 |

背景语义：

- “继承”：不建立本层覆盖。
- “无填充”：本层不绘制背景，仍能看到下层底色。
- “白色”：本层明确绘制白色。
- 输入无效HEX/RGB时保留最后有效预览，提示改正；不能保存无效颜色或意外退回黑色。

## 6. 班级报告元素目录

每个目标均能使用适合它的通用属性，至少覆盖下列目标。

| 目标 | 必须能独立控制的内容 |
|---|---|
| 报告画布 | 自适应/自定义宽度、自动高度、四边距、背景 |
| 三行元信息 | 统一字号/字体、文字色、字重、行高、间距 |
| 主表 | 默认表体背景、外框、表格宽度、整体密度 |
| 日期/星期上层表头 | 文字与背景、字体/字号、日期格式、内边距、对齐、边线 |
| 姓名表头与姓名数据 | 两者分别设置文字/背景/字重/对齐，姓名列宽 |
| 出勤子表头 | 标签、文字色、背景色、字重、对齐、边框 |
| 出勤数据格 | 普通文字色/背景、列宽、字号、内边距、对齐 |
| 课堂评价子表头 | 与出勤独立，不同步改日期表头 |
| 课堂评价数据格 | 普通颜色/背景、等级格式、列宽、对齐、字号 |
| 作业子表头 | 与课堂独立，动态列自动继承 |
| 作业质量数据 | 普通文字色/背景、等级/分数格式、列宽 |
| 作业提交状态文字 | 与质量等级分别设样式、分别匹配规则 |
| 数字分数 | 数字字体、对齐、小数位、是否显示满分与尾零 |
| 空值/不适用 | 中性颜色、空白或“–” |
| 内部横线、竖线 | 分别开关、线色、线宽、线型 |
| 外边框与表头底线 | 不与所有网格强制共用 |
| 日期组/教学与作业边界 | 分隔线颜色、粗细、线型 |
| 隔行底色 | 关闭/开启、奇偶色；按完整名单顺序计算，不按编辑器每页重启 |
| 已开启的序号等辅助列 | 自有表头与数据样式；本轮不自动增加这些列 |
| 特定日期/特定作业列 | 高级本次细调，使用真实对象键，不靠第N列 |

同类列可以统一调整；特定日期或作业列可单独微调。日期上层只表达日期，出勤/课堂/作业在字段层分别配色。现有同日课堂与作业的合法分组继续支持，不因着色而改变记录排序与归属。

数据表与说明区高度独立：说明较长时报告自然增高，不为对齐边栏底边而把每名学生行拉得很高。

## 7. 个人报告元素目录（与班级同等级交付，不得略写）

### 7.1 个人身份与模块

| 目标 | 必须可调内容 |
|---|---|
| 个人报告画布 | 独立宽度、自动高度、边距、背景与输出密度 |
| 三行元信息 | 与班级相同的左对齐及统一字号能力；保留目标学生姓�� |
| 学生身份文字 | 字重/颜色可细调，不强制大号姓名海报 |
| 课堂记录标题 | 名称、字体/字号、颜色、背景、边框、内边距 |
| 作业明细标题 | 与课堂记录标题独立，也可复制样式 |
| 教学介绍/学情说明/跟进说明 | 标题、正文、区块容器各自样式 |
| 本次关注、已选观察 | 标题/正文/关联事实标记样式；只有已选公开内容可输出 |
| 个人亮点 | 文本或小表；标题、数据、边框、间距；无记录不占位 |

### 7.2 个人课堂记录表

| 字段或目标 | 显示与精调要求 |
|---|---|
| 日期表头/日期数据 | 各自文字色/背景/字号/宽度/格式/对齐 |
| 出勤表头/出勤数据 | 各自样式；完整支持请假、早退、迟到等条件规则 |
| 本日课堂评价表头/数据 | 各自样式；根据本条记录实际方案/等级着色 |
| 涉及课次表头/数据 | 可关闭；开启时有独立字体、次要文字色、宽度与换行规则 |
| 时间段 | 仅明细模式且教师开启时显示；单独控制，不在出勤格再重复 |
| 教室 | 可选，独立样式；无值不伪造地点 |
| 日期组边界/课次子行 | 边线、缩进或间距由报告参数控制，不重算成绩 |
| 日评价合并格 | 保留每日一份正式结果，不因课次展开复制成绩 |
| 明确公开的短说明 | 可选，独立颜色、字号、换行；不读取内部备注原文 |
| 空值和不适用格 | 与班级同样简显为“–”或空白 |

按日简况和课次明细两种模式必须使用同一事实来源。切换只改变展示详细度，不修改保存值、不补出勤、不重建日评价。

### 7.3 个人作业明细表

| 字段或目标 | 显示与精调要求 |
|---|---|
| 作业名称表头/数据 | 独立字体、文字/背景、列宽、换行；长名称完整 |
| 检查日期与截止日期 | 可选择显示检查日、截止日或两者；名称必须对应实际字段，不把两日期冒充同一日期 |
| 提交状态表头/数据 | 独立样式与条件规则；确认未交红色、未核对不能冒充未交 |
| 质量评价表头/数据 | 与课堂评价独立；按每份作业实际采用方案匹配 |
| 已有分数 | 只有真实数字才格式化；支持0分、不同满分、小数位；不根据等级推算分数 |
| 教师反馈 | 仅已有且获准公开的文本；独立正文样式与换行 |
| 订正/补交等已有字段 | 当前数据支持且本次开启时显示；不为样式功能编造新状态 |
| 表格横线/竖线/外框/隔行 | 与课堂记录表分别可设置，也可显式同步 |
| 单项作业行/某格 | 高级本次细调，以学生＋作业稳定标识定位 |

个人作业表不依赖本人出勤资格。请假学生实际提交且质量优秀时，出勤可红字，作业可绿字；不能整份个人报告都变红或把作业清空。

### 7.4 个人内容区与数据真实性

- 本生跟进说明、个人评语、教师公开反馈和班级共同介绍分开绑定，不能用班级学情概况假装个别评语。
- 本次选入的观察应显示准确来源关联，风格可调；内部ID不作为正式报告文字。
- 来源日期/作业选择只引用已存在事实，不因切换模板增加新的观察或生成建议。
- 无个人评语可省略此区，不自动填充“表现良好，继续努力”等文案。
- 不泄漏其他学生的个人成绩或私密记录。已有班级共同正文按其公开范围使用。
- 无内容模块释放空间，不保留空白色块或空表格来撑版面。

## 8. 说明区、亮点与标题参数

班级和个人的每个说明区均分别控制：

- 标题用语：沿用“教学介绍/教学内容”“学情介绍/学情概况”等有明确含义的词；个人另有跟进说明、本次关注。
- 标题形式：纯文字、完整色带、局部标签；字体、字号、字重、文字色、背景、对齐、边框与内边距。
- 正文：字体、字号、文字色、背景色、行高、段距、对齐、内边距；保留教师已有的有限加粗等安全文本格式。
- 容器：边框四侧、线色/粗细、自然高度/最小高度、区块间距。
- 亮点：并入学情、独立姓名＋短句、独立小表等已支持方式；避免同一内容重复出现。
- 正文和亮点仅在报告投影中组织，不把内容来回复制写入源字段。

模板结构可保留边栏/下方等成品样式选择。默认紧凑；中文自然换行，英文词不拆成“Add / ition”；长正文自然增高，不自动总结或删字。

## 9. 主题配色：按语义提供独立颜色

不要只有一个“主色”控制所有元素。至少提供以下可引用色槽，班级与个人均能使用：

| 色槽组 | 内容 |
|---|---|
| 基础 | 画布、正文、次要文字、空值、内部网格、外边框 |
| 日期 | 日期表头文字/背景、日期组边界 |
| 姓名/身份 | 姓名表头文字/背景、姓名正文 |
| 出勤 | 表头文字/背景、普通数据文字/背景 |
| 课堂评价 | 表头文字/背景、普通结果文字/背景 |
| 作业 | 表头文字/背景、普通质量文字/背景、提交状态普通文字 |
| 分数 | 数字文字、数字背景 |
| 个人课次明细 | 节次/时间/教室次要文字和可选背景 |
| 说明区 | 标题文字/背景、正文文字/背景、容器边线 |
| 状态 | 优秀、需关注、未交、迟到、中性等文字/背景配对 |

每个色槽支持HEX三位/六位、RGB、取色器、主题引用和恢复默认。教师自选颜色不限于有限预设。

主题本身不判定哪一个等级优秀。主题只提供颜色；条件规则决定什么时候使用。

提供至少一套“经典清晰”和一套“低彩色”配色起点，用同一报告数据实际预览。配色可换，报告结构、字体大小、受众、成绩和公开内容不随之变动。

班级模板和个人模板可复用同一个主题资源，也可完全不同。**编辑一个模板的颜色不应未经明确应用就改变另一类报告。**共享主题内容修订后，当前使用者明确采用新版本；已发布快照不受影响。不新增复杂主题历史管理页面。

## 10. 条件格式：班级、个人及个人明细均适用

### 10.1 规则编辑能力

每条规则有：名称、开启/停用、适用报告类型、目标字段、判断条件、呈现效果、优先级。

目标：出勤、课堂评价、作业提交、作业质量、已有分数。高级可限定当前任务/日期/具体作业，但实例范围不保存到通用模板。

条件只允许基于该报告已获准呈现的结构化数据：

- 状态等于/属于所选状态集合。
- 等级属于指定评价方案中的明确等级集合。
- 已有有效分数大于/小于/等于/落入数值区间。
- 百分比条件仅在这条记录真实满分存在时可用，不能默认满分100。

效果：对应文字颜色、字重、可选下划线；对应数据格背景与边框。默认仅影响该字段文字或数据格，不染整名学生一行。

支持新增、编辑、复制、排序、停用、删除、规则试算。无需教师写表达式、脚本、HTML或CSS。

### 10.2 初始可修改规则

| 匹配条件 | 默认效果 | 可选效果 |
|---|---|---|
| 请假、早退、明确缺勤 | 深红文字，可用 #B42318 | 浅红背景，可用 #FEF3F2 |
| 迟到 | 深橙文字，可用 #92400E | 教师可改红色或其他清楚颜色 |
| 在他班 | 中性文字，不自动负面化 | 自选文字或背景 |
| 明确确认未交 | 深红文字 | 可选浅红背景 |
| 教师指定的优秀课堂等级 | 深绿文字，可用 #166534 | 仅浅绿底/绿字加浅绿底，可用 #ECFDF3 |
| 教师指定的优秀作业等级 | 独立匹配、深绿文字 | 可与课堂使用不同颜色 |
| 空值、不适用 | 中性文字，可用 #6B7280 | 不触发优秀、缺勤或未交条件 |

请假红字只是关注提示，不能生成“违纪/表现不好”等额外结论。

“仅文字”“仅背景”“文字＋背景”均可选；默认只突出文字，不要求全班优秀时全部铺满绿色。

### 10.3 等级匹配与独立评价方案

课堂和作业分别绑定记录实际使用的方案及等级。建议匹配键明确到：评价维度＋schemeId＋实际schemeRevision＋gradeId；复用实际工程等价标识。

- 基础四级可把A选作优秀；细化八级可选A+、A；是否含A-由教师设置。
- A*、A+、A不是同一等级；不同方案同名A不自动套规则。
- 新方案没有规则映射时使用普通字段样式，只在设置界面提示未映射，不能猜测或改分。
- 切换方案/重置评分属于现有评价业务，本轮不重做；本轮颜色必须跟随每条记录实际方案，不跟随当前下拉候选值。
- 班级报告与个人报告可以显式复用同一组兼容规则；无需为每位学生重新配置，但不可未经选择互相覆盖。

### 10.4 业务判断先于颜色

1. 某日全部适用课次确认未出席：该日正式课堂评价为不适用，输出“–”，不被旧残值渲染为绿色A；该日课堂亮点不输出。其他合法日期的亮点不一起清掉。
2. 部分出席：沿用现行日记录资格与已保存合法结果，不自行推导新等级。
3. 作业与出勤独立：请假不自动免做，不自动未交，不清掉实际作业结果。
4. 未登记、未截止、待核对、明确未交是不同状态；未知不得用红色“未交”替代。
5. 选做未参与、明确免做不标为未交，不按0分处理。
6. 真正0分保留；空白不转0；无真实满分不做百分比判断。
7. 格式可以把空值或不适用显示为“–”，但底层状态与校验语义保持不同。
8. 规则不能隐藏问题学生、隐藏明确未交、改评价文字含义、自动确认或发布。

### 10.5 混合内容分别着色

- 班级按日考勤“正常1 / 请假1”：仅请假短语着色，不能混为全天缺席，也不加课次时间。
- 个人课次明细：对应课次的请假/早退单独着色，其他课次状态不受影响。
- “迟交 · A”：提交状态与质量等级可分别着色，不用一个全格红底默认覆盖优秀信息。
- 教师明确启用全格背景时，多规则冲突按明确优先级，不按所谓“最坏状态”猜测。
- 内部健康原因、家庭信息不能作为公开颜色条件，避免通过颜色间接泄露未公开信息。

## 11. 样式来源、继承与冲突

两类报告共用一套确定的、逐属性计算的解析规则。低到高：

```text
模板结构与基础主题默认
→ 表格奇偶行背景
→ 当前报告类型下的元素/字段样式
→ 本次指定日期/作业列或行的细调
→ 命中的条件格式
→ 本次明确的单格呈现微调
```

同层同目标同属性最后明确保存的值生效。条件规则优先级由排序控制，同一属性采用更高优先级匹配；不同属性可以组合。不能由组件挂载或CSS加载顺序决定。

例：课堂数据默认浅蓝底，优秀规则只改绿字，结果应为浅蓝底＋绿字；如果优秀规则同时指定浅绿背景，才覆盖该格背景。

每个属性可查看简短来源，例如“文字：优秀规则；背景：作业质量列；字号：正文默认”。只在编辑器出现，不进入正式图片。

区分两种明确操作：

- **仅改默认**：修改主题默认，保留明确元素覆盖，同时说明哪些目标仍有覆盖。
- **统一此范围的对应属性**：真正统一选定范围，如“统一全部表头背景”；只处理背景，不清空字号、边框、正文、学生选择或规则。

“统一全部表头背景”在个人报告中必须覆盖其课堂表、作业表及已开启的相关表头，而不是只改第一张表。教师选择更窄范围时只作用于该表。

单格微调只改外观，不改文字内容或评价结果；按学生ID＋任务ID＋日期/作业/课次ID＋语义字段定位，不能按屏幕第N行第N列。新增动态作业列、排序、分页或切学生后不得串位。

单格、具体日期、某份作业实例微调默认属于本次报告，保存可复用模板时移除这些实例键。

## 12. 个人批次与单人微调：作用域必须明确

支持以下作用域，常用操作不需要每次弹出确认：

| 作用域 | 行为 |
|---|---|
| 当前班级报告 | 修改这份班级报告，不修改个人报告 |
| 本批个人报告 | 修改本次已选个人报告共同设置，预览换人仍使用共同设置 |
| 仅此学生的本次报告 | 形成该生本次呈现覆盖，不影响同批其他学生 |
| 我的班级模板 | 保存后可复用于未来班级报告，不含本次学生事实 |
| 我的个人模板 | 保存后可复用于未来个人报告，不含学生身份/本次关注内容 |

发布准备中编辑个人样式，默认作用于“本批个人报告”；教师明确选择“仅此学生”才建立个体呈现覆盖。编辑范围始终可识别，不靠当前预览下拉暗中决定。

批次统一设置默认保留已存在的明确单人微调，并给出覆盖提示；教师主动选择统一相应属性时，可清除这些覆盖。与第11节使用同一语义。

支持显式复制班级配色/条件规则到个人，或反向复制兼容部分：不复制布局结构、学生名单、发送对象、私有正文或只属于一类报告的字段定位；不能匹配的字段明确跳过，不能按列序号乱套。

仅选中一个学生生成个人报告，也不能把这个学生ID保存到通用个人模板。

## 13. 发布准备、模板中心与预览联动

### 13.1 发布准备

保留班级/个人开关、学生选择、分页、自定义每页数量、搜索、明确公开内容、交付选项和核对发布。

- 搜索、分页、切换预览不改变选定受众；勾选/取消勾选才改变受众。
- 切模板、改色、开关课次明细不创建发布，不发送通知。
- “修改报告样式（仅本次）”能进入同一精调能力，并识别当前班级或个人批次作用域。
- 展示用的样式、内容可见范围和交付对象是三种独立状态，互不暗中修改。
- 操作未完成、失败或取消时保留已选学生、当前周、任务与有效输入。

### 13.2 模板中心

- 先展示可选模板清单；选中一项后才展示这一项的一份实际报告预览。
- 班级与个人都具备四类配置能力；切换类型时可恢复各自上次编辑对象，不将班级元素编辑器错误套到个人表。
- 支持复制系统模板为我的模板、重命名、保存、设为对应类型默认、归档/删除已有合法操作。
- 系统模板不直接覆盖修改，复制后可调。
- 支持设置搜索、选择元素、复制同类样式、只复制颜色、恢复单元素、撤销/重做。
- 高级参数按需使用，不让普通教师为改请假颜色先遍历几十个字段。

### 13.3 直接选择元素

提供“选择样式元素”模式：点击报告中的日期表头、某个出勤格、个人作业质量列或跟进标题，定位对应设置目标。

同时提供可按名称选目标的方式；普通预览不劫持阅读操作。选中后明确当前是“全部出勤数据格”“个人作业表质量列”还是“本次这个格”。

该模式两类报告都必须可用。不得在个人报告中点击任何表都只选中整份报告背景。

### 13.4 单份实时预览

- 支持班级/某学生切换、原始比例、适配宽度、整体查看、缩放、黑白查看。
- 缩放只改变查看比例，不改报告真实列宽、字号或换行算法。
- 每次仅渲染当前模板的一个当前对象；不把全部个人报告铺成一个长页面。
- 样式修改实时更新；保存、应用到本次、正式发布是不同动作，不显示假保存。
- 切学生时身份、课堂表、作业表、亮点、跟进说明和单人微调全部同��切换，迟到渲染结果不能把上一位学生覆盖回来。
- 无选定个人学生时，可选择合法对象仅用于预览；不得自动加入发送。另用测试样本时必须在操作界面明确，不混入本次真实报告。
- 隐藏模块或无内容模块应释放报告空间；预览器背景空间不等于导出画布，不把巨大空白容器一起导出。

## 14. 数据保��与参数边界

先生成当前受众获准读取的报告数据，再应用样式和条件格式。不得把完整内部记录交给模板，然后只用CSS隐藏。

- 个人报告的“本次关注”“公开观察”保留当前显式选入机制。样式改变不能替教师选入。
- 内部备注、详细私人请假原因、未公开观察等不进入PNG、阅读页或可访问的报告DOM/序列化数据。
- 普通出勤、课堂评分和作业简况按现有班级报告规则展示，不借本轮样式修正改成全部隐藏。
- 模板不能执行任意脚本，不能使用任意HTML/CSS/外链资源输入绕过内容边界。
- 预览只能更改外观；修改成绩返回现有编辑入口，本轮不提供在图片预览直接“改成A”的路径。
- 模板保存不保存具体学生、周次日期、实际成绩、具体作业、公开观察选择或本周正文。
- 切换任教任务、同名分工、学生重名、不同教师时，配置与数据通过稳定ID和当前合法上下文隔离，不按显示名关联。

## 15. 保存、应用、输出与历史

### 15.1 保存语义

| 动作 | 结果 |
|---|---|
| 调整属性 | 更新当前编辑候选与对应预览，不自动发布 |
| 保存主题 | 保存颜色资源，不改变成绩或结构；取消编辑回到进入编辑前值 |
| 保存样式/模板 | 保存可复用结构、元素参数和合法通用规则，不夹带真实学生数据 |
| 应用于本次 | 将当前有效组合应用到指定报告作用域 |
| 设置班级/个人默认 | 对各自后续新准备报告生效，直到教师再修改，不增加“下期开始”调度 |
| 正式发布 | 沿用现有发布校验与快照，冻结当次内容、受众、模板与有效样式 |

保存模板不等于向家长发布。预览候选、已保存模板、本次已应用的配置应能清楚区分，但不要为每个步骤增加冗长说明。

正式导出必须使用与相应预览一致的有效配置。若正在预览尚未应用的候选，导出预览稿采用候选，正式发布采用已明确应用并核对的配置；不能静默导出旧样式。

### 15.2 输出

- 模板中心预览、发布准备实时预览、发布前核对、PNG、ZIP内每一份报告、现有模拟阅读页使用同一数据格式化与样式解析。
- 班级默认一张完整长图；个人默认每名学生一份完整主报告。附表或分张由教师明确选择，不自行拆页。
- 输出包括完整学生集合/个人完整周数据，不只捕获编辑器当前分页、滚动可见行或虚拟列表已挂载部分。
- 1×/2×/3×等倍率仅改变输出清晰度，不能改变相对字号、列宽、数据范围或样式规则。
- 字体加载完成后再渲染；字体缺失、安全回退、超宽/超长或输出失败明确提示，不交付缺字/裁切/少学生的成功图片。
- 超出实际导出能力时提供调整宽度、参数或教师明确拆分的动作，不静默截断。
- 选择框、焦点框、条件来源提示、预览控件、模拟状态、保存提示均不进入正式报告。
- 修改个人模板后，批量PNG/ZIP中的每一位学生都采用正确模板、规则和个体微调；不能只更新当前预览学生。
- 已发布历史沿用当时内容与样式快照；本轮无需新建“评价方案更换历史”或多轮草稿管理。

### 15.3 可读性检查

按实际文字前景与最终叠加背景检测对比度。本项目可采用4.5:1作为普通文字的默认预警目标；此为本轮验收参数，不构成整站无障碍认证声明。

预设配色须通过该检查。教师自选低对比组合时就近提示，并提供建议可读文字色或恢复选项；不偷偷改色、不隐藏成绩、不靠整格透明度处理。

保留“请假”“未交”“A+”等实际文字，不只用色块表达状态。黑白查看中仍能辨认基本结果。两类报告及个人明细均检查。

## 16. 实现一致性要求

具体文件名和实现方式由当前工程决定，必须实现以下逻辑职责，不要求机械新建同名服务：

1. 获准报告数据投影：班级/个人范围不同，共用来源事实。
2. 语义字段注册：日期、姓名、出勤、课堂等级、作业提交、作业质量、分数、课次、说明等。
3. 有效样式解析：字段样式、实例细调、条件格式逐属性组合，可解释来源。
4. 条件规则执行：只对合法结构化数据求值；有确定优先级与空值处理。
5. 统一输出：不同结构模板使用共同参数和规则，而不是另写一个忽略参数的个人渲染分支。

样式必须绑定语义字段和稳定对象，不依赖CSS nth-child或显示文字匹配。班级出勤在列中、个人出勤在日期行中，仍可识别为同一种数据语义，但各自样式值独立。

不要将所有逻辑写成模板名的固定分支；也不要为本轮重建全套后端、数据库、排课或评价系统。

## 17. 演示数据与最低验收（班级、个人都必须实际操作）

使用明确合成样本，不照抄截图中的真实学生姓名和错误业务数据。新增示例正文与所选学科相符，不把数学向量正文混到计算机反馈中。

至少有：12人基础班、53人分页班、123人长表压力样本；一个教师两个分工；课堂和作业采用不同方案；非授课日检查作业；同日两份作业；同日两节课。

- 请假但作业已提交且优秀。
