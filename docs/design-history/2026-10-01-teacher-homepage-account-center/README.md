# 教师主页与账号中心 · 设计与实现记录（2026-10-01）

状态：**现行（待 Owner 核验）**。本文补记此前未成文的教师主页、账号中心设计与实现，并记录本轮“头像只保留一处修改入口”的调整。

## 1. 两个页面的职责划分

| 页面 | 路由 | 定位 | 谁能看 |
| --- | --- | --- | --- |
| 账号中心 | `/account` | 我自己的账号、教职工身份、**个人资料（头像 / 显示名）**、教师主页设置 | 仅本人（在职教职工） |
| 教师主页 | `/people/[id]` | 面向同事的公开名片：教学介绍、教学概况、留言 | 本人；主页设为“本校教职工可见”时，本校在职教职工也能看 |

原则：**账号中心管理“我是谁、我的设置”，教师主页负责展示与交流**。同一份数据只在一个地方编辑。

## 2. 头像与显示名（本轮调整）

- 问题：账号中心和教师主页（“头像与显示名”弹窗）都放了头像编辑器，用户分不清应在哪里改、两处是否同步。
- 决定：**头像与显示名只在账号中心「个人资料」中修改**。
  - 教师主页删除“头像与显示名”弹窗；主页头部仍**展示**头像（名片需要），主人自己看时，原按钮改为跳转链接“在账号中心修改头像与显示名”（`/account`）。
  - 账号中心说明文案改为：“头像与显示名只在这里修改，用于顶栏、教师主页、留言与通知，不改变正式档案。”
- 头像规则（`identity-editor.tsx` / `lib/profile/store.tsx`）：
  - 仅 JPG、PNG、WebP 静态图片；GIF 或动态头像明确拒绝；上限 2 MB（`AVATAR_MAX_BYTES`），超出时提示实际大小。
  - 流程为“选择 → 预览 → 确认 / 取消”；可恢复缺省头像。读取失败、取消或保存失败时保留原头像。
  - 只能修改自己的头像；账号不可用时拒绝。原型中只保存在当前浏览器会话。
- 显示名：从正式姓名派生，不能自由输入，可选 `正式姓名` / `正式姓名 + 英文名` / `英文名 + 老师`（有英文名时）。显示名与正式姓名不同时，主页同时标注“正式姓名 xxx”。
- 头像组件 `StaffAvatar` 在顶栏、主页、留言、通知中复用，数据来源相同。

## 3. 账号中心（`components/profile/account-center.tsx`）

自上而下的卡片：

1. **个人资料**：头像、主页显示名（唯一编辑入口）。
2. **账号**：姓名、用户名、所属学校、账号状态；操作：修改密码（`PasswordModal`）、权限诊断（演示，用普通语言解释“动作 × 对象范围 × 内容状态”）、退出登录（普通退出，非安全撤销）。
3. **教职工身份**：教职工编号、任职状态、部门、岗位、系统角色、当前职责。只读，由学校管理员维护。
4. **联系方式**：手机、邮箱。只读的人事档案信息，明确说明不是登录 / 验证 / 找回密码渠道；原型不提供账号恢复设置。
5. **教师主页**：有主页的账号可在这里直接修改主页设置（与主页上的“主页设置”是同一份），并查看介绍是否已填、留言 / 回复数，以及“查看我的主页”入口。没有主页的账号说明原因（仅任课教师与班主任有主页），不影响其他功能。

非教职工（家长、匿名）或无效账号进入时显示 `HomepageDenied`。

## 4. 教师主页（`components/profile/teacher-homepage.tsx`）

- **谁有主页**：在职的任课教师与班主任（`hasTeacherHomepage`）。其他教职工没有主页，人名处不渲染为链接（`TeacherLink`）。
- **访问判定**（`homepageAccess`），拒绝原因分开提示：
  - `not_staff`：家长 / 未登录；
  - `invalid_staff`：访客账号不在职；
  - `not_found`：主页主人不存在；
  - `no_homepage`：对方没有主页；
  - `private`：主人设为“仅自己可见”。
- **头部**：头像、显示名（可附正式姓名）、部门 · 岗位 · 学校、当前职责徽章。主人自己看时显示“我的主页”徽章、“在账号中心修改头像与显示名”链接、“主页设置”按钮，以及当前可见范围 / 留言开关状态。
- **教学介绍**：最多 300 字（按字素计数，emoji 计 1 字）。主人在原位编辑，访客只读，未填写时显示占位文案。
- **教学概况**（侧栏，只读）：当前学期的任教学科、课程、主要任教班级（同一教学班的多个分工合并为一行，最多 6 行，其余显示“另有 N 个班级”）。只展示工作信息，不含学生名单。
- **主页设置**：可见范围（本校教职工可见 / 仅自己可见）、留言开关。从账号中心“编辑主页设置”带 `#settings` 进入时，自动打开设置弹窗。

## 5. 留言、回复、点赞与通知

- 留言和回复最多 300 字，支持文字与 emoji，不能为空。回复只能引用主留言（只有一层）。
- 权限：
  - 点赞要求主页可访问；
  - 发表留言 / 回复还要求留言开启；
  - 删除：作者可删自己的内容，主页主人可删自己主页上的任何内容。
- **快照与重新校验**：访客看到的是“打开页面时”的主页状态。主人在别处修改设置时，访客页面不会自动变化；访客提交时按最新状态重新校验。被拒时说明原因（已关闭留言、已改为仅自己可见、引用的留言已删除等），并**保留输入框中的内容**。
- 网络失败：提示“提交未完成，内容已保留，可直接重试”。
- **通知铃**（顶栏 `NoticeBell`）：有人在我主页上留言，或回复了我的留言时生成通知，显示未读数。打开时按最新状态解析：内容已删除 / 主页已转为私密 / 无权限时分别提示，不显示过期正文。

## 6. 原型演示控件

教师主页侧栏的虚线框中（仅原型）：

- “下一次提交模拟网络失败”；
- 访客视角下模拟主人关闭留言、设为仅自己可见，用于演示快照与重新校验；
- 重置主页与留言示例数据。

示例数据：部分教师预置头像（`/demo/avatars/*.png`）、显示名风格与教学介绍，其中一位预设为“仅自己可见”。

## 8. 验收要点

- 教师主页上不再出现头像上传 / 显示名编辑；主人看到的是指向 `/account` 的链接。
- 在账号中心更换头像后，顶栏、主页头部、留言作者头像同步更新。
- 访客看到的教师主页仍显示主人头像。
