## 1. 真实路由

| 路由 | 用途 |
|---|---|
| `/teaching` | 我的教学任务列表（周选择、搜索、状态筛选、口径卡片、任务行“显示自定义分工”开关） |
| `/teaching/schedule?week=N` | 保留的简版“本周教学安排”：每个有效课次一张课卡，点击进入该任务整周反馈 |
| `/teaching/task/[id]?week=N&from=…&back=…` | 任务工作区：整周反馈 / 作业 / 发布与历史 / 教学计划 |
| `…&student=<ID>` | 学生详情抽屉（URL 驱动，可刷新、可直链、上一位/下一位） |

## 2. 模拟数据来源与持久化方式

- 数据来源：交付包 `fixtures/demo_scenario.json`，转写为 `lib/mt/model.ts` 中的模拟场景（示例林老师 Lynn，4 个任务：高一2班计算机整科、高一1班数学 P1、高一2班数学 P1、高一2班数学 S1）。
- 持久化：浏览器 `localStorage`，按变体命名空间 `tgs-mt-r3:biz:<variant>` 存储业务数据，`META_KEY` 存当前变体和故障注入开关。不是正式数据库，不跨设备同步。
- 重置：原型演示控制中的“定向重置”只清除当前变体命名空间，不清除其他模块或全部浏览器数据。
- 作业归期口径（原型回退）：当前没有产品级归期规则时，原型按截止日期归期，无截止日期的按布置日期归期，并保留“查看本任务全部作业”入口。**这只是原型核验口径，不代表产品政策已修改。**

- `components/mt/*`：任务列表、周选择器、简版周安排、整周反馈表、学生抽屉、常规确认对话框、作业、教学计划、发布面板、工作区外壳与离开保护、共用保存状态控件。

- 本归档目录：提示词、设计、核验清单、README、fixtures/checks 副本及 `evidence/` 截图。
