# 整张课卡中的教师与地点文字样式（2026-10-19）

## 需求与理解

Owner 原文：“设置页中，整张课卡下，除了可以设置对象样式，还应增加设置教师和办公室。”Owner随后明确确认：“分别设置课卡中教师姓名、办公室／教室文字的颜色、字体等样式”，与当前实现一致。该轮不增加按地点分类整卡配色，也不修改任课教师或实际排课地点。

## 页面与视觉

教务显示样式的“整张课卡”中，保留设置对象，增加三个内容部位：对象样式、教师姓名、办公室／教室。选择教学对象后，可分别设置各部位颜色、背景、字体、字重，实时预览及独立恢复。对象样式保留原CARD偏好；教师、地点的背景仅覆盖相应文字片段。部位切换放在对象选择下方，沿用现有紧凑绿色按钮和双列预览，不重排导航或既有顶级类别。“按教师”整卡默认配色继续保留。

预览显示对象名称、教师姓名与真实地点；显示和课卡共用 StyledCardText 与字段解析器。当前选中教师或地点部位时，右侧背景明确为“文字底色”，恢复按钮为“恢复此部位默认”，避免误清整卡。切换对象、类别或部位时清除未保存候选预览。

## 数据与样式边界

课表仅有 entry.room，表示实际上课/活动地点，没有教师个人办公室字段。用户所说办公室以现有地点行进行样式设置；不从人员部门填充办公室，不虚构地点。room为空仍显示“未排教室”，说明样式会用于同对象已排地点的课卡。

新增 CARD_TEACHER_TEXT/CARD_ROOM_TEXT，以当前浏览者 + admin + 部位 + className 保存，与原CARD、TEACHER、SUBJECT、HOMEROOM互相独立。仅作用于教务非活动课卡；活动沿用其原整体样式。未设置/清除后的教师行和地点行保留原文字默认，不继承只用于标题的整卡颜色/字体。原教师端TASK/CLASS/COURSE规则未改。

教师行仍仅在教学班/行政班等 showTeacher=true 的视图出现；选择单教师时不重复显示姓名。文字样式不影响冲突/待核对、过去锁定、停课、草稿、补课状态、不改搜索内容或排课版本。
