## 1. “我的教学”成为三个视图的统一入口

### 1.1 三种视图及用途

| 视图 | 查看单位 | 主要动作 |
|---|---|---|
| 教学任务 | 本人真实教学班／规范分工或整科任务 | 班名查看班级详情，开始／继续填写、准备发布、查看反馈保持直达 |
| 课次安排 | 每个有效实际课次 | 原位打开课次详情，补充可选观察；明确选择才进入日记录或整周反馈 |
| 按日记录 | 同任务、同实际日期合并的日卡 | 原位填写当天全班记录，补充亮点、小结，布置作业或预览周反馈 |

三者共用本人有权任务、学校、学期和所选反馈周期，不维护三套任务、课表或反馈数组。不新增侧栏一级入口。

任务列表已有班名直达统一详情、学生资料、班主任主页、个人显示设置以及直接填写／发布能力保留。不同班同名 P1、同班 P1/S1、整科任务都按稳定身份区分，不按标题文字定位。

### 1.2 入口、返回和浏览状态

- 日常用户不再必须经历“我的教学→本周教学安排→独立日记录页”三层路径。
- 既有本周教学安排链接解析为“我的教学”中相应视图；旧日记录深链接解析为该背景视图及对应日记录弹窗。复用组件，不保留另一套功能分叉的独立记录页。
- 显式任务、日期、周期和视图优先于浏览偏好；未指定时可以恢复本人上次合法视图。没有有效偏好时采用合理默认，不强制每次先选视图。
- 周次、任务范围及共享搜索只出现必要的一份。不同视图不适用的筛选不能暗中生效；各视图可以记住自己有意义的筛选和滚动位置。
- 日记录内的“只看待处理”、学生搜索等仅影响查看，不变成周反馈发布范围。
- 关闭弹窗、返回视图、浏览器前进／后退和刷新，恢复正确任务、日期、周期及合法来源；不能刷新后默认跳 P1、当前周或另一个班。
- 无权／无效的显式目标明确拒绝或提供合法返回，不用另一个学生或任务伪装打开成功。
- 保留“我的完整课表”入口，进入同一真实教师的完整课表。侧栏“我的课表”仍独立；普通教师不能误入课表中心，也不固定出现“返回课表中心”。

## 2. 日卡打开原位“本日快速记录”，不是把整页压进弹窗

日卡仍负责正式本日综合评价，只改变打开方式，不退化成单课次参考弹窗。

### 2.1 必须能够完成的操作

- 清楚识别当前教学任务与实际日期，必要时查看合并的真实课次、时间和地点。
- 查看本日适用学生、出勤、本日评价、已有异常及简洁的处理状态。
- 搜索学生、只看待处理、进行明确的本日常规确认。
- 选择常见原因并补充说明，添加／查看亮点，按需编辑个人内部备注及可选本日小结。
- 查看相关课次观察和当前实际采用的评价标准。
- 继续使用已有学生资料和学生反馈详情通路；查看资料不创建或确认反馈。
- 轻量“布置作业”和明确的“预览周反馈”。

不需要把所有能力都做成同等显眼的常驻按钮，也不要求每行永久展示空备注输入。已有内容必须可辨认、可查看和修改；不要为了简洁让已填内容消失。

### 2.2 删除冗余表达

- 教学任务名称、实际日期和保存状态清楚表达，避免重复多份。
- 不显示 `DEMO_STU_01`、`TASK_CS_WHOLE` 等内部模拟键，不把内部键冒充学号。正式学号在确有需要且有值时显示。
- 移除整段常驻的“一天一条评价／同一份数据／分母计算”等技术与规则说明；详细依据按需查看。
- 不重复显示周次、基准日、“有效名单”长文、课次数与已发生数量的多份同义摘要。
- 保存失败、权限失效、待核对问题和批量作用范围属于必要信息，不能一起隐藏。
- 演示详细参数使用已有演示控制；实际生效的模拟时钟／故障场景保持必要的简短可辨提示，不在每页重复长说明。

### 2.3 原位操作和输入保护

- 普通合法修改自动保存到同一模拟业务存储；查看、打开、关闭不产生评价事实。
- 正常保存后关闭不反复要求确认；未保存或保存失败时保留输入，提供可理解的恢复动作。不能用关闭弹窗表示删除整周期草稿。
- 可在当前记录上下文中明确切换到下一张合法日卡／待处理日卡，不自动跳走。切换前处理在途保存，下一张目标可辨认。
- 完成待处理筛选中的学生后，不突然移除正在操作的行、关闭编辑或跳到别人；结束当前操作再更新可见结果。
- 单课详情、日记录、学生详情、原因选择与周预览不要层层叠出多个争夺焦点的模态窗口。按需切换当前操作内容，返回恢复前一上下文；普通下拉选项可以正常使用。
- 弹窗关闭后恢复背景的视图、周次、筛选、滚动和触发位置。键盘、触屏和页面滚动均可用，现有页头不得遮挡内容或与弹窗重复出现。

## 3. 日卡与已有课堂事实继续同源

### 3.1 合并与记录单位不改变

同一学校、同一教师实际责任／真实教学任务、同一实际日期形成一张日卡。任务包含真实班级及规范分工或整科目标。

连续或不连续课次都可合并；不同教室或个人课次文字不拆卡；不同任务、教师责任或班级不合并。日卡不成为长课次，不参与拖拽排课。

两节及以上显示“合并 N 节”等明确含义，具体视觉由你设计，不只靠颜色。第3、5节不能称为连堂。原始课次数不随卡片合并而减少，时间与教室仍可对应到具体课次。

正式评价保持“学生＋真实任务＋实际日期”的一份综合评价；出勤保留唯一课次明细及学生适用范围。弹窗、周矩阵、学生反馈抽屉、工作台和任务进度读写同源，不加“同步／导入日记录”步骤。

### 3.2 按日常规、按需课次例外

- 当天只有一个课次，出勤直接编辑这一条，不再展开一份内容相同的重复控件。
- 多课次常规出勤可以按明确范围一次处理；出现部分请假、在他班等差异时，才编辑必要课次明细，不把第一节状态覆盖全天。
- 班主任准确覆盖课次的既有请假直接关联，任课教师不重复选择或输入。来源冲突、部分覆盖或实际到课不同才核对；不反向修改原请假申请。
- 考勤原因、可选亮点、小结和备注缺失，不自动增加评价待办。已确认的迟到是例外事实，不等于未处理。
- 综合待处理人数按学生去重，不把同一学生的出勤缺项、评价缺项相加成两个人。
- 全天全部适用课堂均未参与时，核对评价适用性；保留原等级与来源，不静默清空，也不让无依据的 A 继续被当成正常完成。部分请假但有实际可评价参与，可以保留有依据的日评价。
- 明确不评价、不适用与尚待判断不同；不增加“不评价理由必填”。

### 3.3 阶段记录、评价方案与状态

- 复用当前任务周期实际绑定的四级／八级／文字方案，A＝优秀的既有系统预设不改。不能从不同入口临时读取教师最新默认来替换原标准。
- 上午已填写手动 B、下午还有适用课堂：保留 B 和已处理覆盖，不提前确认下午。下午发生后可沿用 B 确认新增覆盖，不要求重新选 B，也不用默认 A 覆盖。
- 当天只有上午适用的学生，可以完成自己的范围；不能强迫等不适用的下午课堂。
- 最后适用课次结束后才首次填写，可以一次完成，不增加第二个启动或结束教学日动作。
- “确认本日常规”只作用于当前任务、当前日已发生且适用的范围。默认覆盖本日全体适用学生，不被搜索／分页静默缩小；已有明确子集操作保留并显示范围。
- 保护手动值、已处理内容、明确留空和异常；只对尚未处理的常规部分采用本对象方案中的默认。无默认等级时不猜最高档，明确哪些评价仍需判断。覆盖确认与改分分开。
- 时间流逝不自动评分或扩大确认范围。未来、停课、无适用对象、目标待匹配、无权和读取失败分别表达。
- 日卡继续使用“待评价／评价待补N人／评价进行中／评价已完成／无需评价”等准确状态；已发生事实不因日期过去而被假定存在。考勤待核对按需单独提示，不重复堆同义标签。
- 未来日卡可以查看安排、合法信息和提前布置作业，但不铺开整班禁用评价表，也不写入实际课堂观察和出勤。
- 周矩阵保留摘要式编辑、学生反馈详情，不恢复含糊的“本周”逐生比例列。

## 4. 考勤原因：常见选项＋可选补充

把原因选择接入日记录弹窗、周矩阵单元格、学生反馈抽屉、课次考勤核对等既有入口，复用同一选择逻辑和实际记录，不只修一处。

### 4.1 选择行为

- 先明确出勤事实状态，再提供与该状态适用的常见原因。
- 通常一个主要原因＋可选补充即可；不默认设计成复杂多选分类表。
- 支持搜索常见原因、直接选择、清除，以及直接手写。没有匹配项也能完成记录。
- 原因整体选填；选“其他”也不强制说明。教师不知道原因时可选择“原因待核实”，但这不等于出勤事实未核实。
- 不自动预选上一名学生的原因，不从成绩、姓名、历史病假或私人观察推断原因。
- 正常状态不需要填写原因；现有常驻原因框若保留则禁用且标题可理解，不能给正常状态预填异常原因。
- 异常状态变化时重新核对原因适用性，不静默带入明显不适用的原因。需要清除时明确处理；原有历史不删除，补充文字不会在无提示下丢失，也不继续伪装成新状态的有效原因。

### 4.2 系统初始常用项

以下作为本原型初始建议内容，不冒充学校批准的请假政策。允许教师使用自己的通用表达，但不改变状态本身。

| 状态 | 初始常用原因 |
|---|---|
| 迟到 | 交通延误、上一项活动延时、临时身体不适、临时事务、原因待核实、其他 |
| 早退 | 身体不适、就医安排、家庭事务、校内其他安排、原因待核实、其他 |
| 请假 | 身体不适、家庭事务、校外比赛、学校活动、其他个人事务、原因待核实 |
| 缺勤 | 原因待核实、已核实未返校、行程延误、其他已说明原因 |
| 在他班 | 临时调班、参加其他教学安排、补课／辅导、其他 |

正式状态继续使用现行正常、迟到、早退、缺勤、请假、在他班等字典，不开放任意改义。

### 4.3 状态、原因与来源分离

- 选择“校外比赛”不是批准请假；选择“身体不适”不自动将缺勤改成请假。
- 原因文本只说明当前记录，不能创建请假申请、审批通过、行为扣分、预警或家长通知。
- 明确的教师考勤更正更新已有唯一明细；自由文本写“迟到”不会自动改考勤。
- 已有班主任请假及来源文字按当前权限查看；私人模板选择不篡改来源或批准状态。
- 原因和内部补充不因本次增加选择器而自动进入家长输出，继续遵守既有字段可见性。

## 5. 学生亮点：可采用、可修改的常用短语

### 5.1 轻量填写

在日记录、已有矩阵亮点入口和学生反馈抽屉使用同一短语能力及同一亮点记录。

提供可搜索的系统常用短语、本人收藏／自建短语和自由填写。教师明确选择后，可直接加入当前学生的亮点草稿，能够修改或撤销；不要增加“选择→插入→添加→再保存”的重复步骤。

日卡来源可带入本任务和当天；已有周级亮点保留其原含义，不强迫为所有历史亮点补一个日期。

建议初始内容：

| 类别 | 示例短语 |
|---|---|
| 课堂参与 | 主动解释解题思路；提出了有价值的问题 |
| 思维与表达 | 尝试了不同解法；能够清楚说明推理依据 |
| 学习习惯 | 主动订正并解释错因；认真核对关键步骤 |
| 合作沟通 | 帮助同伴理解知识点；清楚展示小组讨论结果 |

分类仅帮助查找，不是新的必填评价维度。允许直接使用短语，也允许改成更具体的事例；事例可选，不再增加必填证明表单。

### 5.2 事实与历史保护

- 选择由教师明确作出，表示教师确认这件事适用于当前学生；不根据 A／A+ 自动生成亮点，不默认给全班套同一句。
- 亮点可空，不增加日评价或周反馈的必填门槛，不产生“缺亮点”待办。
- 日记录添加后，学生周反馈详情读取同一条亮点；不是复制一份周亮点。
- 同一学生、任务、日期的一次操作重试或误双击不重复创建；不同日期确实发生相同行为时可以再次记录，不能按全文全局去重。
- 已有个体评语不被选择短语覆盖。添加亮点不自动发布；普通草稿更正不改变已发布快照。
- 单课观察只有经教师明确采用，才成为亮点；不能因为复用选择器，自动把内部参考和全班观察变成学生个人事实。

## 6. 教学设置中的“常用内容”保持轻量

在已有“我的教学→教学设置”内提供“常用内容”，覆盖考勤原因和亮点短语，不新增一级模块或另建评价方案系统。

支持系统常用内容与我的常用内容：

- 系统项可直接使用、收藏；需要修改时保存为自己的条目，不改系统原文和其他教师内容。
- 个人项支持新增、修改、停用／删除及常用排序或收藏；考勤原因能够声明适用状态。
- 不要求教师先配置才能开始记录，初始系统项立即可用。
- 普通文字输入不自动进入常用库。只有明确保存为通用内容才创建条目，不自动收集学生姓名、健康或家庭细节。
- 常用库按真实学校和教师隔离；已有结果是否可被班主任／家长读取，遵守结果本身权限，不因此开放个人库。
- 实际学生记录保存当时选择／编辑后的文字及必要来源。以后修改、停用或删除模板，不改写已保存文字和历史发布内容。
- 既有自由文本继续可读可改，不强迫匹配为某个新模板；没有匹配项不清空原文。
- 使用安全文本及合理输入校验，复用现有中英文界面资源；教师自建正文不自动翻译。

本轮不建设模板审批、复杂模板版本树、全校共享市场、AI 自动推荐或批量给全班生成亮点。不要把轻量快捷填写扩成配置平台。

## 7. 发布语义锁定：按日记录，按周汇报

### 7.1 唯一入口含义

日记录弹窗提供“预览周反馈”，不使用“发布本日”“发送课堂记录”或含糊的直接“发布”。这是辅助快捷入口，不要求教师每次记录完都发布或先提交一天。

点击直接调用现有统一周反馈准备／预览能力，不经过周反馈矩阵中转，不复制“日卡版发布器”。

可以在当前“我的教学”工作界面原位切换至周反馈准备；明确显示已从本日记录切换为整周范围，返回恢复原日卡。不要叠加一串发布弹窗。具体呈现由你设计。

教学任务列表、工作台及整周编辑器的既有发布入口继续调用同一流程；日卡只是增加一个可直达的来源。

### 7.2 来源日期只定位周期，不限制内容

例如教师从“9月30日，高一2班·计算机”日卡点击后，应看到：

“第5周周反馈｜高一2班·计算机｜9月28日—10月4日”。

它读取这个教学任务整个反馈周期的上下文，不能仅包含9月30日。该示例用于验证语义，不硬编码具体日期、班名和人数。

默认范围：

| 对象 | 解析规则 |
|---|---|
| 任务 | 来源日卡真实教学任务及当前有权责任；不自动选择其他分工或其他班 |
| 周期 | 来源日实际日期所属的学校反馈周期；历史日卡进入历史周期，调休补课按实际日期归属 |
| 课堂 | 该任务本周期完整课堂上下文，包括已处理、尚待处理、未来、取消或不适用的真实区别 |
| 学生 | 按本任务本周期的合法适用关系解析，不仅是来源日适用、到课或当前可见的学生 |
| 作业 | 按既有归期及纳入规则的实际相关作业，不仅是从这张日卡布置的作业 |
| 总结与评语 | 当前任务／周期已经保存的周公共总结、学生亮点和个体评语，按其真实含义及发布权限使用 |

日卡的搜索、仅待处理、分页、所选学生和来源课次，均不得隐式传成发布范围。它们只用于返回和必要定位。

同任务同周期，分别从周一或周三日卡进入，在数据版本相同时应得到相同的默认周范围及内容。不得为每张日卡另建一份待发布周反馈。

同校同班同期本人有权且兼容的任务，继续支持已有明确组合操作；不自动勾同事任务，不新增跨班合并平台。

### 7.3 预览是完整核对，不是过滤掉问题后假装完整

- 进入前等待相关在途保存完成，核对最新已保存版本。保存失败保留输入，不发布旧内容；无关任务的未保存修改不会被顺带纳入。
- 浏览预览不确认课堂、不生成发布版本、不发通知，也不建立多轮命名草稿。
- 周中可以预览，看到已记录内容和后续安排。未来课堂不填正常／A，不当作漏交；普通流程继续记录，按周整理。
- 已发生但待处理的记录要可见并可定位，不自动从预览移除以获得“全部通过”。
- 从预览能完成必要的总结／评语编辑或打开相关问题的既有编辑通路；处理后回到同一次准备，保留任务、周期和明确选择。不能再次强迫先去周矩阵首页找对象。
- 权限、对象、受众关系不明、未保存或版本冲突、拟输出不允许内容等真实阻断必须处理。
- 疑似未交未核实不能作为已证实负面结果外发；沿用核实或明确本次暂不纳入。暂不纳入不改作业责任、不免做、不清除原待办。
- 可选小结、总结、亮点和个体评语为空，不新增必填阻断；原因选项没填也不自动阻断。
- 没有有效可发布内容不制造空报告，但允许查看准备情况和合法返回。

### 7.4 常规周反馈与提前阶段发布

正常使用方式：平时日卡记录，准备整周反馈时核对并明确发布。不要增加“日反馈／周反馈”开关、日报模板或每天发布提醒。

- 本任务只有周一一节课，也仍是该任务本周期的周反馈，不是日报。
- 本周最后一次课结束，不自动等于相关作业已处理或周反馈已发布。
- 不新增必须等到周日、某个全校固定时刻或所有未来课发生后才可预览／发布的时间锁；遵守现有学校安排及合法阶段发布规则。
- 已有提前阶段发布保留为明确的例外：教师主动选择，在同一周反馈中标明本次已核对范围或截至时间及仍有后续安排，不宣称整周全部完成。
- 来源日卡不是阶段发布截止日。周五从周一日卡进入，不能默认只发布到周一。
- 本轮不取消已有合法范围选择，但不默认按某一天发布，也不设计每张日卡一份报告。
- 后续新增课堂或作业结果，通过同一周期的补发布／更正与历史能力处理。保留此前仍有效的已发布内容，不因本次选择新日期就无声删除旧覆盖。
- 切换阶段范围必须明确，不靠修改真实课次、任务归期或学生名单来凑出某个报告范围。

### 7.5 确认发布与对外内容

- 确认动作明确当前周反馈任务、周期、内容范围及受众；预览入口本身不发送。
- 发布前重新核对保存内容、范围、权限和版本。预览后内容变化时重新校验，不发布与教师刚看到的不一致的旧快照。
- 发布写入不可变模拟快照、实际发布时间和明确范围；重复点击／响应丢失重试不重复创建版本。
- 家长结果使用真实正式任务名称与该结果实际采用的评价标准；个人显示分工不被冒充为全校正式定义。
- 保留各日真实等级，不自动取最后一天／最低档或平均成周等级；不同评价方案的同名字母不混算。
- 作业独立显示其实际任务及学生结果，不按课次复制。日小结可供教师整理周公共总结，不自动拼接或覆盖；课堂参考、个人内部备注、内部请假原因和未采用的观察不自动外发。
- 家长只看到公共教学信息和自己孩子的获准结果。按行政班内部核对不等于把整班评价表发给每个家长；受众读取真实监护关系，不从教学班名字推断。
- 原型沿用首次发布的受众与内容快照规则，缺少联系方式不伪造送达。未有可验证监护关系不自动发给任意联系人。
- 发布后修改课堂事实、短语或评语，只产生未发布变化；不改旧报告、旧图片，不自动重发。重生成旧版输出使用旧快照。
- 发布、图片生成、下载、人工送达和家长已读分别记录。现有图片失败重试不重复发布；未接真实渠道不能声称已经通知家长。

保持三个状态独立：日评价已完成／当前周反馈待发布／某版本周反馈已发布。日卡不因有发布入口就把三者合并为“完成”。

## 8. 其他已实现能力的保留边界

### 单课次参考与完整课表

课次安排单卡及完整课表普通浏览继续原位显示详情。本课教学观察、指定学生课次观察仍可选、共享、只作参考；不恢复独立逐课次等级，不要求全班每节都写观察。

正式考勤更正只更新选定学生和真实课次的唯一事实。课次参考自由文本不自动改考勤、日评价、亮点、进度或发布。

完整课表明确编辑上下文保留教学对象、生效范围、规范分工、自定义分工、本课备注、教室，以及空格新增、真实拖拽、导入、学校更新采用、差异和跨周放弃。不增加星期／节次下拉替代拖拽，不以观察入口解锁受保护排课。

三个视图继续读取同一身份、实际周期、本人已应用版本、校历与系统时间。未应用草稿不进入日记录；移动、重新导入或取消安排不悄悄挪动或删除已发生事实与参考。

### 日卡轻量布置作业

必须保留，不能因弹窗精简删除：调用同一布置表单，带入真实任务，使用明确适用名单及布置时有效的作业方案，成功时系统时间为布置时间。历史日卡不回填过去发布时间，实际到课名单不等于作业适用名单。

成功后能在已有作业管理找到同一份作业，返回日记录不丢输入；重复点击不重复创建。课次移动或删除不删除作业，不自动改截止或创建副本。

沿用已确认的截止和锁定规则，本轮不重新定义。未来日卡在有权时可提前布置作业，不因此允许记录未来课堂事实。

本轮不全面改造作业页面、批量登记／评分和统计。周预览中处理已有作业问题属于必要通路，不代表启动第二阶段。

### 评价方案、人员资料与权限

保留多套系统／个人评价方案、课堂／作业分别默认、明确生效与历史修订保护，不重做方案库。常用短语不是评价方案，不增加评分标准版本流程。

班名直达详情、成员姓名查看学生资料、班主任校内主页及真实对象权限继续可用；管理员或班主任身份不自动获得同事草稿和个人常用库。

## 9. 保存、失败和原型实施要求

- 使用当前共享组件、业务模型及模拟存储，做必要的最小增量。不强制新技术栈、新微服务、新 Schema 命名或复杂事件平台。
- 刷新能恢复已保存的日记录、原因、亮点、个人常用内容及已有发布结果；浏览偏好不改变业务事实。
- 保存按发起时的学校、教师、任务、日期、学生、字段和版本绑定；快速切换和迟到响应不串写，不用旧整表覆盖新单字段。
- 取消未保存输入只影响对应本地内容；关闭不删除已保存日记录，放弃课表草稿不删除课堂参考。
- 失权后不继续可编辑或由缓存恢复受限内容；错误、未知与真实零值分开。
- 不通过清空全部本地存储、重置全校模拟数据或改固定日期来掩盖问题。需要修正旧样例时只定向处理本轮对象并说明影响。
- 现有正常教学日、部分请假、手工等级、跨周补课及发布历史应能继续用于验证，不把截图人数、日期、版本写成业务常量。
- 不新增人员编号、人事管理、审批、教室占用查询、全校学生目录、评分自动排名、真实 AI 或家长门户。
- 不声称纯前端隐藏证明产品权限安全；原型至少按真实模拟身份和有权对象工作，正式安全实现留待产品阶段。

## 10. 必须实际操作核验

逐项记录 PASS／FAIL／NOT_RUN 与实际证据。可以结合当前已有自动化检查，但编译、静态截图或直接修改 store 不替代浏览器操作。

| 编号 | 必验场景与结果 |
|---|---|
| T01 | 从侧栏“我的教学”直接切换三种视图；日卡不经中转页即可打开弹窗，教学任务已有详情／填写／发布操作保留。 |
| T02 | 旧安排链接、旧日记录链接、刷新、前进后退和显式历史日期均打开正确视图／弹窗；无权目标不偷偷回退 P1。 |
| T03 | 关闭或切下一张日卡保留背景周次、任务筛选、滚动及输入；无多层模态阻塞，完成筛选中的当前学生不突然消失。 |
| T04 | 同一实际课次在完整表、课次安排、日卡一致；第3、5节显示合并2节，不叫连堂；不同教室正确对应，课次数仍为2。 |
| T05 | 单课次日卡不重复展开同一个出勤下拉；多课次部分请假只修改对应明细，周矩阵与学生抽屉立即读到相同事实。 |
| T06 | 上午手动B、下午未发生：保持阶段状态；下午后沿用确认保留B。未来卡不生成欠评价／禁用全班表，未来作业布置仍可用。 |
| T07 | 过去但未填不显示完成；评价完成与考勤待核对可区分；同一学生多字段待办去重，原因／亮点／小结为空不增待办。 |
| T08 | 各原因入口可选择系统常用项、个人项或手填，选择后可补充／清除；状态切换不会保留不适配原因，不自动沿用上一学生。 |
| T09 | 已批准来源正确映射且不重复录入；选“比赛”不生成批准，原因待核实不抹掉已核实出勤；全天请假但残留A按同一适用规则核对，不能无依据算完成。 |
| T10 | 个人原因／亮点收藏、新建、修改、停用后刷新仍正确，教师互相隔离；已使用文字与已发布内容不随模板改动。 |
| T11 | 明确选亮点一次加入当前学生，修改／撤销实际生效；不自动给A学生或全班添加，误双击不重复，不同日期同类行为可再次记录。 |
| T12 | 从同一任务周一、周三两张日卡预览，得到相同的整周默认范围；来源日仅影响返回。日卡搜索／待处理子集不遗漏其他合法学生，当天请假的学生不被排除。 |
| T13 | 历史日卡进入其所属学校周期；跨周补课按实际日期；本任务只有一天上课仍显示周反馈，不生成日报，不设强制周日发布锁。 |
| T14 | 周中预览包含已记录和未来安排，预览不生成发布、不通知；未来不被填A，已发生缺项不能被静默隐藏。 |
| T15 | 从日卡直接进入周准备，能处理课堂／总结／评语／已有作业问题后返回同一次准备，不强制中转周矩阵，范围不丢失。 |
| T16 | 相关作业不只来自当前日卡，按已有规则归期；疑似未交不能当确认负面发布，明确暂不纳入不免做、不消除原待办。 |
| T17 | 普通周发布与主动提前阶段发布可区分；阶段仍是同周期周反馈。补发布保留旧有效覆盖和旧版本，不为每日日卡创建独立报告。 |
| T18 | 预览前保存失败保留输入；预览后内容改变会重新核对；重复确认／响应丢失重试不重复发布，日卡与周发布状态不混用。 |
| T19 | 家长只见公共内容及本人孩子；内部原因、课次观察、私人备注和未采用文字不外发，多等级不平均为周等级；旧报告／图片仍使用旧快照。 |
| T20 | 日卡布置作业实际创建共享任务，成功系统时间、名单和方案正确；返回不丢课堂输入，重复操作／来源课次调整不复制或删除作业。 |
| T21 | 单课原位参考、学生资料入口、完整课表六项编辑与真正拖拽、采用／差异／跨周放弃正常，纯教师无课表中心误跳。 |
| T22 | 四级／八级／文字及无默认等级均从正确绑定解析；快速切学生／任务、失权、刷新及故障重试不串数据，原有批量保护和安全撤销继续有效。 |

至少提供以下实际操作链的连续证据：

“我的教学按日记录 → 打开日卡 → 选择异常原因 → 添加常用亮点 → 保存并关闭 → 再开核对 → 预览整周反馈 → 定位处理一个问题 → 返回准备 → 明确发布或阶段发布 → 返回原日卡视图 → 查看对应历史版本”。

另提供“同任务两张不同日期日卡进入相同整周范围”的对照。这是本轮发布语义的核心验收，不能只证明按钮打开了一个页面。
