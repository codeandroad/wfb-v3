## 实际实现位置

- `lib/mt/report-tables.ts`：从TaskWeek/byStudent、实际课次、有效日评价、Assignment ID建立只读表格；出勤和一次日评价分离，原始0分保留，个人不裁剪班级投影。
- `lib/mt/report-build.ts`：完整名单、教学介绍、独立学情总结、共同安排、明确选入的评语／观察／重点事实；剔除重复摘要。观察要求任务、教师、学生、课次、适用性匹配。
- `lib/mt/reports.ts`、`report-options.ts`：七套结构预设、模板配置、HEX及对比度校验、模块顺序；保存模板不保存学生事实。
- `components/mt/report-options-editor.tsx`、`report-templates.tsx`、`report-workspace.tsx`：配置编辑、复制／保存／默认／归档、独立个人选择、准备与历史流程。
- `components/mt/report-view.tsx`：正式预览直接使用导出渲染器的图片，提供缩放、分段和无障碍文本表格；渲染失败不显示新报告已就绪。
- `lib/mt/report-table-export.ts`、`report-export.ts`：完整行分页、重复表头与身份、宽表按日期组续页、长正文分页、独立个人文件名和ZIP清单，不截编辑器当前DOM。
- `components/mt/report-verification.tsx`：合成28／72／123人场景的七套报告与完整个人批量实际输出检查。检查PNG解码、清单数量及隐私哨兵。
- `scripts/test-reports.cjs`：37项报告回归，覆盖表头、考勤、作业、多模板、选入观察、完整名单与不可变快照。
- 临时 `app/api/report-evidence/route.ts` 仅用于把浏览器生成产物转存验收目录，完成后已删除，不作为应用能力交付。

## 七套模板

| 模板 | 实际结构 |
|---|---|
| C01 标准矩阵 | 默认一日一格，出勤在前、日评价在后；独立具体作业结果表，可切真两层表头。 |
| C02 清晰分列 | 日期跨两列，第二层分别出勤／课堂表现，序号和姓名跨两行。 |
| C03 紧凑对照 | 紧凑字号／间距、正常考勤简写、日期组续页；异常和作业仍完整。 |
| C04 教学周报 | 教学与学情正文，按日期组织课堂表，课堂与作业分开核对。 |
| P01 学习概览 | 完整日记录和具体作业表，可选课次细节。 |
| P02 逐课详报 | 日表一次评价，另列逐课日期、节次、时间、考勤及允许的选入观察，不复制日等级。 |
| P03 学习跟进 | 主动选定的事实和建议优先，完整周日表与作业表保留。 |
