# 周反馈发布与报告模板完整交接包

日期：2026-10-04｜版本：r2.2

## 使用方式

将整个ZIP交给当前v0工程，并发送 START_HERE.txt 中的文字。也可以单独上传主提示词；主文包含全部执行规则，其余文件用于消除表头歧义、适配合成场景和核验。

本包完整替代此前发布相关r1、r2、r2.1及它们的启动文字。无需先执行旧包。旧文件仅归档，不与本版并列执行；不推翻当前其他模块已确认规则。

## 核心变化

班级默认沿当前按日矩阵：时间表头只用星期／日期，指标在格内分层或独立字段子行。个人按需发布，但每套都拥有完整周课堂记录表、作业明细表与高质量格式，可进一步展开真实课次。个人不再是低配文字补充。

## 本地检查

在解压后的本包目录执行：

```text
python3 tools/validate_package.py
```

检查脚本只读本目录文件，不连接任何外部服务，不修改原型存储，不执行发布或发送。脚本成功不能证明v0页面、PNG、链接、权限或产品流程通过。

## 原型交付范围

本包不含已经实现的v0代码、真实报告样图或产品测试通过记录。v0须基于当前工程实际完成七套报告、可操作配置、预览与PNG／ZIP，再由用户核验。家长账户和链接沿当前原型演示能力，不冒充真实送达或安全部署。
