## 入口统一说明

- 工作台、我的教学、本周教学安排、旧 `/feedback` 均进入同一任务工作区 `/teaching/task/[id]`，以 `from` 标记来源，返回按来源回到原页并保留周次/筛选。
- 任务列表“开始填写”只是导航；进入后已发生且有权的课堂直接可编辑，首次明确修改才写入草稿，浏览不写入。
- 标题＝教学班名称＋必要分工；自定义分工启用时只显示正文；课程名仅按教学班详情“显示课程名称”设置追加。周次只在周次选择器中表达，人数显示为“N人”，名单基准日按需悬停查看。
- 反馈页不再编辑课卡名称：任务默认设置仍在教学班详情，单课覆盖仍在完整课表的课节信息编辑器。

## 矩阵

- 单元格默认显示出勤与课堂评价摘要（待处理/各节不同/不评价区分显示），点击后就地编辑该日各节出勤、异常原因（选填，正常时不可填）和当日评价；可直接打开该生反馈抽屉。
- 候选值不自动保存；未来课显示“尚未上课”，不提前写入。作业仍按真实任务在“作业”页独立管理。
