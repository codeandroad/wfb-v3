# 2026-10-19 课表显示样式与筛选

## 需求与选择

本轮依据教师与教务课表的实际使用反馈：评估学科与行政班片段能否独立定制，保留现有整体样式，补教务显示设置、聚合课卡教师姓名及课卡筛选。不是重新设计外壳，不涉及作业功能或发布业务。

采用可选的名称片段覆盖：学科文字与行政班文字各有文字颜色、局部底色、字重及字体；未设置的属性通过 CSS 继承原整体标题。清除细分设置恢复继承。局部背景只覆盖文字，不覆盖整张课卡、分工或状态提示。旧 TASK / CLASS / COURSE 样式、逐属性最后成功保存规则与恢复默认的序号墓碑均保留。

活动按完整名称统一设置，不拆学科与班名。自由命名、无法可靠识别的组合标题保留完整显示；不会为拆样式改写教学班名称。组合名称必须与结构化 subject 一致，并具有登记班级或已知行政班依据。优先使用登记的 placementHomeroomId / 场景 scheduling_homeroom_id，核对可见名称确实是该行政班后才赋予行政班片段身份；合法教学组别名不会被误作行政班。

## 页面组织

沿用现有绿色、白色、浅灰绿色课表和圆角面板、无衬线正文字体及密集课卡，不重排顶栏、左栏或作息轴。现有主色与语义色延续：松绿 #2f6b4f、墨蓝 #2d4f7c、砖红 #a2422e，课卡浅底使用现有 STYLE_BGS。颜色选择直接复用现有控件、HEX 校验和色板。

教学设置保留“我的显示样式”，下方增加“名称细分与活动样式”。我的完整课表与课表中心，在周网格前增加紧凑工具区：显示张数、显示样式入口、类型/学科/教学班筛选以及关键词。聚合课表增加教师筛选。设置弹窗提供部位、对象、继承预览、逐属性保存和恢复继承；候选 HEX 不自动保存。

教务整卡、文字片段、活动样式按浏览者 staffId 和 admin 模式隔离；教师使用 teacher 模式。兼任教师的教务样式不会写入所查看教师的个人设置，学校发布内容也不变。设置复用当前原型持久化保存通道；失败显示错误，保留候选。

## 课卡与对象

教务“教学班”和“行政班”每卡显示 entry.teacherId 对应教师姓名；教师对象模式不重复姓名。详情显示教师。修复原教学班选择其实选中第一位教师的问题：班级独立选中，只聚合该班教师来源里精确匹配班名的学校课次，调整通过对应教师入口进行。

行政班保留既有合成 memberTeacherIds 聚合口径；本次没有凭名称猜测跨班选修学生归属。它仍可能包含成员教师其他班的安排；可用教学班/学科/教师筛选缩小显示。精确行政班学生课表需要完整学生任课关系，是原数据模型限制。

## 筛选与安全边界

先生成完整周课表和调休补课，再只筛选可见课卡。完整条目仍用于占位、新增格判断、复制/移动校验及冲突；隐藏课次不成为空闲。无结果显示清空条件提示，切换对象清空筛选，换周保留条件且标出当前周已无选项的情况。

关键词与课卡共用可见分工解析，支持教师私人分工简称；教务只索引规范分工，不引入私人标签。差异先按完整数据计算，再保留任一侧命中的差异行，避免伪造新增/删除。教师差异确认与采用仍针对完整安排，筛选时明确提示作用范围。

校历跨周来源显式区分学校发布、学校草稿及教师已应用版，教学班来源仍精确限制本班。锁定、停课、草稿、个人调整和补课的状态底色优先，状态文字与冲突环始终保留。
